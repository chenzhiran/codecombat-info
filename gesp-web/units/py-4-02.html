1　从一排到一片

From a Row to a Grid

1.1 从一排到一片

一维列表像"一排格子"，二维数组像"一张表格"——有行、有列。

1.2 核心约定

打个比方： 一维列表像一排格子，二维数组像一整面货架——横着有行、竖着有列。
找东西时不能只说"第几个"了，得说清楚"第几行、第几列"，就像报座位号一样。
记法：先看行、再看列——a[行][列]。
核心约定： 二维数组 a[i][j] 中，i 是行号，j 是列号。
而且 a[i] 这一整行，本身就是一个一维列表。
所以 len(a) 是"有多少行"，len(a[0]) 是"第一行有多少列"。

2　创建二维数组

Creating

2.1 怎么创建二维数组

两种创建方式 Python 
# 方式一：直接写出来（数据不多时最方便）
grid = [[1, 2, 3],
        [4, 5, 6]]

# 方式二：用推导式生成一张全 0 的表格
rows, cols = 3, 4
table = [[0 for j in range(cols)] for i in range(rows)]
# 得到 3 行 4 列，全是 0
要点　方式二适合"需要一个空的表格来填数据"的场合，比如做地图、记分板

2.2 最容易踩的坑

最容易踩的坑： 千万别写成 [[0] * cols] * rows！
那样创建出来的 几行其实是同一个列表，改一行会"带着"其他行一起改。
要生成多行，必须用推导式，让每一行都是独立造出来的。
对比一下差别 Python 
# ✘ 错误的写法：三行是同一个列表
bad = [[0] * 3] * 2
bad[0][0] = 9
print(bad)      # [[9, 0, 0], [9, 0, 0]]   两行一起变了！

# ✔ 正确的写法：每行独立
good = [[0] * 3 for i in range(2)]
good[0][0] = 9
print(good)     # [[9, 0, 0], [0, 0, 0]]   只有第一行变
结论　要做表格，就用推导式；[[0]*3]*2 是四级最经典的错法

3　行列索引

Indexing

3.1 行列索引

访问与修改 Python 
grid = [[1, 2, 3],
        [4, 5, 6],
        [7, 8, 9]]

print(grid[0][0])     # 第 0 行第 0 列 → 1
print(grid[0][2])     # 第 0 行第 2 列 → 3
print(grid[2][0])     # 第 2 行第 0 列 → 7

print(grid[1])        # 整个第 1 行 → [4, 5, 6]

grid[1][1] = 99       # 把第 1 行第 1 列改成 99
print(grid[1])        # [4, 99, 6]
OUTPUT　1
3
7
[4, 5, 6]
[4, 99, 6]

3.2 读代码的顺序

读代码的顺序： 看到 grid[2][0]，在心里念一遍——"第 2 行、第 0 列"。
先横后纵，就像查表时先说行号再说列号。

4　遍历：双重循环

Traversal

4.1 双重循环遍历

三种遍历写法 Python 
grid = [[1, 2, 3], [4, 5, 6]]

# 写法一：用下标（最通用，能同时知道行列号）
for i in range(len(grid)):
    for j in range(len(grid[i])):
        print(grid[i][j], end=" ")
    print()

# 写法二：直接遍历每一行（更简洁）
for row in grid:
    for x in row:
        print(x, end=" ")
    print()

# 写法三：一行写完（列表推导式）
flat = [x for row in grid for x in row]
print(flat)     # [1, 2, 3, 4, 5, 6]
OUTPUT　1 2 3
4 5 6
1 2 3
4 5 6
[1, 2, 3, 4, 5, 6]

4.2 什么时候用哪个

什么时候用哪个？ 需要行列号（比如要输出坐标、要按位置修改）→ 写法一；
只是把所有数拿出来用 → 写法二，写起来最省事；
要把二维压成一维 → 写法三，一行搞定。

5　三个常见操作

Three Common Tasks

5.1 三个常见操作

操作一：求所有元素的和 Python 
grid = [[1, 2, 3], [4, 5, 6]]

total = 0
for row in grid:
    for x in row:
        total = total + x

print(total)     # 21
套路　和求一维数组的和完全一样，只是多加了一层循环
操作二：求每一行的和 Python 
grid = [[1, 2, 3], [4, 5, 6]]

for i in range(len(grid)):
    rowSum = 0                       # 每行开始时"清零"
    for j in range(len(grid[i])):
        rowSum = rowSum + grid[i][j]
    print("第", i, "行的和是", rowSum)
OUTPUT　第 0 行的和是 6
第 1 行的和是 15
关键　累加变量必须在外层循环里面清零，否则会一直累着
操作三：找出最大值以及它所在的位置 Python 
grid = [[1, 2, 3], [4, 5, 6]]

big = grid[0][0]
bi, bj = 0, 0
for i in range(len(grid)):
    for j in range(len(grid[i])):
        if grid[i][j] > big:
            big = grid[i][j]
            bi, bj = i, j          # 记下它的位置

print(big, bi, bj)     # 6 1 2
要点　除了记住"值"，还要用两个变量记住它的"行和列"

把现实世界里的平面位置，映射成表格里的坐标。

distanceX = 4         # 相邻两列的水平间距

zeroPoint = {"x": 14, "y": 14}     # 第 0 行第 0 列的基准位置

# 把每个金币的坐标，换算成它在表格里的行列号
row = int((coin.pos.y - zeroPoint.y) / distanceY)

要点　用"相对基准点的距离 ÷ 间距"，就能把平面坐标变成行列号

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
二维数组的坑，一半是行列写反，一半是创建方式写错。四条，条条都要考。
1
行列写反。把 a[行][列] 写成了 a[列][行]。
扣哒鸭：记住 a[i][j] 里 i 是行、j 是列。 拿不准就在心里念一遍："第 i 行、第 j 列"。
写反了往往不报错，只是结果错误——最难查的那种错。
正确写法：a[i][j]，i 是行号，j 是列号
2
用 [[0]*n]*m 创建表格。改一格，整列都跟着变。
扣哒鸭：外面的 * m 是把同一个列表复制了 m 份引用， 它们指向同一块内存。
正确写法是推导式：[[0]*n for i in range(m)]，这样每行都是新的。
正确写法：[[0] * cols for i in range(rows)]
3
内层循环用了外层的长度。写成 range(len(grid))。
扣哒鸭：内层要数的是当前这一行有多少列， 所以必须写 range(len(grid[i]))。
如果碰上方阵（行列相等）可能侥幸跑对，一遇到长方形表格立刻崩。
正确写法：内层用 range(len(grid[i]))
4
按行求和时累加器放错了位置。放在外层外面，导致越加越大。
扣哒鸭：每一行都要重新从 0 开始加， 所以 rowSum = 0 必须写在外层循环里面、内层循环外面。
正确做法：在外层循环开头重置累加变量

8　题目练习

Practice

第 1 题改编自 2026 年 9 月 · Python 四级 第 4 题，其余为原创练习题。

改编自 2026 年 9 月 · Python 四级 · 第 4 题单选题
齿轮高台的传送带上摊着一块二维表格（列表里套列表）。
执行下面 Python 代码后，输出的结果是（　　）。
1  nested = [[1, 2], [3, 4], [5, 6]]
2  flat = [num for sublist in nested for num in sublist if num % 2 == 0]
3  print(flat)
A.[2, 4, 6]　　B.[1, 3, 5]　　C.[1, 2, 3, 4, 5, 6]　　D.[2, 4]
查看答案与详解
答案：A。这是双层推导式，读法要从左往右：for sublist in nested 先取出一行，for num in sublist 再把这一行的每个数拿出来，最后 if num % 2 == 0 筛出偶数。
依次得到 2、4、6，所以是 [2, 4, 6]。
要点一：多层推导式的顺序就是嵌套循环的顺序，外层写在前、内层写在后；
要点二：这就是"二维 → 一维"的扁平化（展平）写法，遍历二维数组时最常用。
写成普通循环是这样：for sublist in nested: for num in sublist: if …
对应小节4 遍历：双重循环。

执行 a = [[0] * 3] * 2 后， a[0][0] = 5 会让 a[1][0] 也变成 5。（　　）
查看答案与详解
答案：正确（√）。这种写法创建出来的两行其实是同一个列表， 只是被引用了两次，所以改一行会"带着"另一行一起变。
正确写法：[[0] * 3 for i in range(2)]，让每行独立。

原创练习题编程题
题目要求：已知一个 3 行 3 列的二维数组 g = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]， 编程输出：① 所有元素之和；② 主对角线（左上到右下）上元素之和。
查看参考答案与要点 
g = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# ① 所有元素之和
total = 0
for row in g:
    for x in row:
        total = total + x
print(total)          # 45

# ② 主对角线之和（行号 == 列号）
diag = 0
for i in range(len(g)):
    diag = diag + g[i][i]
print(diag)           # 1 + 5 + 9 = 15

输出：45、15
要点：
① 求总和用双重循环，一层层加；
② 主对角线的特点是行号等于列号，所以只写 g[i][i]；
③ 副对角线（右上到左下）则是 g[i][len(g)-1-i]，可以自己试试。
对应小节4 遍历：双重循环；5 三个常见操作。

9　本单元小结

Unit Summary
戈登 · 齿轮工程师
这一单元就三句话：
一、a[i][j]——i 是行，j 是列，先横后纵。
二、len(a) 是行数，len(a[0]) 是列数。
三、创建表格只能用推导式，别用 [0]*n 去乘。
记住这三条，二维数组的题目你基本都能拿下了。

你在立体货架前收获了什么

  • 二维数组——"每个元素都是一个列表"的列表，可以看成一张表格。
  • 行列索引——a[i][j]：i 是行号，j 是列号；a[i] 拿到的是整整一行。
  • 长度——len(a) 是行数，len(a[0]) 是列数。
  • 创建——直接写字面量，或用 [[0]*cols for i in range(rows)]；不要用 [[0]*n]*m。
  • 遍历——双重循环，外层管行、内层管列，总共执行"行数 × 列数"次。
  • 按行统计——累加变量必须在外层循环里重置。
  • 定位最值——除了记值，还要用两个变量记住行号和列号。
