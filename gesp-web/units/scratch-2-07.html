1　算术运算

Arithmetic

1.1 加减乘除

算盘小铺的柜台后面挂着一把超大的算盘，珠子会发光。摊主说： "所有要算的数字，都能塞进这几把绿色的小积木里。"

重点示例：四则运算 图形化积木
要点　运算积木是"值"——它能塞进任何白色的小框里，也能套在别的运算里算得更复杂

1.2 取整与求余

求余最常用的一个用法：判断"能不能被整除"。n 除以 2 的余数 = 0 就说明 n 是偶数。
同理，"除以 3 的余数 = 0"就说明 n 能被 3 整除——这类题在考卷上出现得非常多。

1.3 随机数

重点示例：随机数的两种用法 图形化积木
要点　随机数会返回范围内任意一个整数（两个端点都可能被抽到）；范围可以填负数
打个比方：随机数就像掷骰子——"在 1 和 6 之间取随机数"就是扔一枚六面骰。每次结果不同，程序就有了"变化"的味道。

2　关系运算

Comparison

2.1 大于、小于、等于

重点示例：三块比较积木 图形化积木
要点　两边可以放数字、变量、随机数，甚至别的运算结果；它们都是六边形

2.2 关系运算的结果是"成立 / 不成立"

一句话记住：算术运算的结果是"一个数"，关系运算的结果是"一句话"（成立或不成立）。所以关系运算天生就是用来当条件的。

3　逻辑运算

Logic

3.1 与：两个都要

重点示例：价格合适而且我还买得起 图形化积木
要点　"与"两边必须同时成立，整个条件才成立；只要有一边不成立，结果就不成立

3.2 或：有一个就行

重点示例：现金或者刷卡都行 图形化积木
要点　"或"两边只要有一边成立，整个条件就成立；两边都不成立时才不成立

3.3 不成立：把结果反过来

重点示例：不是红色的就要 图形化积木
要点　"不成立"只接一个条件，把它反过来：成立变不成立，不成立变成立
打个比方：与像"两把锁都开才进门"；或像"带哪把钥匙都能进"；不成立像"把牌子翻个面"——正面写"是"，反面就写"否"。

4　写出筛选条件

Writing Conditions

4.1 把中文翻译成积木

4.2 组合条件

重点示例：一个稍微复杂的筛选条件 图形化积木
读法　中文是"数量大于 0，而且颜色不是红色"——外层用"与"，里面套一个"不成立"
逻辑推理题的做题顺序：① 把中文拆成几个小条件；
② 判断这几个小条件之间是"都要"还是"有一个就行"；
③ 分别是"都要"就用与，是"有一个就行"就用或；
④ 有"不"字的，用不成立包起来。

Level Practice

这一关要靠"比较"来决定做什么：左右两边的东西一样不一样？' '——这正是关系运算最典型的用法。

关卡 110

等于（Equals）

进入关卡 →
故事： 集市两边各有一排货架，上面的东西有时候是货、有时候是空位。 你要一路往上走，每走一格就左右各看一眼： 左边是货就处理左边，右边是货就处理右边，两边都没有就继续往上。

思路：每一格做三件事：比较左边是什么、比较右边是什么、往上走一格。 "是什么"用关系运算判断，"要不要处理"用分支决定。

重点示例：先比较，再决定 图形化积木
读法　"如果……等于……那么"——关系运算给出"成立 / 不成立"，分支积木据此决定做不做
自己试一试：把第二个"如果……那么……否则"换成"如果……那么"，你会发现"空位"那句提示不见了。这就是"否则"的用处：两种情况都要说话时，才需要它。

这一关的骨架是二级综合题的标准写法：' 循环负责走，关系运算负责比，分支负责选。

回头看一眼“算盘”这个词：算盘上每一次拨珠，都相当于一次算术或关系运算。把运算结果当条件用，程序才真正有了"判断力"。

6　常见陷阱

Common Traps
陷阱 1：把"关系运算"的结果当成一个数。它给出的是"成立 / 不成立"，不能拿去加减。
正确做法：要算数就用算术运算（椭圆），要比大小就用关系运算（六边形）。
陷阱 2：把"与"和"或"用反。"两个人都会游泳"是"与"，"两个人有一个会游泳"是"或"。
判断方法：读中文时圈出"都"还是"有一个"——圈对了就不会用错。
陷阱 3：求余和除法混着用。9 ÷ 2 的商是 4、余数是 1，这两个结果来自不同积木。
正确做法：要"能不能整除"用求余（余数为 0 就是整除）。
陷阱 4：漏掉乘法除法的优先级。虽然积木嵌套本身已经把顺序"画"出来了，但读题时"先乘除后加减"这条规则仍然要自己判断。
正确做法：拿不准就先算，再往积木里填。

7　题目练习

Practice

第 1 题改编自 2026 年 9 月 · 图形化编程 二级 第 9 题，其余为原创练习题。

改编自 2026 年 9 月 · 图形化编程 二 级 · 第 9 题单选题
按照 2、4、8、16、32 的规律，32 后面的数字应该是（　　）。
A.48
B.64
C.96
D.128
查看答案与详解
答案：B。看相邻两项的倍数关系：4 ÷ 2 = 2、8 ÷ 4 = 2、16 ÷ 8 = 2……每一项都是前一项的 2 倍，所以 32 后面是 32 × 2 = 64。
A 错：48 是按"+16"猜的，看不出倍数规律；
C 错：96 = 32 × 3，倍数对不上；
D 错：128 是 64 × 2，跳了一格。
用积木算：把"重复执行"里的"将数字设为 数字 × 2"跑几遍，就能得到同一串数——规律题也能用程序验证。
对应小节1.1 算术运算。
原创练习题单选题
小铺要判断一个数 n 是不是偶数，下面哪种条件写法最合适（　　）。
A.n ÷ 2 的余数 = 0
B.n + 2 > 0
C.n × 2 = 0
D.取整 n = 0
查看答案与详解
答案：A。偶数就是"能被 2 整除"，而"能整除"用求余判断：余数为 0 就说明整除。
B 错：n + 2 大于 0 只说明 n 大于 -2，和奇偶无关；
C 错：n × 2 = 0 只有 n = 0 才成立；
D 错：取整不会改变整数本身。
对应小节1.2 取整与求余。
原创练习题单选题
要表达"价格低于 100，而且我买得起"，六边形槽里最合适的写法是（　　）。
A.{价格 < 100} 或 {钱包 > 价格}
B.{价格 < 100} 且 {钱包 > 价格}
C.不成立 {价格 < 100}
D.{价格 < 100} + {钱包 > 价格}
查看答案与详解
答案：B。"而且"两个字就是提示——需要两个条件同时成立，所以用与。
A 错："或"是"有一个就行"，比题目要求宽松了；
C 错："不成立"是把条件反过来；
D 错：两个六边形不能相加——运算要同类形状（椭圆）才行。
对应小节3.1 与：两个都要。
原创练习题单选题
下面哪个积木的运算结果是"成立 / 不成立"，只能放进六边形的条件槽（　　）。
A.3 + 5
B.在 1 和 6 之间取随机数
C.x > y
D.7 × 8
查看答案与详解
答案：C。只有"比较大小"这类关系运算才会给出"成立 / 不成立"，形状也因此是六边形。
A、B、D 错：这三个算出来的都是一个数，形状是绿色椭圆，要放进白色的小圆框里。
对应小节2.2 关系运算的结果。
原创练习题多选题
关于"与、或、不成立"三个逻辑运算，下面说法哪些是正确的（　　）。
A."与"要求两边都成立
B."或"只要有一边成立就成立
C."不成立"可以把一个条件反过来
D.三个逻辑运算可以用来组合出更复杂的条件
查看答案与详解
答案：A、B、C、D。这四条正是逻辑运算的全部要点——它们可以互相嵌套，把简单的条件拼成复杂的筛选条件。
记忆口诀：都与、或一、非反。
对应小节3.1～3.3 逻辑运算。
原创练习题判断题
在图形化编程中，"在 1 和 6 之间取随机数"执行后，结果可能是 1 到 6 之间的任意整数，但不可能是 7。（　　）
查看答案与详解
答案：正确（√）。随机数的取值范围就是两个参数之间（含端点），所以"1 和 6"只会给出 1、2、3、4、5、6 这六种结果。
要得到更大的数，就得把范围写大——比如"在 1 和 10 之间取随机数"。
对应小节1.3、2.1 随机数。
