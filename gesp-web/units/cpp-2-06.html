1　数学函数库 cmath

The cmath Library

1.1 为什么要用函数

奥卡拿起那把折尺：你要把 -7 变成 7，自己写也行：判断一下是不是负数，是就取相反数。

可要是你要开平方呢？自己写就没那么容易了。 所以前人在仓库里备好了一把现成的尺子——你报个数，它就还你一个结果。

函数是什么： 函数就是"一段已经被写好、取好了名字、可以直接调用的代码"。
你只要写函数名加上一对括号，把要处理的数放进括号里，它就把结果给你。
这个"放进去的数"叫参数，拿到的结果叫返回值。
好处：不用重复造轮子，而且不容易出错。
用法都一样：函数名(参数) C++ 
int x = abs(-7);            // 把 -7 放进 abs，拿回 7
double y = sqrt(16.0);      // 把 16.0 放进 sqrt，拿回 4.0

cout << x << endl;            // 7
cout << y;                   // 4
读法　函数名(参数) → 得到返回值；返回值可以直接输出，也可以先存进变量

1.2 头文件不能忘

要用数学函数，先请出工具箱 C++ 
#include <iostream>    // 输入输出
#include <cmath>        // ★ 数学函数都在这里
using namespace std;

int main() {
    cout << abs(-3) << endl;    // 3
    cout << sqrt(9.0);          // 3

    return 0;
}
OUTPUT　3
3
漏了后果很直接： 不写 #include <cmath>，编译器就不认识 sqrt、pow 这些名字， 会直接报"未声明"的错误。
所以只要用到数学函数，第一件事就是加上那一行——#include <cmath>。

2　绝对值

abs / fabs

2.1 把负数折成正数

函数用于例子结果返回类型
abs(x)整数abs(-7)7整数
abs(x)小数（<cmath> 里可用）abs(-3.5)3.5小数
fabs(x)小数（更明确的写法）fabs(-3.5)3.5小数
打个比方： 绝对值就像一把折尺——不管这块牌子是挂在左边还是右边，量出来的距离都是正的。
|-7| 和 |7| 都是 7：绝对值只关心"离 0 有多远"，不关心方向。
记法：abs 里的 a 就是 absolute（绝对）的第一个字母。

2.2 什么时候需要它

求两个数的"差多少" C++ 
int a = 3, b = 10;

cout << a - b << endl;           // -7   有负号
cout << abs(a - b) << endl;       // 7    "相差 7"，不管谁大

// 判断两个小数是否"足够接近"
double x = 0.1 + 0.2, y = 0.3;
cout << (abs(x - y) < 0.000001);  // 1    差很小，就算相等
常见用途　① 求"相差多少"；② 判断两个浮点数是否相等（比较它们的差是否足够小）
为什么浮点数不能用 == 直接比？ 因为小数在计算机里是近似存储的，0.1 + 0.2 常常不等于 0.3。
正确做法：比较两者的差是否小于一个很小的数（比如 0.000001）——这时候就要用到 abs。

3　取整三兄弟

floor / ceil / round

3.1 向下取整 floor

floor：往下踩到最近的整数 C++ 
cout << floor(3.9) << endl;     // 3    往下踩
cout << floor(3.1) << endl;     // 3    也是 3
cout << floor(-2.3) << endl;    // -3   ★ 负数是往"更小"走
注意　floor(-2.3) 是 -3，不是 -2——"向下"指的是一直朝数轴的左边走

3.2 向上取整 ceil

ceil：往上抬到最近的整数 C++ 
cout << ceil(3.1) << endl;      // 4    往上抬
cout << ceil(3.9) << endl;      // 4    也是 4
cout << ceil(-2.3) << endl;     // -2   ★ 负数是往"更大"走
注意　ceil(-2.3) 是 -2——"向上"指的是朝数轴的右边走

3.3 四舍五入 round

round：看小数部分，磨到最近的那个整数 C++ 
cout << round(3.4) << endl;     // 3    小数 0.4，舍
cout << round(3.5) << endl;     // 4    小数 0.5，入
cout << round(3.6) << endl;     // 4
cout << round(-2.5) << endl;    // -3   负数离 -3 更近的规则见下
要点　round 才是大家熟悉的"四舍五入"；它和 (int) 强制转完全不是一回事
三个都要注意：返回值是小数！ floor、ceil、round 返回的都是浮点数， 只是数值变成了整数。
如果直接 cout << floor(3.9);，有些环境下会输出 3，但它的"身份"仍是小数。
想存进整型变量，记得加一步 (int)。

3.4 三个一起比

数floor 向下ceil 向上round 四舍五入(int) 强制转换
3.23433
3.53443
3.83443
-2.3-3-2-2-2
-2.5-3-2-3-2
最容易混的一栏： (int) 永远等于"砍掉小数"，也就是正数时和 floor 一样、负数时和 ceil 一样。
它和 round 的区别最明显：(int)3.9 得 3，round(3.9) 得 4。

4　幂与开方

pow & sqrt

4.1 pow 乘方

pow(底数, 指数) = 底数的指数次方 C++ 
cout << pow(2, 10) << endl;       // 1024   2 的 10 次方
cout << pow(2, 0.5) << endl;      // 1.41421  相当于开平方
cout << pow(3, 3) << endl;        // 27

int n = (int)pow(2, 10);          // 想存整数要加 (int)
cout << n << endl;                // 1024
要点　pow 的两个参数都是"底数和指数"，返回的是小数，需要整数时要转换
打个比方： 乘方就像把砖往上叠——每一层都比下一层多一倍。
pow(2, 10) 就是"从 1 开始，翻倍翻十次"：1 → 2 → 4 → … → 1024。
口诀：底数 × 底数 …… 一共乘"指数"次。

4.2 sqrt 开方

sqrt：开平方 C++ 
cout << sqrt(16.0) << endl;       // 4
cout << sqrt(2.0) << endl;        // 1.41421
cout << sqrt(100.0) << endl;      // 10

// 判断质数时常用：只试到 sqrt(n) 就够了
int n = 49;
for (int i = 2; i <= sqrt(n); i++) {
    if (n % i == 0) {
        cout << "非素数";
        break;
    }
}
注意　sqrt 的参数最好写成小数（如 16.0），避免类型不匹配的麻烦
为什么判断质数只试到 sqrt(n)？ 因为如果 n 有一个大于 √n 的因数，那它一定还配着一个小于 √n 的因数。
所以只要试到 √n，就能把所有"成对出现"的因数都试完——不用试到 n 那么大。
这是"用数学减少计算量"的经典例子，二级真题里出现过。

5　最大与最小

max & min
挑两个数里的大者 / 小者 C++ 
int a = 7, b = 3;

cout << max(a, b) << endl;       // 7
cout << min(a, b) << endl;       // 3

// 链式使用，可以挑出三个数里的最大值
int c = 5;
cout << max(max(a, b), c);        // 7
要点　max / min 一次只能比两个数；三个数要嵌套着写
打个比方： max 像一个裁判——你给它两名选手，它指给你高的那一个。
想在三名选手里挑最高的？先让前两名比一次，再把胜者和第三名比一次。
这就是 max(max(a, b), c) 的来源。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
数学函数这一块，错的全是"细节"。四条，每条都能设一道题。
1
把 floor 的负数结果算错。
扣哒鸭：floor(-2.3) 是 -3，不是 -2！
"向下"的意思是往数轴的左边走，-3 比 -2 更靠左。
同理 ceil(-2.3) 是 -2。
正确认识：floor 往小、ceil 往大
2
把 (int)3.9 和 round(3.9) 当成一回事。
扣哒鸭：(int)3.9 是砍掉小数，得到 3；
round(3.9) 是四舍五入，得到 4。
结果差 1，题目里常常就靠这一分。
正确认识：截断 ≠ 四舍五入
3
用数学函数却忘了 #include <cmath>。
扣哒鸭：漏了这一行，编译器就不认识 sqrt、pow、floor。
而且报的错常常是"未声明"，看着和数学函数毫不相干，很容易查错方向。
正确做法：第一行先写 #include <cmath>
4
以为 pow / sqrt 返回整数。
扣哒鸭：pow(2, 10) 得到的是 1024.0，sqrt(16.0) 得到的是 4.0。
要把结果存进 int 变量，就得加一步转换——虽然数值恰好是整数，但类型仍是小数。
正确写法：int n = (int)pow(2, 10);

8　题目练习

Practice

第 1 题改编自 C++ 二级真题，其余为原创练习题。

改编自 2026 年 9 月 · C++ 二级 · 第 10 题单选题
下面的 C++ 代码用于判断正整数 n 是否为素数（质数）， 其中 limit = sqrt(n) + 1; 的作用是控制循环范围。 下列关于这段代码的说法中，错误的是（　　）。
int n, limit, i;
cout << "请输入一个正整数: ";
cin >> n;
if (n <= 1)
    printf("%d 非素数", n);
else if (n == 2)
    printf("2 是素数");
else {
    limit = sqrt(n) + 1;
    for (i = 2; i < limit; i++)
        if (n % i == 0) {
            printf("%d 非素数", n);
            break;
        }
    if (i >= limit)
        printf("%d 是素数", n);
}
A.n <= 1 条件用于判断输入 0、1 以及负数时的情况，不能省略
B.n == 2 条件及其相关代码省略，程序的输出结果没有区别
C.break 语句不可以省略，否则非素数还将执行最后一行语句
D.limit = sqrt(n) + 1 中的 1 可以改为其他大于等于 1 的正整数，结果不会错，只是循环次数变多
查看答案与详解
答案：B。把 n == 2 这一分支省略会导致结果出错。
若去掉它：n = 2 时会进入 else 分支，limit = sqrt(2) + 1 ≈ 2.41， 循环条件 i < 2.41 使 i 从 2 开始就满足， 2 % 2 == 0 成立，于是会错误地输出"2 非素数"。
所以这个分支不能省，B 项说法错误。
A 正确：1 和更小的数本来就不是素数，必须提前拦下；
C 正确：没有 break 的话，即使已经判定"非素数"，循环仍会继续，最后 i 会跑到 limit， 反而又满足 i >= limit，把"是素数"也打印出来；
D 正确：把 1 改大只是让循环多跑几趟、效率降低，判定结果依然正确。
本题把 sqrt、循环范围、break 三件事串在一起。
对应小节4.2 sqrt 开方。
原创练习题单选题
下列 C++ 代码执行后，输出的结果是（　　）。
cout << floor(-2.3) << " " << ceil(-2.3) << " " << round(-2.3);
A.-2 -2 -2　　B.-3 -2 -2　　C.-2 -3 -2　　D.-3 -3 -3
查看答案与详解
答案：B。逐个来看：
floor(-2.3)——往数轴左边找最近的整数 → -3；
ceil(-2.3)——往数轴右边找最近的整数 → -2；
round(-2.3)——小数部分是 0.3，舍去，等于 -2。
所以是 -3 -2 -2。
负数这一块最容易错：记住 floor 永远往小、ceil 永远往大。
对应小节3.4 三个一起比。
原创练习题判断题
在 C++ 中，(int)3.9 和 round(3.9) 的结果相同。（　　）
查看答案与详解
答案：错误（×）。
(int)3.9 是强制类型转换，会把小数部分直接砍掉，得到 3；
round(3.9) 是四舍五入，得到 4。
两者差 1。(int) 永不四舍五入——这是最常考的一条。
对应小节3.3 四舍五入 round。
原创练习题单选题
下列 C++ 代码执行后，输出的结果是（　　）。
int a = 3, b = 8, c = 5;
cout << max(a, b) + min(b, c);
A.11　　B.13　　C.16　　D.8
查看答案与详解
答案：B。
max(a, b) = max(3, 8) = 8；
min(b, c) = min(8, 5) = 5；
两者相加：8 + 5 = 13。
注意 max / min 一次只比两个数，三个数要比两次。

答案：B。数学函数都在 <cmath> 里（c 表示 C 语言来的库，math 表示数学）。
A 管输入输出；C 管字符串处理；D 管一些通用工具函数。

原创练习题判断题
在判断两个浮点数是否相等时，通常比较它们的差是否足够小，而不是直接用 ==。（　　）
查看答案与详解
答案：正确（√）。浮点数在计算机里是近似存储的，
0.1 + 0.2 常常并不恰好等于 0.3，直接比较会得到"不相等"。
稳妥做法：if (abs(x - y) < 0.000001)——差值足够小就认为相等。
对应小节2.2 什么时候需要它。
原创练习题编程题
题目要求：读入三个整数，输出它们的最大值，以及最大值与最小值的差。
样例：输入 3 8 5，输出 8 5。
查看参考答案与要点 
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;

    int big = max(max(a, b), c);      // 三个数求最大：嵌套着比
    int small = min(min(a, b), c);    // 三个数求最小

    cout << big << " " << (big - small);

    return 0;
}

输入 3 8 5，输出 8 5。
要点：
① max / min 一次只能比较两个数， 三个数要嵌套写两次：max(max(a, b), c)；
② 本题也可以用 if 判断三次来实现，但用函数更简洁；
③ 差值一定是非负的，因为先求了最大值和最小值，大减小不会出现负数；
④ 如果题目改成"任意两数之差"，就要用 abs() 保证结果非负。
对应小节5 最大与最小。

二、abs 求绝对值；floor 往小取整、ceil 往大取整、round 四舍五入。

你在石室里学到了什么

  • 函数——一段写好、取好名字、可直接调用的代码；参数放进去，返回值拿出来。
  • 头文件——数学函数必须先 #include <cmath>。
  • abs / fabs——求绝对值，把负数折成正数。
  • abs 的用途——求"相差多少"；判断浮点数是否相等。
  • floor——向下（数轴左边）取整；floor(-2.3) = -3。
  • ceil——向上（数轴右边）取整；ceil(-2.3) = -2。
  • round——四舍五入；round(3.5) = 4。
  • (int) 与 round 的区别——(int)3.9 = 3，round(3.9) = 4。
  • pow(底数, 指数)——乘方，返回小数。
  • sqrt——开平方；判断质数时试到 sqrt(n) 即可。
  • max / min——一次比两个；三个数用 max(max(a,b),c)。
