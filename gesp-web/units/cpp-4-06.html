1　什么是递推

What Is Recurrence

1.1 后面的值，由前面的值算出来

递推的思路只有一句话：后面的值，由前面的值算出来。

斐波那契数列：每一项等于前两项之和 TEXT 
第几项：  1  2  3  4  5  6  7   8
数值：    1  1  2  3  5  8  13  21

规律：从第 3 项开始，每一项 = 前两项之和
      第 3 项 = 1 + 1 = 2
      第 4 项 = 1 + 2 = 3
      第 5 项 = 2 + 3 = 5
      ……

用公式写：f(n) = f(n-1) + f(n-2)
这个公式就叫"递推式"　 只要知道最前面的两项，后面所有项都能一路算出来

1.2 递推与递归的区别

递推（迭代）递归
方向从前往后：从已知推出未知从后往前：把大问题拆成小问题
实现用循环函数自己调用自己
效率高——每项只算一次低——同样的项会被重复算很多遍
风险几乎没有层数太深会"栈溢出"
适合有明确"从前往后"规律的问题结构本身就是层层嵌套的问题
为什么递推更受推荐？ 以斐波那契为例，算 f(40)：
递推只要从第 1 项加到第 40 项，算 40 次；
递归会让 f(38) 被算两遍、f(37) 被算三遍…… 总次数是天文数字（指数级增长），程序直接卡死。
所以：能写成递推的，就别用递归。

2　递推的三要素

Three Elements

2.1 初始值、公式、次数

递推的三要素： ① 初始值——链条的第一环（或前几环）是什么。
② 递推式——后一项怎么由前一项（或前几项）算出来。
③ 推进次数——要往前推多少步。
三个缺一不可：少了初始值算不出起点，少了公式推不动，少了次数不知道该推多远。

2.2 万能模板

递推的通用写法 C++ 
// 第 ① 步：设好初始值
数据类型 a = 初始值;

// 第 ② ③ 步：循环推进
for (int i = 起点; i <= 终点; i++) {
    a = 由 a 算出的新值;      // 套用递推式
}

// 最后输出 a
注意　 当递推式用到"前两项"时，就得同时保存两个变量——这就是下面要讲的"滚动变量"
打个比方： 递推就像沿着一条链子往下传——每一环都是从上一环推出来的。
写好递推，只要回答三个问题：
① 链条的第一环是什么？（初始值）
② 后一环怎么从上一环算出来？（递推式）
③ 要往前推多少次？（次数）
三个问题答清楚了，循环就写出来了。

3　三个经典递推

Classic Examples

3.1 斐波那契数列

兔子数列：1 1 2 3 5 8 13 … C++ 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    long long a = 1, b = 1;           // 初始值：前两项都是 1

    for (int i = 3; i <= n; i++) {    // 从第 3 项推到第 n 项
        long long c = a + b;          // 递推式：后一项 = 前两项之和
        a = b;                        // 往前滚一格
        b = c;                        // 往前滚一格
    }

    cout << b << endl;                // n = 7 时输出 13
    return 0;
}
n = 7 时 OUTPUT　13
为什么用 long long？　斐波那契长得很快，第 47 项就超过 int 的范围了

3.2 阶乘与爬楼梯

另外两个常见递推 C++ 
// 【阶乘】n! = 1 × 2 × 3 × … × n
long long f = 1;              // ★ 累乘的初始值必须是 1
for (int i = 1; i <= n; i++) {
    f *= i;
}
cout << f << endl;            // n = 4 时输出 24

// 【爬楼梯】一次迈 1 级或 2 级，走到第 n 级有多少种走法
//   走到第 n 级的走法 = 走到第 n-1 级的走法 + 走到第 n-2 级的走法
//   因为最后一步要么从 n-1 跨 1 级，要么从 n-2 跨 2 级
int f1 = 1, f2 = 2;           // 走到第 1 级有 1 种，第 2 级有 2 种
for (int i = 3; i <= n; i++) {
    int c = f1 + f2;
    f1 = f2;
    f2 = c;
}
cout << f2 << endl;           // n = 4 时输出 5
两个要点　 ① 累乘的初始值是 1，不是 0；
② 爬楼梯的递推式和斐波那契长得一样——因为"最后一步从哪来"正好分两种情况
乘法的初始值必须是 1，不能是 0。 累加的初始值是 0——因为"什么都不加"就是 0；
累乘的初始值必须是 1——因为"什么都不乘"应该保持原样，而乘 0 会把一切变成 0。
初始值写错，结果一定是错的——这是递推题最常见的丢分点。

4　递推的两种存法

Storing the Values

4.1 用数组全部存下来

每一项都留着，方便回头查 C++ 
long long f[100] = {0, 1, 1};        // f[1] = 1, f[2] = 1

for (int i = 3; i <= n; i++) {
    f[i] = f[i-1] + f[i-2];          // 套递推式
}

cout << f[n] << endl;

// ★ 好处：任何一项都还留着，随时能查
//   比如题目还要问"哪一项第一次超过 1000"，
//   用数组就不用重新算一遍
适合　后面还要回头用到前面某一项的情况

4.2 滚动变量：只留最近两项

只留最近两项，省空间 C++ 
// 【数组法】开 n+1 个格子
long long f[1005];
// 第 n 项用完，前面 n 个格子都白开了

// 【滚动法】只开 2 个变量
long long a = 1, b = 1;
for (int i = 3; i <= n; i++) {
    long long c = a + b;
    a = b;
    b = c;
}
// 不管 n 多大，永远只占两个格子
两种方法结果完全一样，区别只在空间—— 滚动法把空间从 O(n) 降到 O(1)
方法优点缺点
数组法每一项都留着，随时能回头查占的空间和 n 成正比
滚动变量法永远只占几个变量，省空间只能拿到最后那几项，前面的丢了
怎么选？ 题目只要"最后一项" → 用滚动变量。
题目还要"回头查某一项"或"输出整个数列" → 用数组。
拿不准就用数组——多占点空间没关系，考试里一般够用。

驯鹿苏醒

进入关卡 →
故事：盲人牧民 Merek 守在围栏边，天亮了，他要把驯鹿一只只叫醒。
可他看不见——哪只醒着、哪只还睡着，得靠你记下来告诉他。
戈登递来一块石板：先一笔一笔把状态记上，再照着石板念。

思路：把每只鹿的状态写进一个数组：先算好"第 i 只怎么样"，存进第 i 格； 后面下指令时直接读第 i 格。每一步都基于上一步已经算好的结果， 这正是递推的雏形——用一张表，把中间结果一路推下去。

重点示例：用数组记录状态，再照着表下指令 C++ 
vector<string> deerStatus;                 // ① 先准备一块"石板"

for (int i = 0; i < deer.size(); i++) {
    if (deer[i].pos.y > 30)
        deerStatus.push_back("awake");          // 不在围栏里 → 醒着
    else
        deerStatus.push_back("asleep");         // 在围栏里 → 睡着
}

for (int i = 0; i < deerStatus.size(); i++) {   // ② 再照着石板逐个念
    if (deerStatus[i] == "asleep" && deer[i].pos.y < 30)
        hero.say("asleep");
}
要点　先存后读：状态只算一次，后面直接查表，不用重算
和本单元的关系： 递推的关键就是"把上一步的结果存下来，下一步直接用"。
这里存的是每只鹿的状态；a[i] 由 a[i-1] 推出来的题目， 存的就是数值。有了这块"石板"，重复的判断就不用做第二遍。

6　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
递推题的错，几乎全在"初始值"和"边界"上。四条。
1
累乘的初始值写成了 0。
扣哒鸭：求阶乘时写 f = 0;—— 第一轮 f *= 1 就变成 0，之后怎么乘都是 0。
累乘必须从 1 开始。
记牢：累加初始值 0，累乘初始值 1
2
滚动变量的赋值顺序写反了。
扣哒鸭：正确顺序是 c = a + b; a = b; b = c;
要是先写 a = b; 再写 c = a + b;， 那 a 已经被覆盖了，算出来的就全错了。
正确顺序：先算出 c，再滚动 a，最后滚动 b
3
忘了处理 n 很小的情况。
扣哒鸭：求斐波那契时，循环写的是 i = 3; i <= n。
如果 n = 1 或 n = 2，循环一次都不跑，直接输出初始值才是对的。
加一句 if (n <= 2) { 输出 1; return 0; } 就稳了。
检查：拿 n = 1、n = 2 各试一遍
4
用 int 存斐波那契，结果溢出。
扣哒鸭：斐波那契长得极快——第 47 项就超过 int 的上限（约 21 亿）了。
int 装不下就会"回绕"成负数。
这种题一律用 long long。
养成习惯：数列递推题优先用 long long

7　题目练习

改编自 2026 年 9 月 · C++ 四级 · 判断题 第 7 题判断题
下面的递推程序用循环计算阶乘，当 n = 4 时返回值为 24。（　　）
int factorial(int n) {
    int result = 1;
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
}
查看答案与详解
答案：正确（√）。手算一遍就清楚了：
初值：result = 1　← 累乘必须从 1 开始，这步是对的
i = 1：result = 1 × 1 = 1
i = 2：result = 1 × 2 = 2
i = 3：result = 2 × 3 = 6
i = 4：result = 6 × 4 = 24
i = 5 时不满足 i <= 4，循环结束，返回 24 ✔
三个检查点： ① 初值是不是 1？② 循环是 i <= n 还是 i < n？ ③ 用的是 *= 还是 +=？
顺便提醒：阶乘增长很快，13! 就超过 int 范围了， 实际写程序建议用 long long。
对应小节3.2 阶乘与爬楼梯。
改编自 2026 年 9 月 · C++ 四级 · 编程题 1编程题
新汉诺塔：有三根柱子，开始时 1 号柱上套着 n 个圆盘（从上到下由小到大）。 要求把 n 个圆盘全部移到 3 号柱上，规则是：
① 每次只能移动一个圆盘，且只能从柱顶取出、放到另一根柱顶；
② 小圆盘必须时刻在大圆盘之上；
③ 每一次移动，圆盘只能从 1 到 2、从 2 到 3、或者从 2 到 1、从 3 到 2 （也就是不能直接从 1 到 3，也不能直接从 3 到 1）。
求最少移动次数。
样例：n = 1 时输出 2；n = 2 时输出 7。
查看参考答案与要点 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    // 递推思路：
    //   把最大盘从 1 移到 3，必须先把它从 1 移到 2，再从 2 移到 3
    //   而每次移动最大盘之前，上面 n-1 个盘必须先全部移到同一根柱上
    //
    //   设 f(n) = 移动 n 个盘所需的最少步数，可以推出：
    //   f(n) = 3 * f(n-1) + 2
    //   初始值：f(1) = 2（1→2，2→3）

    long long f = 2;                 // f(1) = 2
    for (int i = 2; i <= n; i++) {
        f = 3 * f + 2;               // 套递推式
    }

    cout << f << endl;
    return 0;
}

验算：f(1) = 2；f(2) = 3×2 + 2 = 7 ✔（与样例一致）
f(3) = 3×7 + 2 = 23；f(4) = 3×23 + 2 = 71（与试卷给出的 71 一致）
要点：
① 递推题的核心永远是"找规律"—— 先手算 n = 1、2、3 的结果，再看它们之间的关系；
② 本题的规律：要把最大盘从 1 挪到 3， 得先把它从 1 挪到 2（此时上面 n−1 个盘都在 3），再把它从 2 挪到 3（此时 n−1 个盘都在 1）—— 所以 f(n) = 3 × f(n−1) + 2；
③ 初始值 f(1) = 2（1→2、2→3），不是经典汉诺塔的 1； 这是因为本题加了"不能直接 1→3"的限制；
④ 结果增长极快（3 的 n 次方级别），必须用 long long。
对应小节2.1 初始值、公式、次数。

原创练习题单选题
执行下面的代码，输出是（　　）。
int a = 1, b = 2;
for (int i = 1; i <= 3; i++) {
    int c = a + b;
    a = b;
    b = c;
}
cout << b << endl;
A.5　　B.8　　C.13　　D.21
查看答案与详解
答案：B。老老实实地一步步跟着走（这是做递推题最稳的办法）：
初始：a = 1，b = 2
i = 1：c = 1 + 2 = 3　→　a = 2，b = 3
i = 2：c = 2 + 3 = 5　→　a = 3，b = 5
i = 3：c = 3 + 5 = 8　→　a = 5，b = 8
循环一共执行 3 次（i = 1、2、3），结束后输出 b = 8。
易错项 A（5）是少循环了一次的结果。
这题的学习价值：递推题千万不要"心算跳步"， 一定要像上面这样把每一步的 a、b 列成表格。一旦跳过一步，后面的就全错了。
手算列表是递推题唯一可靠的验证手段，务必养成习惯。
对应小节4.2 滚动变量：只留最近两项。
原创练习题判断题
递推和递归是一回事，只是写法不同。（　　）
查看答案与详解
答案：错误（×）。它们虽然常常描述同一个数学关系（同一个递推式）， 但实现方式完全不同：
递推——用循环，从前往后推；每一项只算一次，效率高。
递归——函数自己调用自己，从后往前拆； 同样的子问题会被重复计算很多遍，效率低， 而且层数太深还有"栈溢出"的风险。
举个直观的例子：算斐波那契第 40 项，递推算 40 次就完了； 递归的调用次数是指数级的，程序会直接卡死。
所以结论是：能写成递推就别用递归。
对应小节1.2 递推与递归的区别。
原创练习题编程题
题目要求：一个数列的前两项是 1 和 3， 从第三项起，每一项等于前两项之和。 读入 n，输出这个数列的第 n 项。
查看参考答案与要点 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    if (n == 1) { cout << 1 << endl; return 0; }   // ★ 前两项单独处理
    if (n == 2) { cout << 3 << endl; return 0; }

    long long a = 1, b = 3;          // 初始值：第 1、2 项
    for (int i = 3; i <= n; i++) {
        long long c = a + b;         // 递推式
        a = b;
        b = c;
    }

    cout << b << endl;
    return 0;
}

数列：1、3、4、7、11、18、29、47……
输入 6 输出：18；输入 1 输出：1
要点：
① 递推式没变（还是"前两项之和"），变的只是初始值—— 这就是为什么"初始值"必须单独强调：同一个公式配不同初始值，就是完全不同的数列；
② n = 1、n = 2 必须单独处理， 否则循环不跑、输出的就是初始的 b（等于 3），而 n = 1 时答案应该是 1；
③ 这里用滚动变量法的顺序仍然是 "先算 c，再滚 a，最后滚 b"——顺序不能乱；
④ 用 long long 防止后面项超出 int。
对应小节2.1 初始值、公式、次数。

四句话记住递推：
一、递推就是"后面的值由前面的值算出来"，用循环从前往后推。
二、三要素：初始值、递推式、推进次数——三个缺一不可。
三、累加初值取 0，累乘初值取 1；数列题一律上 long long。
四、只要最后一项就用滚动变量；要回头查前面的项就用数组。
链条转起来了。下一站是队列整编台——那里有一群高矮不齐的石头人，等着被排成整齐的一列。

你在齿轮传动链前收获了什么

  • 递推——后面的值由前面的值算出来；用循环从前往后推。
  • 递推三要素——初始值、递推式、推进次数。
  • 递推 vs 递归——递推用循环、效率高；递归自己调自己、会重复计算、可能栈溢出。
  • 斐波那契——f(n) = f(n−1) + f(n−2)，初始值 1、1。
  • 阶乘——f(n) = f(n−1) × n，初始值必须是 1。
  • 爬楼梯——递推式和斐波那契一样，因为"最后一步"正好分两种情况。
  • 累加 vs 累乘的初值——累加取 0，累乘取 1。
  • 滚动变量——c = a + b; a = b; b = c;，三步顺序不能乱。
  • 数组法 vs 滚动法——数组能回头查、占空间；滚动省空间、只能拿到最后几项。
  • 边界——n 很小时循环可能一次都不跑，前两项要单独处理。
  • 数据类型——递推题结果增长快，优先用 long long。
  • 验证方法——把每一步的值列成表，是没有比这更可靠的检查手段了。
