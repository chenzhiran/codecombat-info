1　字符串也是一种"序列"

Strings Are Sequences

1.1 字符串是"装着字符的列表"

先看这张对比表——把字符串当成"装着字符的列表"，一切就顺了。

操作列表 [1, 2, 3]字符串 "abc"一样吗
求长度len(a)len(s)✅ 一样
按下标取a[0]s[0]✅ 一样
切片a[1:3]s[1:3]✅ 一样
遍历for x in afor ch in s✅ 一样
判断包含x in a"b" in s✅ 一样
修改某个元素a[0] = 9s[0] = "x"❌ 不一样！字符串不行

1.2 一句话记住它

打个比方： 字符串就像一串串起来的珠子——每颗珠子是一个字符，整串按顺序排好。
你可以数第几颗是什么（下标访问），也可以从头到尾摸一遍（遍历）；
但你不能把中间那颗珠子偷偷换掉——只能重新串一串新的（这就是"不可变"）。
一句话： 字符串和列表都是"序列"，下标、切片、遍历、len、in 这些通用操作都能用。
唯一的区别是——列表能改，字符串不能改。

2　访问与遍历

Access & Traverse

2.1 访问与切片

下标、切片与遍历 Python 
s = "Kithgard"

print(s[0])       # 第 1 个字符：'K'

for ch in s:      # 逐字遍历

2.2 两个偷懒写法

两个偷懒写法： s[4:] 表示"从下标 4 一直取到结尾"； s[:4] 表示"从头取到下标 3"。
省略的一边，就是"一直取到头/尾"。

3　字符串不可变

Immutability

3.1 字符串不可变

这是字符串最容易踩的一个坑：你没法直接改它里面的某个字符。

错误的改法与正确的改法 Python 
s = "Kith"
s[0] = "B"          # ✘ 报错：TypeError，字符串不支持赋值

# 正确做法一：重新拼一个新的字符串
s = "B" + s[1:]
print(s)            # Bith

# 正确做法二：用 replace 生成新字符串
s2 = "Kith".replace("K", "B")
print(s2)           # Bith
要点　不是"改了原字符串"，而是"造了一个新的字符串"

3.2 为什么不让改

打个比方： 字符串像已经刻好的石碑——刻上去就改不动了。
想改一个字？不能拿凿子去抠那一笔，只能另刻一块新碑。
所以"修改字符串"其实是"造了一个新字符串"，原来那个还在原地没动。
为什么不让改？ 可以把字符串理解成石碑上刻好的字——刻上去就固定了。 想改？只能另刻一块新的。
好处是安全：程序里到处传来传去的字符串，谁都没法偷偷改动它。
艾达 · 冰霜法师
我写药方有个规矩：写错的方子绝不涂改，直接重抄一张。
一来不会把关键的字蹭花，二来每一张方子都能追查来源。
字符串就是这么"较真"的东西——它不许你涂改，只许你重写。

5　切分与拼接

Split & Join

5.1 split 把一句话拆开

这两个方法是一对儿：split 把一句话拆成列表，join 把列表拼回一句话。

切分与拼接 Python 
s = "苹果 香蕉 橘子"

parts = s.split()          # 按空格切成列表
print(parts)               # ['苹果', '香蕉', '橘子']
print(len(parts))          # 3 段

# 按指定符号切
d = "2026-10-04"
print(d.split("-"))        # ['2026', '10', '04']

# 反过来：把列表拼成字符串
fruits = ["苹果", "香蕉", "橘子"]
print("、".join(fruits))    # 苹果、香蕉、橘子
print(",".join(fruits))     # 苹果,香蕉,橘子
OUTPUT　['苹果', '香蕉', '橘子']
3
['2026', '10', '04']
苹果、香蕉、橘子
苹果,香蕉,橘子

5.2 谁在调用谁

谁在调用谁？ 注意 "-".join(...)：分隔符写在前面，列表写在括号里。
念法是："用 - 去连接这个列表"。
别写成 fruits.join("-")，那是错的。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
字符串的坑大多是"想当然"造成的。四条，条条都值得抄在本子上。
1
想直接改字符串里的字符。写 s[0] = "A"。
扣哒鸭：字符串是不可变的，改不了。
要改就重新拼一个：s = "A" + s[1:]，或者用 s.replace("K", "A") 生成新的。
正确做法：用切片拼接或 replace 生成新字符串
2
以为 upper() 会改掉原字符串。
扣哒鸭：所有字符串方法都返回新字符串，不动原来的。
写 s.upper() 之后 s 没变——要留下结果就得 s = s.upper()。
正确写法：s = s.upper()
3
把 join 的方向写反。写成 列表.join("分隔符")。
扣哒鸭：分隔符在前、列表在后："-".join(列表)。
念一遍就不容易错了："用减号去连接这个列表"。
正确写法："-".join(["红","绿","蓝"])
4
把数字字符串当数字算。写 "5" + 5。
扣哒鸭：带引号就是字，不是数。 "5" + 5 会直接报 TypeError。
要用 int("5") + 5 先转成数字。 另外 "5" + "5" 得到的是 "55"，不是 10。
正确写法：先转换类型，再运算

第 1 题改编自 2026 年 9 月 · Python 三级 第 14 题，其余为原创练习题。

改编自 2026 年 9 月 · Python 三级 · 第 14 题单选题
下面这段 Python 代码的功能是（　　）。
1  s = input("请输入字符串：")
2  words = s.split()
3  longest_word = ""
4  for word in words:
5      if len(word) > len(longest_word):
6          longest_word = word
7  print(longest_word)
A.找出字符串中出现次数最多的单词
B.找出字符串中长度最大的单词，若有多个则全部输出
C.找出字符串中最后一个出现的长度最大的单词
D.找出字符串中第一个出现的长度最大的单词
查看答案与详解
答案：D。s.split() 按空白把字符串切成单词列表；循环里只保留"当前最长的那个"。
关键在判断用的是 > 而不是 >=：
遇到一样长的单词时，条件不成立、longest_word 不会更新 ——所以留下来的是第一个最长的单词。
如果改成 len(word) >= len(longest_word)，就会保留最后一个最长的单词。
学会这一招：看到"求最值"的循环，先看比较用的是 > 还是 >=，它决定了"并列时取哪一个"。

原创练习题编程题
题目要求：输入一行用空格分隔的单词，输出： ① 一共有几个单词；② 全部转成大写后的整句话（单词之间用一个空格分隔）。
查看参考答案与要点 
s = input("请输入一行单词：")

words = s.split()             # 按空格切分成列表

print(len(words))             # ① 单词个数

# ② 每个单词转大写，再用空格拼回一句话
big = []
for w in words:
    big.append(w.upper())

print(" ".join(big))

运行示例：输入 hello kith gard → 输出 3 和 HELLO KITH GARD。

① split() 不写参数时默认按空白（空格、制表符）切分；
② upper() 返回新字符串，必须接住结果；
③ 拼接时 " ".join(...) 的分隔符是空格，列表写在括号里。

9　本单元小结

Unit Summary
贺舒曼 · 镜中先知
三句话收尾：
一、字符串和列表一样能下标、切片、遍历、求长度——但它不能改。
二、所有字符串方法都返回新字符串，原字符串纹丝不动。
三、split 拆成列表，join 拼回字符串；分隔符永远写在前面。
记住这些，剩下的就是多练几道题的事。

你在石碑前收获了什么

  • 字符串是序列——和列表一样支持 len / 下标 / 切片 / 遍历 / in。
  • 下标与切片——下标从 0 开始；切片含头不含尾；s[:4]、s[4:] 是偷懒写法。
  • 不可变性——不能 s[0] = "x"，只能重新拼接或 replace。
  • 大小写——upper() 转大写，lower() 转小写。
  • 清理与查找——strip() 去首尾空白，find() 找位置（找不到返回 -1），count() 数次数。
  • 切分与拼接——s.split() 得到列表；分隔符.join(列表) 得到字符串。
  • 方法链——s.strip().upper() 可以从左往右连着调用。
