1　为什么需要结构体

Why struct

1.1 一堆散着的数据

不用结构体：一个学生要写四行 C++ 
// 记录一个学生的信息
string name = "小明";
int    age  = 12;
double score = 95.5;
char   grade = 'A';

// 问题一：这些数据是"一个人的"，但看起来毫无关系
// 问题二：如果有 50 个学生呢？
//        name1, age1, score1, grade1,
//        name2, age2, score2, grade2, …… 噩梦
两个痛点　① 数据散着，看不出它们属于同一个人； ② 一变多就没法用循环管理

1.2 结构体是什么

用结构体：打包成一个整体 C++ 
struct Student {          // 定义一种"新类型"
    string name;          // 成员一：名字
    int    age;           // 成员二：年龄
    double score;         // 成员三：成绩
    char   grade;         // 成员四：等级
};

Student s;                // ★ 用这个新类型声明一个变量
s.name  = "小明";          // 用点号访问成员
s.age   = 12;
s.score = 95.5;
s.grade = 'A';

cout << s.name << " " << s.age << endl;    // 小明 12
OUTPUT　小明 12
关键　Student 现在成了一个像 int 一样可以用的类型名—— 只不过它装的是"一小捆"数据
打个比方： 数组像一整排同样的抽屉——每格只能放同一种东西。
结构体像一个多层的便当盒——每一层可以放不同菜，但它们属于同一份饭。
把"总是一起出现的数据"打包在一起，就是结构体存在的全部理由。
结构体 vs 数组： 数组——类型相同的一串元素，用下标区分。
结构体——类型可以不同的一组数据，用成员名区分。
两者还能结合：结构体数组，就是"每个元素都是一个结构体"的数组。

2　定义与使用

Defining

2.1 定义结构体

定义的写法：struct 名字 { 成员列表 }; C++ 
struct Point {          // struct 关键字 + 类型名
    int x;              // 成员，各自声明类型
    int y;
};                      // ★ 这个分号千万别丢！

struct Student {
    string name;
    int    age;
    double score;
};
三条格式要求　 ① 用 struct 开头；② 成员写在大括号里，每个成员自己带类型； ③ 右大括号后面必须有分号
最容易忘的一件事：右大括号后面的分号。 struct Point { int x; int y; } —— 少了一个 ;， 编译直接报错。
为什么？因为结构体定义本质上是一条完整的"声明语句"， 和 int a = 5; 一样，语句结束就得有分号。
写结构体时请养成习惯：写完 }; 再敲下一行。

2.2 声明变量与初始化

三种初始化方式 C++ 
struct Point { int x; int y; };

// ① 先声明，再逐个赋值
Point p1;
p1.x = 3;
p1.y = 4;

// ② 花括号列表初始化（按成员顺序）
Point p2 = {3, 4};

// ③ 花括号 + 指定成员名（C++20 起）
Point p3{ .x = 3, .y = 4 };

// ④ 定义结构体的同时就声明变量
struct Node { int v; } a, b;      // a 和 b 都是 Node 类型

cout << p2.x << " " << p2.y << endl;    // 3 4
OUTPUT　3 4
注意　Point p2 = {3, 4}; 是按成员声明的顺序依次填入—— 先 x 后 y，顺序不能想当然

3　访问成员

Member Access

3.1 点号运算符

用 . 取成员 C++ 
struct Point { int x; int y; };
Point p = {3, 4};

cout << p.x << endl;        // 3
cout << p.y << endl;        // 4

p.x = 10;                   // 修改成员
cout << p.x << endl;        // 10

p.x++;                      // 成员也能自增
cout << p.x + p.y << endl;  // 15
读法　p.x 读作 "p 的 x 成员"
点号前面是结构体变量，后面是成员名
打点号，就是"从这个盒子里取这一格"。 s.name → 小明；s.age → 12； s.score → 95.5。
把结构体变量当成一个"套娃"，点号就是往里钻一层的钥匙。

3.2 结构体数组

最常用的组合：结构体 + 数组 C++ 
struct Student {
    string name;
    int    age;
    double score;
};

Student s[3] = {
    {"小明", 12, 95.5},
    {"小红", 13, 88.0},
    {"小刚", 12, 91.5}
};

// 用循环遍历 —— 这就是结构体最大的价值
for (int i = 0; i < 3; i++) {
    cout << s[i].name << " " << s[i].score << endl;
}

// 找出成绩最高的
int best = 0;
for (int i = 1; i < 3; i++) {
    if (s[i].score > s[best].score) best = i;
}
cout << s[best].name << endl;      // 小明
OUTPUT　小明 95.5 / 小红 88 / 小刚 91.5 / 小明
注意写法　s[i].name——先用下标取出第 i 个结构体，再用点号取它的成员
结构体数组怎么读： s[i].name 的读法分两步：
第一步：s[i]——取出第 i 个学生（一个完整的结构体）。
第二步：.name——取这个学生的 name 成员。
顺序是"先下标、后点号"，两个符号分工很明确。

4　结构体与指针

struct & Pointers

4.1 指向结构体的指针

上一单元的指针，也能指向结构体 C++ 
struct Point { int x; int y; };
Point p = {3, 4};

Point *q = &p;              // q 是指向 Point 的指针

cout << (*q).x << endl;     // 3   ← 先解引用，再取成员
cout << q->x << endl;       // 3   ★ 这是更常用的写法
cout << q->y << endl;       // 4

q->x = 100;                 // 通过指针改成员
cout << p.x << endl;        // 100  ← p 也变了
两种写法等价　(*q).x ≡ q->x
原因　(*q) 就是 p 本身，所以 (*q).x 就是 p.x， 而 -> 是专门为这种情况设计的简写

4.2 箭头运算符 ->

写法用在哪例子
.（点号）结构体变量本身p.x
->（箭头）指向结构体的指针q->x
(*q).x先解引用再取成员和 q->x 等价
为什么要有 -> 这个符号？ 因为 *q.x 是错的——点号的优先级比 * 高， 它会被理解成 *(q.x)，也就是"先取 q 的 x 成员、再解引用"， 可 q 是个指针，根本没有 x 成员。
所以要写成 (*q).x——加括号才正确。
但括号写起来太啰嗦，于是 C++ 干脆提供了 ->： q->x 就是 (*q).x 的简写。
一句话记住： 变量用点号，指针用箭头。
p.x（p 是变量）　q->x（q 是指针）
拿不准？就看点号左边那个东西，是不是带 * 定义出来的。

5　常见用法

Common Patterns

5.1 比较与排序

按某个字段比较 C++ 
struct Student {
    string name;
    int    score;
};

Student s[3] = {{"小明", 95}, {"小红", 88}, {"小刚", 91}};

// 按成绩从高到低排序（选择排序的思想）
for (int i = 0; i < 3; i++) {
    int mx = i;
    for (int j = i + 1; j < 3; j++) {
        if (s[j].score > s[mx].score) mx = j;    // ★ 比的是 score
    }
    if (mx != i) {
        Student t = s[i];        // ★ 整个结构体一起交换
        s[i] = s[mx];
        s[mx] = t;
    }
}

// 输出：小明 95 / 小刚 91 / 小红 88
关键　比较时只挑那个要排序的字段（这里是 score）； 但交换时要把整个结构体一起换——不能只换成绩，否则名字和成绩就对不上了

5.2 嵌套与组合

结构体里还可以放结构体 C++ 
struct Point { int x; int y; };

struct Rectangle {
    Point leftTop;        // ★ 成员本身也是结构体
    Point rightBottom;
    string name;
};

Rectangle r;
r.name = "护板";
r.leftTop.x = 0;
r.leftTop.y = 0;
r.rightBottom.x = 10;
r.rightBottom.y = 5;

cout << r.leftTop.x << endl;      // 0
// 读法：r 的 leftTop 的 x —— 一层一层用点号往里钻
读法　r.leftTop.x 就是"r → leftTop → x"， 像剥洋葱一样一层层剥进去
结构体最实用的三个场景： ① 描述一个"有多重属性"的对象——学生、点、货物、玩家。
② 配合数组批量管理——Student s[100]; 一下管住一百个学生。
③ 按某个字段排序 / 查找——交换时整个结构体一起换。
凡是你觉得"这几个变量总是一起出现"，那就该考虑用结构体把它们打包。

哈利把簿子推给你：这些数据总是一起用——报价的时候三样都得看， 少一样就算不出来。

聪明。他敲了敲台面，凡是"总是一起出现"的东西，就该打包成一个整体。

思路：用结构体表示一笔订单， 再用结构体数组存下所有订单，最后遍历求和。

结构体数组：读入、遍历、统计 C++ 
#include <iostream>
#include <string>
using namespace std;

struct Order {
    string name;        // 零件名
    int    count;       // 数量
    double price;       // 单价
};

Order ord[105];         // 结构体数组

int main() {
    int n;
    cin >> n;

    for (int i = 0; i < n; i++) {
        cin >> ord[i].name
            >> ord[i].count
            >> ord[i].price;
    }

    double total = 0;
    for (int i = 0; i < n; i++) {
        total += ord[i].count * ord[i].price;   // 每一笔的金额
    }

    cout << total << endl;
    return 0;
}
输入　2　/　齿轮 3 12.5　/　弹簧 5 2.0　　输出　47.5
验算　3 × 12.5 + 5 × 2.0 = 37.5 + 10 = 47.5 ✔
和本单元的关系： "结构体数组 + 循环"是最典型的用法。
读入时 ord[i].name、ord[i].count、ord[i].price ——先取下标的那个结构体，再点出里面的成员。
如果没有结构体，你就得开三个数组来存这三样，还要自己保证"下标对得上"—— 一旦某个数组漏读一项，数据就全错位了。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
结构体的错基本都出在"符号"上：忘了分号、用错了点号。四条。
1
结构体定义末尾忘了分号。
扣哒鸭：struct Point { int x; int y; } 后面那个 ; 必须有。
结构体定义是一条完整的语句，语句结束就该有分号——和 int a = 5; 一个道理。
正确写法：struct Point { int x; int y; };
2
把结构体数组的成员写法搞错了。
扣哒鸭：是 s[i].name，不是 s.name[i]。
先用下标取出第 i 个结构体，再用点号取成员——顺序反了意思就全变了。
口诀：先下标、后点号
3
指针用点号，或者写成 *q.x。
扣哒鸭：*q.x 会被理解成 *(q.x)—— 而 q 是个指针，压根没有 x 成员。
正确写法是 (*q).x，或者更省事地写 q->x。
记牢：变量用 .，指针用 ->
4
排序时只交换了某个字段。
扣哒鸭：按成绩排序时，比较的是 score，但交换的必须是整个结构体。
只换成绩的话，名字还留在原位——分数和名字就对不上了。
正确做法：Student t = s[i]; s[i] = s[j]; s[j] = t;

前 2 题改编自 C++ 四级真题，其余为原创练习题。

改编自 2026 年 9 月 · C++ 四级 · 判断题 第 5 题判断题
下面的结构体初始化语句是合法的。（　　）
struct Point { int x; int y; };
Point p{3, 4};
查看答案与详解
答案：正确（√）。这是 C++11 引入的列表初始化（brace initialization）， 可以直接在声明时按成员声明的顺序填入初值。
Point p{3, 4}; 等价于 Point p = {3, 4};—— x 得 3、y 得 4。
这种写法的好处：把"裸的数值"只写在初始化的地方， 不用先声明再逐行赋值，代码更紧凑。
注意两点：
① 初值的顺序必须和成员声明的顺序一致——先 x 后 y；
② 花括号里不能随意加多余的项， 写多了编译器会报"初始化值太多"。
对应小节2.2 声明变量与初始化。
改编自 2026 年 6 月 · C++ 四级 · 判断题 第 2 题判断题
一个函数必须在被调用之前既声明又定义。（　　）
查看答案与详解
答案：错误（×）。C++ 的要求是：函数必须在调用之前"被声明"， 但不一定"被定义"。
声明就是告诉编译器"有这么个函数，参数和返回值长这样"：
int add(int a, int b);　← 这叫函数声明（原型）
定义则是把函数体也写出来。既然"声明 + 定义"合在一起已经满足了"先声明"，当然更没问题。
但反过来，只要在调用前有声明就够了——函数体可以写在文件的后面。
实际开发中常见的写法：把所有函数声明集中在文件开头， 定义分散在后面，这样函数之间互相调用就不用操心顺序了。
对应小节3 之外的函数基础（下一单元会重点讲）。
原创练习题单选题
执行下面的代码，输出是（　　）。
struct Point { int x; int y; };
Point p = {3, 4};
Point *q = &p;
q->x += 10;
cout << p.x << " " << p.y << endl;
A.3 4　　B.13 4　　C.13 14　　D.编译错误
查看答案与详解
答案：B。分三步看：
① Point p = {3, 4}; —— p 的 x 是 3、y 是 4。
② Point *q = &p; —— q 指向 p， 此后 q->x 和 p.x 说的是同一个东西。
③ q->x += 10; —— 等价于 p.x += 10， 所以 p.x 变成 13；而 y 从头到尾没被碰过，还是 4。
输出 13 4。
关键理解：q->x 就是 (*q).x， 而 *q 就是 p 本身——所以改它等于改 p。
C 项是误以为两个成员都会受影响。
对应小节4.2 箭头运算符 ->。
原创练习题判断题
结构体和数组一样，里面所有元素的类型必须相同。（　　）
查看答案与详解
答案：错误（×）。这正好是两者最本质的区别：
数组——所有元素必须是同一类型，用下标区分。
结构体——各个成员类型可以完全不同，用成员名区分。
举个例子：struct Student { string name; int age; double score; }; ——一个 string、一个 int、一个 double，三种类型共存，完全合法。
可以这么记：数组是"一排同样的抽屉"，结构体是"一个多层的便当盒"—— 便当盒每一层可以放不同的菜。
对应小节1.2 结构体是什么。
原创练习题编程题
题目要求：读入 n 个学生的姓名和三门课成绩， 按总分从高到低输出姓名和总分。（总分相同时，按输入顺序输出。）
样例：输入 2 / 小明 90 85 95 / 小红 88 92 90， 输出 小明 270 / 小红 270。
查看参考答案与要点 
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int sum;            // 直接存总分，省得反复算
};

Student s[105];

int main() {
    int n;
    cin >> n;

    for (int i = 0; i < n; i++) {
        int a, b, c;
        cin >> s[i].name >> a >> b >> c;
        s[i].sum = a + b + c;               // 读进来就算好总分
    }

    // 选择排序：按总分从高到低
    for (int i = 0; i < n; i++) {
        int mx = i;
        for (int j = i + 1; j < n; j++) {
            if (s[j].sum > s[mx].sum) mx = j;   // ★ 严格大于 → 稳定
        }
        if (mx != i) {
            Student t = s[i];               // ★ 整个结构体一起换
            s[i] = s[mx];
            s[mx] = t;
        }
    }

    for (int i = 0; i < n; i++) {
        cout << s[i].name << " " << s[i].sum << endl;
    }
    return 0;
}

要点：
① 总分在读入时就算好存进结构体，后面比较时就不用反复相加；
② 排序时比较的是 s[j].sum，但交换的是整个 Student—— 这样才能保证"名字和总分"始终绑在一起；
③ 用严格大于 >，是为了让"总分相同"时不交换， 从而保持输入顺序（这就是"稳定"）；
④ 用临时变量 Student t 做交换， 结构体也能像基本类型一样整体赋值——这是结构体的一个便利之处。
对应小节5.1 比较与排序。

9　本单元小结

Unit Summary
哈利 · 铁匠
四句话记住结构体：
一、结构体把"类型不同的几个数据"打包成一个整体，用成员名区分，不用下标。
二、定义写 struct 名字 { 成员列表 };——末尾那个分号千万别丢。
三、变量用点号 .，指针用箭头 ->；结构体数组写 s[i].name。
四、排序时"比的是某个字段，换的是整个结构体"。
零件装好了。下一站是模块化车间——那里要把"重复的活儿"装进机器里，用一次喊一次。

你在零件装配台前收获了什么

  • 结构体——把类型可以不同的一组数据打包成一个整体，用成员名区分。
  • 与数组的区别——数组要求元素类型相同，用下标区分；结构体成员类型可不同。
  • 定义——struct 名字 { 成员列表 };，右大括号后必须有分号。
  • 初始化——Point p = {3, 4}; 按成员声明顺序填入。
  • 访问成员——用点号：p.x。
  • 结构体数组——Student s[100];，访问写 s[i].name（先下标、后点号）。
  • 结构体指针——Point *q = &p;，用 q->x 访问成员。
  • 箭头与点号——q->x 等价于 (*q).x，不能写成 *q.x。
  • 排序——比较某个字段，交换整个结构体；用严格小于 / 大于可保持稳定。
  • 嵌套——结构体的成员也可以是结构体，用 r.leftTop.x 一层层点进去。
