1　一面刻着数字的墙

A Wall of Numbers

1.1 杨辉三角的前几层

1.2 一面刻着数字的墙

1.3 构造规则只有一条

构造规则只有一条： 每个位置的数 = 它左上角的数 + 它右上角的数（越界的地方当 0 处理）。
每一层的两端永远是 1。
而第 n 层的第 m 个数，正好就是组合数 C(n, m)。

2　每一层就是组合数

Rows Are Combinations

2.1 每一层就是组合数

层数 n这一层的数字对应的组合数
01C(0,0)
11　1C(1,0)　C(1,1)
21　2　1C(2,0)　C(2,1)　C(2,2)
31　3　3　1C(3,0)　C(3,1)　C(3,2)　C(3,3)
41　4　6　4　1C(4,0) … C(4,4)
51　5　10　10　5　1C(5,0) … C(5,5)

2.2 这条对应关系为什么成立

这条对应关系为什么成立？ 想从 n 个东西里选出 m 个，可以分两种情况讨论最后一个东西选不选：
· 不选它：要从剩下的 n-1 个里选 m 个 → C(n-1, m)
· 选它：还要从剩下的 n-1 个里再选 m-1 个 → C(n-1, m-1)
两种情况相加，就得到组合数的递推式： C(n,m) = C(n-1,m-1) + C(n-1,m)
而这正是杨辉三角的"上面两数相加"规则。

3　生成杨辉三角

Generating It

3.1 用二维列表一层层填

用二维列表一层层填（就是二维 DP） C++ 
int n = 6;
vector<vector<int>> tri(n + 1, vector<int>(n + 1, 0));

for (int i = 0; i <= n; i++) {
    tri[i][0] = 1;                // 每层第一个是 1
    tri[i][i] = 1;                // 每层最后一个是 1

    for (int j = 1; j < i; j++) {
        // 关键：左上角的数 + 右上角的数
        tri[i][j] = tri[i - 1][j - 1] + tri[i - 1][j];
    }
}

// 打印前 6 层
for (int i = 0; i <= n; i++) {
    for (int j = 0; j <= i; j++) {
        cout << tri[i][j] << " ";
    }
    cout << endl;
}
OUTPUT
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
1 5 10 10 5 1

3.2 和二维 DP 的关系

和二维 DP 的关系： 看这段代码——下标 i 是行、j 是列，转移方程来自"上一行的两个位置"。
这正是七级学的二维动态规划！
杨辉三角就是"用 DP 生成组合数表"的经典例子。公式法和填表法，两条路通向同一个答案。

4　几条重要性质

Useful Properties

4.1 对称性与行和

性质说法例子
对称性每一层左右对称C(5,1) = C(5,4) = 5
首尾为 1C(n,0) = C(n,n) = 1每层两端都是 1
每层之和第 n 层所有数之和 = 2n1+4+6+4+1 = 16 = 24
斜线和沿斜线相加会得到斐波那契数列1、1、2、3、5、8…
递推关系C(n,m) = C(n-1,m-1) + C(n-1,m)6 = 3 + 3

4.2 用程序验证这些性质

用程序验证这些性质 C++ 
// 验证"第 n 层之和 = 2 的 n 次方"
for (int i = 0; i < 6; i++) {
    int rowSum = 0;
    for (int j = 0; j <= i; j++) {
        rowSum = rowSum + tri[i][j];
    }
    cout << "第 " << i << " 层之和 = " << rowSum
         << "，2 的幂 = " << (1 << i) << endl;
}

// 验证对称性 C(n,m) = C(n,n-m)
cout << (tri[5][1] == tri[5][4]) << endl;     // 1，表示相等
为什么每层和是 2n？　从 n 个东西里任意挑选，每个东西都有"选/不选"两种可能， 所以一共 2n 种——正好等于各类"选 m 个"的数目之和

故事：食人魔巫师给你准备了一堆"惊喜"：各种类型的士兵和敌人混在一起。
指挥官说：别一股脑儿冲。先想清楚：哪种士兵该打哪个目标。
贺舒曼补了一句：这就是分类——把复杂的情况先理成几类，再分别处理。

思路：写一个函数，根据"士兵的类型"返回"他该攻击的目标"。 把判断逻辑封装成函数，主流程就清爽了。

重点示例：按类型分类处理 C++ 
Unit chooseTarget(Unit friendUnit) {
    // 根据士兵类型，返回他该打的目标
    if (friendUnit.type == "soldier") {
        return wizard;                          // 士兵去打巫师
    } else if (friendUnit.type == "archer") {
        return friendUnit.findNearestEnemy();   // 弓箭手打最近的敌人
    }
    return nullptr;
}
要点　一个函数把"分类逻辑"收拢起来；主程序只要调用它
和杨辉三角的关联： 杨辉三角的递推式 C(n,m) = C(n-1,m-1) + C(n-1,m)， 本身就是"按'选不选最后一个'分两类"推出来的。
先分类、再各自处理、最后合并结果——这个思路在计数和编程里都一样好用。

6　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
杨辉三角的代码只有几行，但边界和层数最容易写错。四条，条条都能让结果差一层。
1
内层循环范围搞错，把两端的 1 覆盖掉了。
扣哒鸭：每层两端必须固定为 1， 所以内层只填中间那些位置：
for (int j = 1; j < i; j++)—— 从 1 开始、到 i-1 结束。
写成从 j = 0 起 或 到 j <= i 止 都会出错。
正确写法：for (int j = 1; j < i; j++)
2
层数和数组大小对不上。
扣哒鸭：第 n 层有 n+1 个数， 所以想要 6 层（第 0 层到第 5 层），数组要开 6×6 而不是 6×5。
需要下标 0 到 n 时，一律开 n+1。
正确写法：vector<vector<int>> tri(n + 1, vector<int>(n + 1, 0))
3
建表时只给了行数。
扣哒鸭：vector<vector<int>> tri(n) 只会建出 n 个空行， 一写 tri[i][j] 就越界崩溃。
每一行也要给大小。
正确写法：外层给行数，内层给列数
4
以为"第 n 层之和"是 n² 或别的数。
扣哒鸭：是 2 的 n 次方。
第 0 层 1 = 2⁰；第 4 层 1+4+6+4+1 = 16 = 2⁴。
记忆法：每个东西都有"选/不选"两种可能，n 个东西就是 2ⁿ 种总的挑选方式。
正确认识：第 n 层之和 = 2n

改编自 2026 年 9 月 · C++ 八级 · 第 6 题单选题
王座回音壁上的杨辉三角按行排列，第 0 行是 1，第 1 行是 1 1，依次类推。
第 7 行第 3 个数（行、列均从 0 开始计数）是（　　）。
A.21　　B.35　　C.42　　D.56
查看答案与详解
答案：B。杨辉三角的第 n 行第 m 个数，就是组合数 C(n, m) —— 这正是本单元要记的恒等式。
所以第 7 行第 3 个数 = C(7, 3) = 7 × 6 × 5 ÷ (3 × 2 × 1) = 35。
另一条路：按"每个数等于肩上两数之和"逐行算出第 7 行：1 7 21 35 35 21 7 1，第 3 个数（从 0 数起）正是 35。
易错："第 3 个"是从 0 开始数的，对应的是 C(7, 3) 而不是 C(7, 2)。
顺带记：第 7 行所有数之和 = 2⁷ = 128；C++ 里可以直接用 (1 << 7) 算出来。
对应小节1 组合数表。
原创练习题单选题
杨辉三角第 5 层（从第 0 层开始数）的数是（　　）。
A.1 4 6 4 1　　B.1 5 10 10 5 1　　C.1 5 5 1　　D.1 6 15 20 15 6 1
查看答案与详解
答案：B。逐层推：
第 0~4 层依次是 1 / 1 1 / 1 2 1 / 1 3 3 1 / 1 4 6 4 1；
第 5 层 = 1、(1+4)=5、(4+6)=10、(6+4)=10、(4+1)=5、1 → 1 5 10 10 5 1。
注意：A 项是第 4 层；D 项是第 6 层。
对应小节1 一面刻着数字的墙。
原创练习题单选题
杨辉三角第 n 层中第 m 个数（从 0 开始编号）等于（　　）。
A.A(n, m)　　B.C(n, m) 　　C.n!　　D.m!
查看答案与详解
答案：B。杨辉三角第 n 层的第 m 个数，正好是从 n 个里选 m 个的组合数。
验证：第 4 层是 1、4、6、4、1，而 C(4,0)=1、C(4,1)=4、C(4,2)=6、C(4,3)=4、C(4,4)=1——完全吻合。
对应小节2 每一层就是组合数。
原创练习题判断题
杨辉三角第 n 层所有数字之和等于 2n。（　　）
查看答案与详解
答案：正确（√）。这条性质很常用。
验证：第 5 层 1+5+10+10+5+1 = 32 = 2⁵。
理解：n 个东西每个都有"选或不选"两种可能，总的挑选方式正好是 2ⁿ 种。

原创练习题判断题
组合数的递推关系 C(n,m) = C(n-1,m-1) + C(n-1,m) 可以用"最后一个元素选不选"来解释。（　　）
查看答案与详解
答案：正确（√）。从 n 个东西里选 m 个，分两种情况：
不选最后一个：从剩下 n-1 个里选 m 个 → C(n-1, m)；
选最后一个：还要从剩下 n-1 个里选 m-1 个 → C(n-1, m-1)。
两类相加，正是杨辉三角"上面两数之和"的由来。
对应小节2 每一层就是组合数。
原创练习题单选题
用杨辉三角查 C(6, 2) 的值，应该看（　　）。
A.第 2 层的第 6 个数　　B.第 6 层的第 2 个数
C.第 6 层的第 6 个数　　D.第 2 层的第 2 个数
查看答案与详解
答案：B。C(n, m) 对应"第 n 层、第 m 个"（都从 0 开始编号）。
第 6 层是 1、6、15、20、15、6、1，第 2 个数是 15——正好等于 C(6,2) = 6×5÷2 = 15。
对应小节2 每一层就是组合数。
原创练习题编程题
题目要求：生成 10 层杨辉三角并输出；再验证"第 9 层之和等于 2 的 9 次方"； 最后输出第 9 层中最大的数。
查看参考答案与要点 
int n = 9;
vector<vector<int>> tri(n + 1, vector<int>(n + 1, 0));

for (int i = 0; i <= n; i++) {
    tri[i][0] = 1;
    tri[i][i] = 1;
    for (int j = 1; j < i; j++) {
        tri[i][j] = tri[i - 1][j - 1] + tri[i - 1][j];
    }
}

for (int i = 0; i <= n; i++) {                 // 打印
    for (int j = 0; j <= i; j++) {
        cout << tri[i][j] << " ";
    }
    cout << endl;
}

long long rowSum = 0;                          // 验证 2 的 9 次方
int biggest = 0;
for (int j = 0; j <= n; j++) {
    rowSum = rowSum + tri[n][j];
    if (tri[n][j] > biggest) {
        biggest = tri[n][j];
    }
}

cout << "第 9 层之和：" << rowSum << endl;
cout << "2 的 9 次方：" << (1 << 9) << endl;
cout << "第 9 层最大的数：" << biggest << endl;

输出：第 9 层为 1 9 36 84 126 126 84 36 9 1； 之和 512；29 = 512；最大的数是 126。
要点：
① 数组要开 (n+1)×(n+1)；
② 两端先置 1，中间用递推填；
③ 第 9 层的数左右对称，所以最大的数有两个（126 和 126）；
④ 行和与 29 相等，可以用来验证程序是否正确。
对应小节3 生成杨辉三角；4 几条重要性质。

8　本单元小结

Unit Summary
贺舒曼 · 镜中先知
三句话记住杨辉三角：
一、每个数 = 上面两个数之和；两端永远是 1。
二、第 n 层第 m 个数就是 C(n,m)。
三、第 n 层之和是 2 的 n 次方。
还有一句要记住：生成它的代码，就是二维动态规划——七级的知识在这里又用上了。

你在三角石壁前收获了什么

  • 杨辉三角——每层两端为 1，中间的数等于上面两个数之和。
  • 与组合数的关系——第 n 层第 m 个数 = C(n,m)。
  • 递推式——C(n,m) = C(n-1,m-1) + C(n-1,m)，由"最后一个选不选"推出。
  • 生成方法——用二维列表一层层填，本质是二维 DP。
  • 循环范围——两端先置 1，中间填 for (int j = 1; j < i; j++)。
  • 重要性质——对称性、每层和 = 2n、斜线和 = 斐波那契。
  • 实用价值——用三角表查组合数，比反复乘除更快且不会溢出。
