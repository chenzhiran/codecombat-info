1　字符与字符串

Characters

1.1 字符 char 与它的编码

计算机里只有 0 和 1，那"字母 A"是怎么存进去的？
答案很朴素：给每个字符编一个号。

字符其实是个小整数 C++ 
#include <iostream>
using namespace std;

int main() {
    char c1 = 'A';
    char c2 = 'a';
    char c3 = '0';

    cout << c1 << " " << (int)c1 << endl;   // A 65
    cout << c2 << " " << (int)c2 << endl;   // a 97
    cout << c3 << " " << (int)c3 << endl;   // 0 48

    return 0;
}
OUTPUT　A 65 / a 97 / 0 48
看明白了吗　'A' 的值就是 65，'a' 是 97，'0' 是 48—— 它们本身就是整数
两条超级好用的规律： ① 字符数字 → 数字：'7' − '0' ＝ 55 − 48 ＝ 7。
② 数字 → 字符数字：3 + '0' ＝ 3 + 48 ＝ '3'。
这两个写法在"读入一大串数字字符"时天天用，一定要记熟。
别把 '0' 和 0 搞混！ 0 是整数零；'0' 是字符零，它的值是 48。
就像 'A' 和 65 说的是同一件事—— 只不过一个是"看起来的样子"，一个是"存进去的值"。

1.2 从字符到字符串

字符 char字符串 string
表示什么一个字符一串字符
怎么写的用单引号：'A'用双引号："GESP"
例子char c = 'x';string s = "hello";
引号千万别写反： 'A' 是字符，"A" 是字符串——它们不是一回事。
char c = "A"; 是错的（把字符串塞进单个字符里）；
string s = 'A'; 虽然能编译通过，但意义上很容易出岔子，别这么写。
口诀：一个字符用单引号，一串字符用双引号。

2　两种字符串存储

Two Ways to Store

2.1 字符数组与结束符

C++ 里存字符串有两条路。第一条是"字符数组"——本质就是一个 char 数组，
但要额外记住一条规矩：末尾必须有个结束符 '\0'。

字符数组：四个字母要占五个格子 C++ 
char s[5] = "GESP";     // ★ 长度必须是 5，不是 4

// 内存里长这样：
//   s[0]  s[1]  s[2]  s[3]  s[4]
//    G     E     S     P    '\0'
//                            ↑ 结束符，占用一个字节

char t[] = "GESP";      // 也可以让编译器自己数，长度自动是 5
必记　字符串占的字节数 = 字符个数 + 1（那个 '\0' 也算一个）
所以 char s[4] = "GESP"; 是错的——装不下
为什么要有结束符？ 因为字符数组本身不知道"我装了多长"——它只是一个格子排。
程序从第一个格子开始读，一直读到 '\0' 才知道"到这儿为止了"。
所以那个结束符不是可有可无的装饰，它是"句号"。

2.2 string 类型

第二条路是 C++ 标准库里的 string 类型—— 它把上面这些麻烦事都替你处理好了，推荐优先使用它。

用 string，省心很多 C++ 
#include <iostream>
#include <string>             // ★ 别忘了这一行
using namespace std;

int main() {
    string s = "GESP";

    cout << s << endl;         // GESP
    cout << s.size() << endl;   // 4    ← 不用管 '\0'，size 是 4 不是 5

    s += " 2026";               // 直接用 += 拼字符串
    cout << s << endl;         // GESP 2026

    return 0;
}
OUTPUT　GESP / 4 / GESP 2026
最舒服的一点　size() 返回的是真正的字符个数，不用自己去数、也不用管结束符
字符数组 char s[]string 类型
长度定义后固定可以自动变长
结束符必须自己留位置不用管
拼接得用 strcat 之类的函数直接 s += t
比较不能用 ==，要用 strcmp可以直接用 ==、<、>
求长度strlen(s)s.size()
结论：能用 string 就用 string。 它更安全、更好写、功能更全。
但两种都要认识——因为考试里常把 char s[] 和 string 放在一起考， 比如问"char str[4] = "GESP"; 要几个字节"。

3　访问与遍历

Access & Traversal

3.1 下标访问

字符串的下标也是从 0 开始 C++ 
string s = "GESP";
//  下标：  0    1    2    3
//  字符：  G    E    S    P

cout << s[0] << endl;        // G
cout << s[3] << endl;        // P
cout << s[4] << endl;        // ★ 越界！这里什么都没有

s[1] = 'X';                 // ★ C++ 的 string 可以直接改
cout << s << endl;          // GXSP
OUTPUT　G / P / GXSP
注意最后一行　C++ 的 string 可以直接修改某个字符—— 这一点和很多语言不同，直接用 s[1] = 'X' 就行
和数组一个道理： 长度为 n 的字符串，合法下标是 0 ~ n−1。
s.size() 是 4，最后一个字符就是 s[3]。
写 s[s.size()] 一定越界。

3.2 遍历字符串

三种遍历写法 C++ 
string s = "GESP2026";

// 写法一：下标遍历（最常用）
for (int i = 0; i < (int)s.size(); i++) {
    cout << s[i];
}
cout << endl;

// 写法二：范围 for（只读）
for (char c : s) {
    cout << c;
}
cout << endl;

// 写法三：范围 for 加引用（可以改）
for (char &c : s) {
    if (c >= 'a' && c <= 'z') c = c - 32;   // 小写转大写
}
cout << s << endl;                        // GESP2026
OUTPUT　GESP2026 / GESP2026 / GESP2026
注意写法一里的 (int)s.size()　size() 返回的是无符号类型， 和 int i 比较时编译器会警告，加个 (int) 更稳妥
小写转大写为什么是减 32？ 因为 'a' 是 97、'A' 是 65，刚好差 32。
所以 c − 32 就把小写字母变成了大写。
反过来，大写转小写就是 c + 32。 这条对应关系考试里常考。

4　常用成员函数

Member Functions

4.1 size / empty / substr

函数作用例子（s = "GESP2026"）
s.size()返回字符个数，不含结束符8
s.length()和 size() 完全等价8
s.empty()为空返回 true，否则 falsefalse
s.substr(pos, len)从 pos 开始，截取 len 个字符s.substr(0, 4) → "GESP"
s.substr(pos)省略第二个参数 → 一直截到末尾s.substr(4) → "2026"
substr 的两种用法 C++ 
string s = "GESP2026";

cout << s.substr(0, 4) << endl;   // GESP    从 0 开始取 4 个
cout << s.substr(4) << endl;      // 2026    从 4 开始取到末尾
cout << s.substr(2, 3) << endl;   // SP2     从 2 开始取 3 个
cout << s.size() << endl;         // 8       一共 8 个字符
关键　substr(pos, len) 里，pos 是起始下标、len 是"取几个"
省略 len，就一路取到末尾

4.2 find 与 npos

查找子串在哪 C++ 
string s = "GESP2026";

cout << s.find("2026") << endl;    // 4      找到了，返回起始下标
cout << s.find("XYZ") << endl;     // 很大一个数 ← 找不到时返回 npos

if (s.find("XYZ") == string::npos) {
    cout << "没找到" << endl;        // 没找到
}

if (s.find("2026") != string::npos) {
    cout << "找到了" << endl;        // 找到了
}
关键　find 找到就返回起始下标，找不到返回 string::npos
npos 是一个很大的数（无符号类型的最大值），判断时用 == string::npos
find 找不到会怎样？ 它不会报错，也不会返回 −1，而是返回一个特殊值 string::npos。
如果你不判断就用这个结果当下标去访问，就会越界。
所以每次用 find，都要习惯性地判断一下"找没找到"。

5　修改字符串

Modifying Strings

5.1 直接改某个字符

C++ 的 string 是可以直接改的 C++ 
string s = "GESP";

s[0] = 'T';              // 把第 0 个字符改成 'T'
cout << s << endl;        // TESP

s[1] = s[1] + 32;        // 'E' 是大写，加 32 变小写 'e'
cout << s << endl;        // Tesp

s += "!";                // 末尾追加
cout << s << endl;        // Tesp!
OUTPUT　TESP / Tesp / Tesp!
和数组一样　用下标就能改某一位，改的是原串本身
这一点和"字符数组"是一样的： 它们的元素都可以被直接修改。
但要注意：如果字符串是"字面量"（比如 char *p = "abc";）， 那是不允许改的——那是只读区域。
用 string s = "abc"; 或 char s[] = "abc"; 就没问题。

5.2 erase 与 replace

写法效果例子（s = "GESP2026"）
s.erase(pos, len)删除从 pos 开始的 len 个字符s.erase(0, 4) → "2026"
s.erase(pos)只带一个参数 → 删除从 pos 到末尾的全部字符s.erase(4) → "GESP"
s.replace(pos, len, t)把 pos 开始的 len 个字符替换成 ts.replace(0, 4, "HB") → "HB2026"
s.insert(pos, t)在 pos 处插入 ts.insert(0, "!") → "!GESP2026"
最容易考错的一条：erase 只带一个参数时删的是"一整段"，不是"一个字符"。 s.erase(2) 表示删除下标为 2 的这一个字符——这句话是错的。
s.erase(2) 的实际效果是：从下标 2 开始，一直删到末尾。
想只删一个字符，得写 s.erase(2, 1)——第二个参数指定"删几个"。
记忆：erase 第一个参数是"从哪儿开始"，第二个参数是"删多少个"；不写第二个参数就删到底。

进入关卡 →
故事：矿坑里养着一只会说暗语的宠物，它传来的消息是一串字符。
斯凯勒把消息记在石板上：这些字符里藏着关键词——你得找出它在第几个位置， 才知道宠物想说什么。
你看着那串字：用 find 就行吧？
对，她点头，但记住——找不到的时候，它不会报错，会给你一个特殊的值。

思路：把消息存成 string， 用 find 定位关键词、用 substr 截取片段、 用 size 判断长度。

查找、截取、统计一次做完 C++ 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string msg = "GESP2026";

    // ① 长度
    cout << msg.size() << endl;              // 8

    // ② 查找关键词
    size_t p = msg.find("2026");
    if (p != string::npos) {
        cout << p << endl;                   // 4
        cout << msg.substr(p) << endl;        // 2026
    }

    // ③ 统计数字字符的个数
    int cnt = 0;
    for (int i = 0; i < (int)msg.size(); i++) {
        if (msg[i] >= '0' && msg[i] <= '9') cnt++;
    }
    cout << cnt << endl;                     // 4

    return 0;
}
OUTPUT　8 / 4 / 2026 / 4
三个要点　size() 不含结束符；find 返回下标、要判断 npos； 判断数字字符用 c >= '0' && c <= '9'
和本单元的关系： 查找 + 截取 + 遍历统计，是字符串题的三板斧。
尤其是"统计某类字符的个数"—— 判断数字用 c >= '0' && c <= '9'、 判断小写用 c >= 'a' && c <= 'z'、 判断大写用 c >= 'A' && c <= 'Z'。
这三行判断几乎每年都考。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
字符串这块，考的全是"细节"。四条，都是原题踩过的坑。
1
把 char 和 '0' 搞混。
扣哒鸭：判断一个字符是不是数字字符，要写 c >= '0' && c <= '9'，
不能写 c == 0 || c == 1——那是拿字符和整数 0、1 比，意思完全变了。
而且题目说"是 '0' 或者 '1'"，就只该判断这两个字符。
正确写法：if (c == '0' || c == '1')
2
以为 s.erase(2) 只删一个字符。
扣哒鸭：erase 只带一个参数时，删的是"从那个位置到末尾"的一整段！
想删一个字符必须写 s.erase(2, 1)。
真题里"erase(2) 表示删除下标为 2 的这一个字符"是错误说法。
记牢：erase(pos, len)；省略 len 就删到末尾
3
字符数组忘了给结束符留位置。
扣哒鸭：char s[4] = "GESP"; 编译就过不去——
4 个字母加上结束符要 5 个字节。
写成 char s[5] = "GESP"; 或者干脆 char s[] = "GESP"; 让编译器自己数。
口诀：字符个数 + 1 = 需要的字节数
4
用 find 的结果不判断就直接用。
扣哒鸭：找不到时 find 返回的是 string::npos， 不是 −1，也不是 0。
直接拿它当下标用，就是一个巨大的越界访问。
养成习惯：if (s.find(x) != string::npos) { … }
正确写法：先判断 != string::npos 再使用结果

改编自 2026 年 9 月 · C++ 三级 · 第 13 题单选题
关于 string 的成员函数，下面说法错误的是（　　）。
A.size() 返回字符串的字符个数，不包含末尾的 '\0'； length() 和 size() 功能完全等价
B.s.empty()：字符串为空时返回 true，不为空返回 false
C.s.substr(pos, len)，当省略第二个参数 len 时， 代表从 pos 位置一直截取到字符串末尾
D.s.erase(2) 表示删除字符串中下标为 2 的这一个字符
查看答案与详解
答案：D。erase 的参数含义是 erase(pos, len)： 从 pos 开始删 len 个字符。
只写一个参数时，第二个参数取默认值"一直到末尾"—— 所以 s.erase(2) 的效果是把下标 2 及其后面的所有字符全部删掉， 不仅仅是下标 2 那一个。
想只删一个字符，要写 s.erase(2, 1)。
A、B、C 三项都正确：
A：size() 数的是真正的字符个数（不含结束符）， 而 length() 确实和它完全一样——历史上 string 借鉴了其他容器的命名， 于是留下了两个同义函数。
B：empty() 等价于 size() == 0。
C：省略 len 就是"取到末尾"。
对应小节5.2 erase 与 replace。
改编自 2026 年 6 月 · C++ 三级 · 判断题 第 7 题判断题
判断字符串中的字符是否是 '0' 或者 '1'， 可以写条件 if (str[i] == 0 || str[i] == 1)。（　　）
查看答案与详解
答案：错误（×）。str[i] 是一个字符， 而 0 和 1 是整数——两边类型不同，比较的意义完全变了。
str[i] == 0 实际是在问"这个字符的编码是不是 0"，只有字符串的结束符 '\0' 才满足。
正确写法必须加单引号：if (str[i] == '0' || str[i] == '1')。
顺带记一下编码：'0' 是 48、'1' 是 49， 和整数 0、1 差着 48 呢。
对应小节1.1 字符 char 与它的编码。
改编自 2026 年 6 月 · C++ 三级 · 编程题 2编程题
分割字符串：从左到右扫描，第一次遇到 1 个空格就分割； 之后对右侧部分继续扫描，第二次遇到连续 2 个空格才分割； 第三次要连续 3 个空格……以此类推。
依次输出每次分割左侧的字符串，最后输出最后一次分割右侧的字符串。 若完全无法分割，直接输出原串。
查看参考答案与要点 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);            // ★ 整行读入，含空格

    int need = 1;               // 这次需要几个连续空格
    size_t pos = 0;             // 从哪儿开始找

    while (true) {
        // 在 s[pos] 之后找 need 个连续空格
        size_t found = string::npos;
        for (size_t i = pos; i + need <= s.size(); i++) {
            bool ok = true;
            for (int k = 0; k < need; k++)
                if (s[i + k] != ' ') { ok = false; break; }
            if (ok) { found = i; break; }
        }

        if (found == string::npos) break;   // 找不到了，停止

        cout << s.substr(pos, found - pos) << endl;   // 输出左侧
        pos = found + need;                            // 跳过这些空格
        need++;                                        // 下次多要一个
    }

    cout << s.substr(pos) << endl;      // 最后输出剩下的右侧
    return 0;
}

要点：
① 读入整行要用 getline(cin, s)， 因为 cin >> 一遇到空格就停了，读不到整句；
② size_t 是无符号类型，用来接 find 的结果； 它也正好能表示 string::npos；
③ "连续 need 个空格"要靠内层循环逐个字符检查； 循环边界写 i + need <= s.size()，防止越界；
④ substr(pos, found − pos) 截出左侧， 长度是"结束位置减起始位置"；
⑤ 找到后要把 pos 跳到空格之后（found + need）， 并把 need 加 1。
对应小节4.1 size / empty / substr；4.2 find 与 npos。

原创练习题单选题
执行下面的代码，输出是（　　）。
string s = "GESP2026";
cout << s.size() << " " << s.substr(4) << " " << s.find("SP") << endl;
A.8 2026 2　　B.9 2026 2　　C.8 2026 3　　D.8 026 2
查看答案与详解
答案：A。三部分分别看：
① s.size()："GESP2026" 一共 8 个字符， 不含结束符，所以是 8（B 项的 9 就是错把它算进去了）。
② s.substr(4)：从下标 4 开始取到末尾。 下标 0~3 是 G、E、S、P，所以从 4 开始就是 "2026"。
③ s.find("SP")：S 在下标 2，P 在下标 3， 所以 "SP" 从下标 2 开始——find 返回的是起始下标，不是结束位置。
对应小节4.1 size / empty / substr；4.2 find 与 npos。
原创练习题判断题
在 C++ 中，char s[] = "hello"; 定义的数组长度是 5。（　　）
查看答案与详解
答案：错误（×）。字符串字面量 "hello" 末尾还有一个隐含的结束符 '\0'。
所以实际长度是 5 + 1 = 6。
可以用程序验证：sizeof(s) / sizeof(s[0]) 的结果是 6， 而 strlen(s) 或 string(s).size() 才是 5—— 因为后者数的是"真正的字符个数"，不含结束符。
这两个数字容易混：数组长度含结束符，字符串长度不含。
对应小节2.1 字符数组与结束符。
原创练习题编程题
题目要求：读入一行字符串，分别统计其中大写字母、小写字母、数字字符的个数， 并输出三个数字，用空格隔开。
查看参考答案与要点 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    int upper = 0, lower = 0, digit = 0;

    for (int i = 0; i < (int)s.size(); i++) {
        char c = s[i];
        if (c >= 'A' && c <= 'Z')      upper++;
        else if (c >= 'a' && c <= 'z') lower++;
        else if (c >= '0' && c <= '9') digit++;
    }

    cout << upper << " " << lower << " " << digit << endl;
    return 0;
}

输入 GESP2026 abc 输出：4 3 4
要点：
① 三行范围判断是字符串题的万能钥匙： c >= 'A' && c <= 'Z'、c >= 'a' && c <= 'z'、 c >= '0' && c <= '9'；
② 用 else if 串起来，一个字符只可能归入一类，互不干扰；
③ 边界条件必须写 &&，不能写成 c >= 'A' && c <= 'Z' 之外的组合—— 比如误写成 c >= 'A' && c <= 'z' 就会把中间几个符号也算进去；
④ 读整行记得用 getline。
对应小节3.2 遍历字符串。

四句话记住字符串：
一、字符本质上是整数：'0' 是 48、'A' 是 65、'a' 是 97，大小写差 32。
二、字符数组末尾要有 '\0'，所以字节数 = 字符数 + 1；string 不用管，但更推荐用。
三、下标从 0 开始；size() 不含结束符；substr 省略长度就取到末尾。
四、erase(pos) 删的是"从 pos 到末尾"一整段；find 找不到返回 npos。
碑文读通了。最后一站是穷举矿灯——那里有一整面墙的灯，我们一盏一盏试过去。

你在石碑前收获了什么

  • 字符 char——本质是小整数；'0'=48、'A'=65、'a'=97。
  • 两条转换公式——字符数字 − '0' = 数字；数字 + '0' = 字符数字。
  • 大小写差 32——'a' − 32 = 'A'。
  • 引号——一个字符用单引号 'A'，一串字符用双引号 "A"。
  • 字符数组——末尾有结束符 '\0'，字节数 = 字符数 + 1。
  • string——不用管结束符、能自动变长、可直接 += 拼接和 == 比较。
  • 访问——下标从 0 开始，长度 n 的串合法下标是 0 ~ n−1；C++ 的 string 可以直接改某个字符。
  • size / length——两者等价，返回真正的字符个数（不含 '\0'）。
  • substr(pos, len)——从 pos 取 len 个；省略 len 就取到末尾。
  • find——找到返回起始下标，找不到返回 string::npos，一定要判断。
  • erase(pos, len)——删 len 个；只写 pos 就删到末尾（不是删一个！）。
  • 字符判断三件套——c >= 'A' && c <= 'Z'、c >= 'a' && c <= 'z'、c >= '0' && c <= '9'。
