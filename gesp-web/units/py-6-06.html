1　栈：后进先出

Stack

1.1 只有一个口

栈的规矩只有一条：后进先出（LIFO）。 栈只在一端进出东西——这一端叫栈顶，另一端封死叫栈底。
所以：最后放进去的，一定最先被拿出来。
想拿下面那个？对不起——得先把上面的都搬走。
LIFO 就是 "Last In, First Out"（后进先出）的缩写。
用叠盘子理解栈 TEXT 
往栈里依次放入 1、2、3：

  push(1)      push(2)      push(3)
  ┌───┐        ┌───┐        ┌───┐
  │ 1 │        │ 2 │        │ 3 │ ← 栈顶
  └───┘        │ 1 │        │ 2 │
               └───┘        │ 1 │
                            └───┘

现在 pop() 一次，取出的是谁？
   → 取出 3（最后放进去的）
   剩下 2、1

再 pop() 一次 → 取出 2
再 pop() 一次 → 取出 1

★ 出栈的顺序和入栈的顺序正好相反：3、2、1

【关键结论】
   入栈顺序 1 2 3  →  出栈顺序 3 2 1
记忆　 栈像一叠盘子——只能从最上面拿，也只能往最上面放
所以"先放进去的被压在最底下"，最后才轮得到它

1.2 栈的三个操作

操作作用Python STL 写法
入栈把元素放到栈顶s.push(x);
出栈把栈顶元素拿走s.pop();
看栈顶看看栈顶是谁（不拿走）s.top();
判断空空返回 trues.empty();
元素个数返回有几个元素s.size();
最容易考错的一条：pop() 不返回任何东西。 在 Python 的 STL 里：
s.top() —— 只"看"栈顶元素，不会删除它；
s.pop() —— 只"删掉"栈顶元素，不返回它（返回类型是 void）。
所以想把栈顶"取出来用"，必须两步走： int x = s.top(); s.pop();
"stack 的 pop() 会返回栈顶元素并将其删除"——这句话是错的。
（这一点和很多别的语言不同，写惯别的语言的同学特别容易踩。）
上机跑一遍 Python 
s = []                          # Python 用列表当栈

for i in range(2, 7, 2):        # 放入 2、4、6
    s.append(i)

s.pop()                         # 拿走栈顶的 6

print(s[-1])                    # 4　（栈顶）
print(len(s))                   # 2
OUTPUT　4 / 2
为什么 top 是 4？　入栈顺序 2、4、6，6 在栈顶；pop 掉 6 之后，栈顶变成 4

2　队列：先进先出

Queue

2.1 两头各开一个口

队列的规矩：先进先出（FIFO）。 队列两头各开一个口：一端只进（队尾），另一端只出（队首）。
所以：最先排进队伍的，一定最先被处理。
FIFO 就是 "First In, First Out"（先进先出）的缩写。
这就是现实里"排队"的规则——先来的先办事，不许插队。
用排队理解队列 TEXT 
往队列里依次放入 1、2、3：

  push(1)      push(2)          push(3)
  ┌───┐        ┌───┬───┐        ┌───┬───┬───┐
  │ 1 │        │ 1 │ 2 │        │ 1 │ 2 │ 3 │
  └───┘        └───┴───┘        └───┴───┴───┘
  队首=队尾     ↑出   ↑入        ↑出       ↑入

现在 pop() 一次，取出的是谁？
   → 取出 1（最先放进去的）
   剩下 2、3，队首变成 2

再 pop() 一次 → 取出 2
再 pop() 一次 → 取出 3

★ 出队的顺序和入队的顺序完全一样：1、2、3

【关键结论】
   入队顺序 1 2 3  →  出队顺序 1 2 3
和栈正好相反　 栈是"入 1 2 3、出 3 2 1"；队列是"入 1 2 3、出 1 2 3"
这一点是判断题和选择题的高频考点

2.2 队列的三个操作

操作作用Python STL 写法
入队把元素放到队尾q.push(x);
出队把队首元素拿走q.pop();
看队首看看队首是谁（不拿走）q.front();
看队尾看看队尾是谁q.back();
判断空 / 个数—q.empty(); / q.size();
和栈放在一起对比着看 Python 
s = []      # 栈：只在同一头进出
q = []      # 队列：一头进、另一头出

for i in range(2, 7, 2):        # 都放入 2、4、6
    s.append(i)
    q.append(i)

s.pop()                         # 栈：拿掉栈顶的 6
q.pop(0)                        # 队列：拿掉队首的 2

print(s[-1], " ", q[0])         # 4   4
OUTPUT　4 4
看明白了吗　 同一个 pop()，栈取走的是"最后进来的 6"，队列取走的是"最早进来的 2"
结果刚好都是 4——但原因完全不同：一个是"6 走了剩 4"，一个是"2 走了剩 4"
把两个规则并排记： 栈——只有一个口，后进先出；入 1 2 3 出 3 2 1。
队列——两个口，先进先出；入 1 2 3 出 1 2 3。
做题时先在草稿纸上画一画"入的顺序"，再按规则一个个搬出来—— 这样最不容易错。

3　它们在程序里的用处

What They Are For

3.1 栈能干什么

栈的典型用途： ① 函数调用——上一课讲过，每次调用就"压一层栈"，返回时"弹一层"。 这就是"调用栈"这个名字的来源。
② 括号匹配——遇到左括号就入栈，遇到右括号就看栈顶是不是配对的左括号。
③ 撤销操作——把操作一个个压进栈；按撤销就弹一个出来， 而且"最近做的最先撤销"正好符合直觉。
④ 用栈模拟递归——上一课 DFS 的栈写法就是它。
⑤ 表达式求值、进制转换——都是"后进先出"天然合适的场景。
用栈判断括号是否配对 Python 
def check(s):
    st = []

    for c in s:
        if c == "(":
            st.append(c)            # 左括号入栈
        elif c == ")":
            if not st:
                return False        # ★ 右括号多了
            st.pop()                # 消掉一个左括号
    return not st                   # ★ 栈空才是配对成功
两处判断　 ① 遇到右括号但栈是空的 → 右括号多了，不合法；
② 全部扫完后栈不为空 → 左括号多了，不合法

3.2 队列能干什么

队列的典型用途： ① BFS（广度优先搜索）——上一课学的，一层层往外扩靠的就是队列。
② 层序遍历——二叉树的"从上到下、从左到右"。
③ 任务调度——打印机排队、CPU 处理请求，都是"先来先服务"。
④ 缓冲区——数据来得快、处理得慢时，先排进队列缓冲一下。
核心共性： 凡是"要先来先处理、要按顺序公平对待"的场景，都该想到队列。
一句话选结构： 要"倒退着处理"、"记住回去的路"、"最近的最相关" → 用栈。
要"按顺序公平处理"、"一圈圈往外扩"、"先来先服务" → 用队列。
判断口诀：栈是"回头看"，队列是"往前排队"。

4　循环队列

Circular Queue

4.1 普通队列的"假满"

用数组当队列，会出什么问题？ TEXT 
开一个长度 5 的数组当队列，用 front 和 rear 两个下标管理：

  操作      数组内容              front  rear
  初始      [ ][ ][ ][ ][ ]         0      0
  入队 A    [A][ ][ ][ ][ ]         0      1
  入队 B    [A][B][ ][ ][ ]         0      2
  出队      [A][B][ ][ ][ ]         1      2   ← front 前进了
  入队 C    [A][B][C][ ][ ]         1      3
  入队 D    [A][B][C][D][ ]         1      4
  入队 E    [A][B][C][D][E]         1      5   ← rear 到头了！

这时 rear == 5，数组满了 —— 可是前面 A 明明已经被出队、那个位置空着！

★ 明明还有空位，却放不进去 —— 这叫"假满"（假溢出）。

【解决办法】让 rear 和 front "绕回来"：
   走到数组末尾之后，回到下标 0 继续用。
   这就是"循环队列"——把数组看成首尾相接的一个圈。
问题根源　 下标只往前走、不回头——前面的空位白白浪费了

4.2 怎么判空与判满

循环队列的四个关键动作 Python 
MAXN = 8                        # 数组长度
data = [0] * MAXN
front, rear = 0, 0              # 队首、队尾下标（注意初始都为 0）

# 【入队】先放，再把 rear 往前挪一格（绕回）
def push(x):
    global rear
    data[rear] = x
    rear = (rear + 1) % MAXN    # ★ 关键：% MAXN 让它"绕回来"

# 【出队】先把 front 往前挪一格
def pop():
    global front
    front = (front + 1) % MAXN  # ★ 同样要取模

# 【判空】队首和队尾撞在一起 → 空
def empty():
    return front == rear

# 【判满】队尾的"下一个位置"就是队首 → 满
def full():
    return (rear + 1) % MAXN == front

# 【取队首】下标就是 front
def getFront():
    return data[front]
三处都要记住　 ① 入队 / 出队时下标要 % MAXN 才能"绕圈"；
② 判空：front == rear；
③ 判满：(rear + 1) % MAXN == front
为什么判满要写成 (rear + 1) % MAXN == front？ 这根"空出一个位置"的约定有关。
问题在哪？ 当队列刚好装满时，rear 绕一圈回来正好等于 front—— 和"队列为空"时的 front == rear 长得一模一样，没法区分。
解决办法：特意不把数组用满，永远留出一个空位。
于是：真装的元素最多是 MAXN − 1 个； 当"rear 的下一个位置"追上 front 时，就认为满了 ✔
这就是"空出一个位置"的经典做法，也是真题反复考的点。
所以：数组长度为 8 的循环队列，最多只能装 7 个元素。

5　用数组自己实现

Implementing with Arrays

5.1 手写一个栈

栈其实就是一个数组 + 一个栈顶指针 Python 
st = [0] * 1005                 # 存数据的数组
top = 0                         # ★ 栈顶指针：也表示"现在有几个元素"

def push(x):
    global top
    st[top] = x                 # 放到"下一个空位"
    top += 1                    # 栈顶往上挪

def pop():
    global top
    top -= 1                    # 栈顶往下挪 —— 就这么简单

def getTop():
    return st[top - 1]          # ★ 注意是 top - 1，不是 top

def empty():
    return top == 0
OUTPUT　推入 2、4、6 后 getTop() 是 6
关键理解　 top 指向的是"下一个空位"，所以栈顶元素在 top - 1 处
这也是为什么出栈只要 top-- 就行——不用真的把数据擦掉，指针退一格就够了

5.2 手写循环队列

完整实现（把这几个式子背下来） Python 
MAXN = 105
q = [0] * MAXN
front, rear = 0, 0

def empty():
    return front == rear

def full():
    return (rear + 1) % MAXN == front

def push(x):
    global rear
    if full():
        return False
    q[rear] = x
    rear = (rear + 1) % MAXN              # ★ 绕圈
    return True

def pop():
    global front
    if empty():
        return False
    front = (front + 1) % MAXN            # ★ 绕圈
    return True

def getFront():
    return q[front]                       # 队首就在 front 处

def size():
    return (rear - front + MAXN) % MAXN   # ★ 加 MAXN 防负数
注意 size() 的写法　 (rear − front + MAXN) % MAXN——
因为 rear 可能"绕"到了 front 前面，直接相减会得到负数，所以先加一个 MAXN 再取模
手写队列最容易忘的一件事：出队时不用擦数据。 看 pop()——它只做了一件事：front 往前挪一格。
数组里那个位置的数据还在，但它已经"不算数"了——因为取队首只看 front 指的地方。
等以后有新的元素入队、并且 rear 绕到那里时，它就会被新的数据覆盖掉。
这种"用下标表示有效范围、不真的搬动数据"的做法，正是所有环形结构的基本思路。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
栈和队列的坑只有几个，但每个都年年考。四条。
1
以为 pop() 会返回被删掉的元素。
扣哒鸭：STL 里 stack::pop() 和 queue::pop() 的返回类型都是 void—— 它们只删、不给。
想要那个值，必须先 top() / front() 看一眼，再 pop()。
"pop() 返回栈顶元素并删除"——这句话是错的。
正确写法：int x = s.top(); s.pop();
2
对空栈 / 空队列取元素。
扣哒鸭：对空的栈调 top()、对空的队列调 front()， 结果是不确定的——可能崩溃，也可能拿到垃圾值。 Python 不会帮你检查。
取之前一定要先 if (!s.empty()) 或写 while (!q.empty())。
习惯：取元素前先判空
3
循环队列的下标忘了取模。
扣哒鸭：必须写 rear = (rear + 1) % MAXN;， 写成 rear++ 的话，下标很快就会冲出数组、越界访问。
那个 % MAXN 就是"让它绕回来"的关键。
正确写法：(下标 + 1) % MAXN
4
判满写成 rear == front，或者以为队列能装满。
扣哒鸭：front == rear 是"判空"，不是判满！
判满要写 (rear + 1) % MAXN == front。
而且要注意：用"空出一个位置"的办法时，长度为 MAXN 的队列最多只能装 MAXN − 1 个元素。 以为能装满 MAXN 个就错了。
记牢：空看 front == rear；满看 (rear+1)%MAXN == front

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
栈和队列只有一行之差，写反了结果完全不对。四条，看完你就不会再弄混。
1
队列出队用了 pop()。
扣哒鸭：pop() 拿的是末尾——那就成栈了！
队列必须从队头拿：pop(0) 或 deque.popleft()。
正确写法：队列出队 pop(0)
2
空栈/空队列时直接 pop。
扣哒鸭：会报 IndexError: pop from empty list。
动手前先用 if stack: 或 if len(queue) > 0: 判断一下。
正确做法：while stack: x = stack.pop()
3
循环队列忘了取余。直接写 rear = rear + 1。
扣哒鸭：不取余的话，rear 会一直涨到超出数组长度，直接越界。
必须写 rear = (rear + 1) % capacity——这才是"绕回起点"的关键。
正确写法：下标更新一律对容量取余
4
把"看栈顶"和"出栈"搞混。
扣哒鸭：stack[-1] 只是看一眼，元素还在； stack.pop() 是拿走，元素没了。
题目要"查看栈顶"却用了 pop，就把数据弄丢了。
正确区分：查看用 [-1]，取出用 pop()

天阶的传送队列采用牺牲一个存储单元（空出一个位置）的办法来区分"队空"与"队满"。
full() 函数用来判断队列是否已满，横线处应填写（　　）。
1  MAXN = 8
2  data = [0] * MAXN
3  front = 0
4  rear = 0
5
6  def full():
7      return _______________
A.rear == front
B.(front + 1) % MAXN == rear
C.(rear + 1) % MAXN == front
D.rear == MAXN - 1
查看答案与详解
答案：C。循环队列里 rear 指向下一个要写入的位置，front 指向队头元素。
队满的判据是"下一个写入位置追上了队头"：(rear + 1) % MAXN == front。取余是为了让下标到末尾后绕回 0，这正是"循环"队列的关键。
A 错：rear == front 表示的是队空；
B 错：把 rear 和 front 的角色写反了；
D 错：这是普通队列的判满条件，循环队列里 rear 会绕回 0，写成这样到不了队满、还会浪费空间。
为什么"牺牲一个单元"？如果不空出一格，"队满"和"队空"都会是 rear == front，两种状态分不清了 —— 所以约定队尾永远留一个空位，队列最多只能存 MAXN − 1 个元素。

原创练习题编程题
题目要求：利用栈判断一个字符串中的括号是否配对。 只考虑小括号 ( )，配对则输出 True，否则输出 False。
查看参考答案与要点 
def check(s):
    stack = []
    for ch in s:
        if ch == "(":
            stack.append(ch)          # 遇到左括号：压栈
        elif ch == ")":
            if not stack:             # 右括号多了：直接失败
                return False
            stack.pop()               # 遇到右括号：弹出一个
    return len(stack) == 0            # 栈空了才算配对

print(check("(a(b)c)"))     # True
print(check("(a(b)c"))      # False
print(check(")a("))         # False

输出：True、False、False
要点：
① 遇到左括号压栈，相当于"记住这里还有一个没配对的"；
② 遇到右括号弹栈，相当于"配对掉最近的一个"——"最近"正是栈的强项；
③ 出现右括号但栈已空，说明右括号多了，直接返回 False；
④ 全部扫完后栈必须为空，否则说明左括号多了。
对应小节2 栈：后进先出。
