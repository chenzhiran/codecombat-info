1　顺序重要吗

Does Order Matter

1.1 顺序算不算不一样

1.2 排列与组合只差一个问题

1.3 判断口诀

判断口诀： 顺序变了以后，结果算不算"不同"？
算不同 → 排列（比如排名次、排座位、密码、站队）
算相同 → 组合（比如组队、选几个人、挑几件东西）
记法：排列讲"次序"，组合只讲"谁在里面"。

2　排列：顺序重要

Permutations

2.1 用乘法原理推出来

从 n 个不同的东西里，依次选出 m 个排成一列，方案数记作 A(n, m)。

用乘法原理推出来 分析 
第 1 个位置：有 n 种选法
第 2 个位置：剩下 n-1 种
第 3 个位置：剩下 n-2 种
……
第 m 个位置：剩下 n-m+1 种

所以 A(n, m) = n × (n-1) × (n-2) × … × (n-m+1)

例：A(5, 3) = 5 × 4 × 3 = 60
要点　一共乘 m 个数，从 n 开始往下数

2.2 全排列：m = n 的情况

全排列：m = n 的情况 A(n, n) = n × (n-1) × … × 1 = n!
比如 5 个人全部排成一排，就是 5! = 120 种。
考试里"全部排列"就是阶乘，看到就反应过来。

3　组合：顺序不重要

Combinations

3.1 从排列"除重"得到组合

从 n 个里只选出 m 个（不管顺序），方案数记作 C(n, m)。

从排列"除重"得到组合 分析 
先按"排列"算：A(n, m)
但每一组 m 个东西，被当作不同排列数了 m! 次
（因为 m 个东西自己排队有 m! 种顺序）

所以 C(n, m) = A(n, m) ÷ m!
             = n × (n-1) × … × (n-m+1) ÷ m!

例：C(5, 3) = (5 × 4 × 3) ÷ (3 × 2 × 1) = 60 ÷ 6 = 10
要点　组合 = 排列 ÷ m!，除以的正是"同一组内部的排列数"

3.2 两个常用特例

两个常用特例：
C(n, 1) = n（选 1 个，就是 n 种）
C(n, n) = 1 和 C(n, 0) = 1（全选或不选，都只有 1 种）
还有一条对称性：C(n, m) = C(n, n-m)—— 选 3 个和"留下 n-3 个"是一回事，所以 C(5,2) = C(5,3)。

4　阶乘与递推

Factorial & Recurrence

4.1 三种算组合数的写法

三种算组合数的写法 C++ 
// ① 直接用阶乘公式
long long fact(int k) {
    long long r = 1;
    for (int i = 1; i <= k; i++) r *= i;
    return r;
}

long long c1(int n, int m) {
    return fact(n) / (fact(m) * fact(n - m));
}

cout << c1(5, 3) << endl;      // 10

// ② 边乘边除，避免溢出（推荐）
long long c2(int n, int m) {
    if (m > n - m) m = n - m;                 // 利用对称性，少算几次
    long long result = 1;
    for (int i = 1; i <= m; i++) {
        result = result * (n - m + i) / i;
    }
    return result;
}

cout << c2(5, 3) << endl;      // 10
cout << c2(100, 3) << endl;    // 161700
要点　// 在每一步都能整除，所以边乘边除不会出错

4.2 递推法

递推法：下一级别会正式学到杨辉三角 C++ 
// C(n, m) = C(n-1, m-1) + C(n-1, m)
// 选不选第 n 个东西，分成两种情况

long long c3(int n, int m) {
    if (m == 0 || m == n) return 1;
    return c3(n - 1, m - 1) + c3(n - 1, m);
}

cout << c3(5, 3) << endl;      // 10
要点　这条递推式，下一单元会变成一整张"杨辉三角"

5　用程序列举

Enumerating

5.1 列举所有组合

有时候题目要的不是"多少个"，而是把每一种都列出来。

列举所有组合：用"选或不选"的递归 C++ 
vector<string> items = {"甲", "乙", "丙"};
vector<vector<string>> result;
vector<string> picked;

void choose(int start) {
    if (picked.size() == 2) {          // 已经选够 2 个
        result.push_back(picked);
        return;
    }
    for (int i = start; i < items.size(); i++) {
        picked.push_back(items[i]);
        choose(i + 1);                 // 注意是 i+1，避免重复
        picked.pop_back();             // 回溯：撤销这一步
    }
}

choose(0);
for (auto& r : result) {
    for (string& s : r) cout << s << " ";
    cout << endl;
}
OUTPUT　['甲', '乙']
['甲', '丙']
['乙', '丙']
列举排列只要改一个字母： 把 choose(i + 1, picked) 改成 choose(0, picked)， 并多加一个"是否已选过"的判断——因为排列允许后面再用前面的元素。
组合用 i+1（往后选），排列用 0（从头挑但排除已选）。

故事：王座前的传送带上，物品一个个滑过去：药水、毒药、还有别的杂物。
你要做的只有一件事：看清最上面是什么，然后把它分到该去的地方。
贺舒曼说：注意，你只能看最上面那一个—— 这就是栈。但分类的依据，是"它属于哪一类"。

思路：每次只看栈顶的元素，判断它属于哪一种，再决定送到哪里。 这其实就是在做"分类计数"——每一类有多少个，数一数就出来了。

重点示例：看栈顶，再按类型分流 C++ 
while (peasant.peekItem()) {
    Unit item = peasant.peekItem();      // 只看，不取

    if (item.type == "potion") {         // 属于"药水"这一类
        hero.command(peasant, "dropItem", hero.pos);
    } else if (item.type == "poison") {  // 属于"毒药"这一类
        hero.command(peasant, "dropItem", enemy.pos);
    }
}
要点　peekItem() 只看栈顶；if / elif 把物品分到不同类别
和排列组合的关联： 分类是计数的第一步——先分成互不重叠的几类，才能用加法原理把各类相加。
如果分类分错了（比如某件物品同时属于两类），计数就会重复。
所以"分类"这件事，本质上就是在为"加法原理"做准备。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
排列组合的错，第一错就是"该用组合却用了排列"。四条，看完能救回一大半分。
1
没看清题目问的是排列还是组合。
扣哒鸭：养成习惯：读题时问一句——
把 AB 换成 BA，结果算不算不一样？
"排成一排/排名次/密码"多半是排列；"选几个/组队/挑选"多半是组合。
正确做法：先判断顺序是否重要，再选公式
2
组合数忘了除以 m!。
扣哒鸭：A(n,m) 算出的是排列数， 里面把同一组东西的不同顺序当成不同方案了。
要得到组合数，必须再除以 m!——这一步千万别省。
正确公式：C(n,m) = A(n,m) / m!
3
列举组合时内层还是从 0 开始，导致重复。
扣哒鸭：[甲,乙] 和 [乙,甲] 是同一组！
列举组合时，递归调用要传 i+1（只往后选）。 传 0 就变成排列了。
正确写法：choose(i + 1, picked)
4
算组合数时直接用浮点除法，结果出现小数。
扣哒鸭：数字一大，/ 的精度就不够了， 可能出现 10.000000000000002 这种结果。
整数运算一律用 //，而且组合数每步都能整除，放心除。
正确写法：用 // 做整数除法

8　题目练习

Practice

第 1 题改编自 2026 年 9 月 · C++ 八级 第 2 题，其余为原创练习题。

改编自 2026 年 9 月 · C++ 八级 · 第 2 题单选题
王座厅里 6 个人围成一圈就座，座位没有区分，但区分时针方向，且甲、乙两人必须相邻。
共有（　　）种不同的坐法。
A.24　　B.36　　C.48　　D.120
查看答案与详解
答案：C。圆桌排列分两步算：
① 把"必须相邻"的两人捆成一个整体：这样一来相当于 5 个"单位"围成一圈，圆心排列数是 (5 − 1)! = 4! = 24；
② 甲、乙两人在整体内部还能左右互换，再乘 2：24 × 2 = 48。
所以是 48 种。
为什么圆桌是 (n−1)! 而不是 n!？因为座位没有区分，把整桌人同时旋转一格还是同一种坐法，所以要去掉 n 个重复 ——打个比方：圆桌没有"第一个位置"，谁坐在你左边才重要。
A 错：只算了圆桌排列，忘了两人互换；
B 错：数字对不上，常见于组合与排列混用；
D 错：120 = 5!，那是把圆桌当成一排来排的（直线排列）。
对应小节3 排列数 A(n, m) 与组合数 C(n, m)。
原创练习题单选题
从 5 名同学中选出 2 名分别担任正、副班长，共有多少种选法？（　　）
A.10　　B.20　　C.25　　D.5
查看答案与详解
答案：B。正班长和副班长是不同的职位， (甲正、乙副) 和 (乙正、甲副) 是两种不同的情况——顺序重要，用排列。
A(5, 2) = 5 × 4 = 20。
对比：如果只是"选 2 个人"（不分职务），才是组合 10 种。
对应小节1 顺序重要吗；2 排列。
原创练习题单选题
A(6, 2) 的值是（　　）。
A.12　　B.15　　C.30　　D.36
查看答案与详解
答案：C。A(n, m) = n × (n-1) × … 共 m 个数，
所以 A(6, 2) = 6 × 5 = 30。
容易错的地方：记成 6 的阶乘，或者乘了 3 个数。数清楚要乘几个。
对应小节2 排列：顺序重要。
原创练习题判断题
组合数与排列数满足 C(n, m) = A(n, m) / m!。（　　）
查看答案与详解
答案：正确（√）。排列数把"同一组东西的不同顺序"算成了不同的方案， 数了 m! 遍；
组合只关心"谁在里面"，所以要除以 m! 去掉这层重复。
对应小节3 组合：顺序不重要。
原创练习题单选题
C(8, 2) 的值是（　　）。
A.56　　B.28　　C.16　　D.64
查看答案与详解
答案：B。C(8,2) = 8 × 7 ÷ (2 × 1) = 56 ÷ 2 = 28。
快速算组合数的小技巧：分子从 n 往下乘 m 个数，分母是 m!。
易错点：A 项 56 是排列数 A(8,2)，忘了除以 2。
对应小节3 组合：顺序不重要。
原创练习题判断题
C(10, 3) 与 C(10, 7) 的结果相同。（　　）
查看答案与详解
答案：正确（√）。这是组合数的对称性：C(n,m) = C(n,n-m)。
直观理解："选出 3 个留下"和"挑出 7 个拿走"是同一件事的两种说法。
实用价值：计算时可以把 m 换成较小的那个，少算几步。
对应小节3 组合：顺序不重要。
原创练习题单选题
5 个人站成一排照相，共有多少种站法？（　　）
A.25　　B.60　　C.120　　D.5
查看答案与详解
答案：C。这是"全排列"，也就是 5 的阶乘：
5! = 5 × 4 × 3 × 2 × 1 = 120。
要点："全部排一排"看到就用阶乘。
对应小节4 阶乘与递推。
原创练习题编程题
题目要求：编写程序，① 计算并输出 A(6,3) 与 C(6,3)； ② 列举出从 [1,2,3,4] 中选 2 个的所有组合，并输出组合个数。
查看参考答案与要点 
// ① 计算排列数与组合数
long long A(int n, int m) {
    long long result = 1;
    for (int i = 0; i < m; i++) {
        result = result * (n - i);
    }
    return result;
}

long long fact(int k) {
    long long r = 1;
    for (int i = 1; i <= k; i++) r *= i;
    return r;
}

long long C(int n, int m) {
    return A(n, m) / fact(m);
}

cout << "A(6,3) = " << A(6, 3) << endl;       // 120
cout << "C(6,3) = " << C(6, 3) << endl;       // 20

// ② 列举所有组合
vector<int> items = {1, 2, 3, 4};
vector<vector<int>> result;
vector<int> picked;

void choose(int start) {
    if (picked.size() == 2) {
        result.push_back(picked);
        return;
    }
    for (int i = start; i < items.size(); i++) {
        picked.push_back(items[i]);
        choose(i + 1);           // i+1：只往后选，避免重复
        picked.pop_back();
    }
}

choose(0);
for (auto& r : result) {
    for (int x : r) cout << x << " ";
    cout << endl;
}
cout << "组合个数：" << result.size() << endl;

输出：A(6,3) = 120、C(6,3) = 20； [1,2]、[1,3]、[1,4]、[2,3]、[2,4]、[3,4]；组合个数 6
验证：C(4,2) = 4×3÷2 = 6，与程序列举的个数一致。
要点：
① 排列用"从 n 开始往下乘 m 个数"；组合再除以 m!；
② 列举组合时递归传 i + 1，保证不重复；
③ picked.pop() 是回溯——撤销这一步，才能试下一种；
④ 最后用公式算出的个数和列举的个数对照，是很好的自我检查。
对应小节5 用程序列举。

9　本单元小结

Unit Summary
贺舒曼 · 镜中先知
三句话记住排列组合：
一、先问一句："顺序变了算不算不一样？"——算，就是排列；不算，就是组合。
二、排列 A(n,m) = n × (n-1) × … 共 m 个数；组合再除以 m!。
三、C(n,m) = C(n,n-m)，算的时候取小的那个更快。
列举组合时记住：递归传 i+1，不要传 0。

你在王冠前收获了什么

  • 排列——顺序重要；A(n,m) = n × (n-1) × … （共 m 个数）。
  • 组合——顺序不重要；C(n,m) = A(n,m) / m!。
  • 判断方法——把两个元素交换位置，结果算不算不同。
  • 全排列——A(n,n) = n!，如 5 个人排一排是 120 种。
  • 两个特例——C(n,1) = n；C(n,0) = C(n,n) = 1。
  • 对称性——C(n,m) = C(n,n-m)。
  • 程序列举——组合用"递归传 i+1 + 回溯 pop"；排列则要从头挑并排除已选。
