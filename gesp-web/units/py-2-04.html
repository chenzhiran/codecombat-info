1　多层分支：岔路里的岔路

Nested Branches

先看一个你熟悉的场景：岗哨的卫兵要检查进城的人。

他会先问第一个问题："你是来干什么的？" ——如果回答"送货"，他会接着问第二个问题："有通行证吗？" ——如果回答"来访友"，他会问："谁是你的联系人？"

你看，第二个问题，是在第一个问题的答案里才问的。这就是嵌套分支。

嵌套分支示例 Python 
hp = int(input("请输入血量："))

if hp > 0:
    if hp < 30:
        print("危险！需要治疗")
    else:
        print("状态良好")
else:
    print("英雄倒下了")
运行过程　请输入血量：20　→　危险！需要治疗
三层缩进的读法：
第 1 层（顶格）：外层的 if / else，它们是一家人；
第 2 层（缩进 4 空格）：外层成立后要做的事，里头的 if / else 又是一家人；
第 3 层（缩进 8 空格）：内层成立后要做的事。
同缩进 = 同一伙人；多缩进 = 进了里屋。
服部半藏 · 赤影武士
我们潜入前要先判断：门锁了吗？——锁了，就再判断：有钥匙吗？
你看，第二个问题根本不会在"门没锁"的时候出现。
嵌套就是把问题排好队，一个一个问。一次只问一个，永远不会乱。

2　if-elif-else 综合运用

The if-elif-else Chain

2.1 判断链的顺序

如果情况一次有好几种（比如成绩分档、宝石分级），用 elif 串成一条"判断链"最清爽：

成绩分档（正确顺序） Python 
score = int(input("请输入成绩："))

if score >= 90:          # 最严的条件放最前面
    print("优秀")
elif score >= 60:        # 次严的放中间
    print("及格")
else:                    # 剩下的都归我
    print("不及格")
运行过程　输入 75 → 及格　｜　输入 95 → 优秀
顺序颠倒会出大乱子： 如果写成 if score >= 60 在前、elif score >= 90 在后， 那么输入 95 时，第一条 95 >= 60 就成立了， 程序会立刻输出"及格"，根本不会去看后面那条"优秀"。
牢记：范围越窄、要求越严的条件，越要写在前面。

2.2 常见判断场景

二级的判断题翻来覆去就是这几种，我们一次性认全：

要判断什么怎么写说明
是否是偶数n % 2 == 0除以 2 余数为 0
是否是 3 的倍数n % 3 == 0同理
是否在 1~100 之间1 <= n <= 100Python 支持这种连写
是否同时满足两个条件a > 0 and b > 0两个都要真
是否满足其中之一a == 1 or a == 2一个真就够了
是否不是某个值not (a == 0)等价于 a != 0
字符是否是大写字母'A' <= ch <= 'Z'用 ASCII 顺序比较
Python 的"连写"很好用： 1 <= n <= 100 和 1 <= n and n <= 100 完全等价， 但写起来更短、更不容易错。这种写法只有 Python 才支持，用的时候很得意。

3　用逻辑运算组合条件

Combining Conditions

嵌套分支有个"笨兄弟"——用 and 把两个条件直接拼起来，往往能少写好几行。

同一个判断，两种写法 Python 
hp = 20
gold = 5

# 写法一：嵌套（两层缩进）
if hp > 0:
    if gold >= 10:
        print("可以买药水")

# 写法二：用 and 合并（一层缩进，更清爽）
if hp > 0 and gold >= 10:
    print("可以买药水")
结果　两种写法效果完全一样，都不会输出（因为金币不够）
什么时候用嵌套、什么时候用 and？
条件要"先判断一个，再看要不要问下一个" → 用嵌套；
几个条件地位平等、都要同时成立 → 用 and。
能一行说清的事，就别叠三层。
安雅 · 红发队长
我审新兵的时候只用一句话："十八岁以上、体检合格、愿意守夜"—— 三个条件并列，中间用 and 串起来就行。
要是我真的一层一层嵌套着问，新兵们早排队排到溪谷对岸去了。

4　缩进就是层级

Indentation Is Hierarchy

Python 用缩进表示"谁属于谁"。嵌套越深，缩进越多。 这个规则简单，但它是二级考卷里最容易看走眼的地方。

最容易错的地方： 上图的 else 缩进了 4 格，所以它属于里面那个 if score >= 90， 而不是最外层那个。
看代码时，先对齐缩进，再判断"谁和谁是一对"。

5　代码实战

Level Practice
关卡

村庄守护者

进入关卡 →
故事：溪谷边的村庄有两个入口，一个在左边、一个在右边。 食人魔鬼鬼祟祟，时而在左、时而在右——你没法提前知道它从哪边来。
于是你只能来回巡逻：走到左边的路口看一眼，再走到右边的路口看一眼。 哪边有人，就揍哪边。

思路：看上面的关卡实况——两个村口分别在左和右，你得来回巡逻。 把"循环 + 两次判断"合起来用：每跑到一个路口，就先看一眼有没有敌人。
注意：两个 if 是各自独立判断的—— 左边有没有敌人、右边有没有敌人，互不干扰。

重点示例：一个路口的"看一眼再动手" Python 
while True:
    hero.moveXY(35, 34)                 # 跑到左边路口
    leftEnemy = hero.findNearestEnemy() # 看一眼
    if leftEnemy:
        hero.attack(leftEnemy)
        hero.attack(leftEnemy)

    # 右侧路口照抄一遍，换个变量名即可……
要点　两次变量、两次判断，各自管好自己的那一侧
看仔细：这里有两个变量
leftEnemy 记录左边看到的敌人， rightEnemy 记录右边看到的敌人。
为什么要用两个名字？因为你在左边找完之后又走到了右边， 如果共用同一个变量，它就会被新的结果覆盖，你就分不清哪只是哪只了。 这和一级"名称大师"里那三只木箱是同一个道理。
想一想：如果把第二个 if rightEnemy: 删掉会怎样？ 英雄走到右边就只是站着——看到敌人也不动手，白挨一顿打。 判断写不写，取决于你想不想对那种情况作出反应。

6　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
嵌套分支的错误，99% 都在"数缩进"上。四条，看完你能少熬两小时夜。
1
else 跟错了 if。以为 else 属于最外层，其实它属于里面那个。
扣哒鸭：else 永远和"离它最近、缩进相同的那个 if"配对。 数缩进，别靠感觉。看不准就拿手指头在屏幕上比一比。
正确做法：看缩进格数，同缩进的 if / elif / else 才是一家人
2
判断链顺序写反。把宽松条件写在前面，导致后面的永远执行不到。
扣哒鸭：先严后松。 score >= 90 一定要写在 score >= 60 前面。 写反了程序不会报错，只会安安静静地给你一个错答案——这种错最难发现。
正确做法：范围窄的、要求高的条件放最上面
3
该用 and 的地方硬套两层 if。代码又长又难读。
扣哒鸭：两个条件地位平等、都要成立？那就用 and 一行写完。 嵌套是留给"先看第一步结果、再决定要不要看第二步"的场合。别用大炮打蚊子。
正确写法：if a > 0 and b > 0:
4
用 = 代替 ==，或用 =< 这种不存在的写法。
扣哒鸭：比较要用 ==（两个等号）； "小于等于"要写成 <=，不是 =<，也不是数学课上的 ≤。 中文输入法下的符号 Python 一概不认。
正确写法：if a == 5:　if a <= 100:

7　题目练习

Practice

下面 6 道题围绕多层分支展开，前 2 道改编自真题，后 4 道为原创练习题。

改编自 2026 年 9 月 · Python 一级 · 判断题第 4 题判断题
下列 Python 代码执行时如果先后输入 10 和 10，则将输出 10小于等于10。（　　）
1  N = int(input())
2  M = int(input())
3
4  if N > M:
5      print(f"{N}大于{M}")
6  else:
7      print(f"{N}小于等于{M}")
查看答案与详解
答案：正确（√）。N = 10、M = 10，10 > 10 不成立， 走 else 分支，输出 10小于等于10。
提示：相等的情况落在 else 里，所以 else 的措辞必须是"小于等于"。
对应小节2.1 判断链的顺序。
改编自 2026 年 9 月 · Python 一级 · 第 10 题单选题
下列 Python 代码执行后，其输出是（　　）。
1  for i in range(1,5):
2      if i % 3 == 0:
3          print(i, end = "+")
4          continue
5      else:
6          print(i, end = "-")
7      break
8  print(i, "END", end = "#")
A.1-1　　B.1+1 END#　　C.1+1-2-2 END#　　D.1-1 END#
查看答案与详解
答案：D。i = 1 时 1 % 3 == 0 不成立 → 走 else，输出 1-； 接着执行 break，跳出整个循环。此时 i 仍为 1，最后输出 1 END#。
关键：break 写在 if-else 之外，所以第一轮就会结束整个循环。
对应小节2.1 判断链的顺序；4 缩进就是层级。
原创练习题单选题
下列 Python 代码执行后，输出的结果是（　　）。
1  score = 95
2
3  if score >= 60:
4      print("及格")
5  elif score >= 90:
6      print("优秀")
7  else:
8      print("不及格")
A.及格　　B.优秀　　C.及格优秀　　D.不及格
查看答案与详解
答案：A。判断链从上往下、命中即停： 95 >= 60 首先成立，于是输出"及格"，后面那条永远不会被检查。
正确写法：把 if score >= 90: 写在最前面。
对应小节2.1 判断链的顺序。
原创练习题单选题
下列 Python 代码执行后，输出的结果是（　　）。
1  a = 7
2
3  if a > 0:
4      if a % 2 == 0:
5          print("正偶数")
6      else:
7          print("正奇数")
8  else:
9      print("非正数")
A.正偶数　　B.正奇数　　C.非正数　　D.什么都不输出
查看答案与详解
答案：B。先看外层：7 > 0 成立，进入内层； 再看内层：7 % 2 == 0 不成立（7 是奇数），所以走内层的 else， 输出 "正奇数"。
易错点：第 7 行的 else 缩进 4 格，属于内层 if； 第 8 行的 else 顶格，属于外层 if。两者不是一回事。
对应小节1 多层分支；4 缩进就是层级。
原创练习题判断题
在 Python 中，1 <= n <= 100 与 1 <= n and n <= 100 的判断结果完全一样。（　　）
查看答案与详解
答案：正确（√）。Python 允许把区间判断"连写"， 1 <= n <= 100 就是"n 同时大于等于 1 且小于等于 100"。
注意：这种连写是 Python 的特色（有些语言不支持）， 在其他语言里写成这样可能会得到完全不同的结果。
对应小节2.2 常见判断场景。
原创练习题编程题
题目要求：输入一个整数，按下表规则输出它的类型—— 大于 0 且是偶数输出 正偶数；大于 0 且是奇数输出 正奇数； 等于 0 输出 零；小于 0 输出 负数。
查看参考答案与要点 
n = int(input("请输入一个整数："))

if n > 0:
    # 正数里再分奇偶
    if n % 2 == 0:
        print("正偶数")
    else:
        print("正奇数")
elif n == 0:
    print("零")
else:
    print("负数")

要点：
① "正数里再分奇偶"这一步必须用嵌套——因为奇偶只在正数范围内讨论；
② 也可以写成 if n > 0 and n % 2 == 0: 的两条并列判断， 但嵌套写法更贴近"先判断正负，再判断奇偶"的思路；
③ 注意 elif n == 0 和最后的 else 要顶格书写。
对应小节1 多层分支；2.2 常见判断场景。

8　本单元小结

Unit Summary
贺舒曼 · 镜中先知
分歧越长，越需要秩序。记住三句话：
一、嵌套就是"先问一个，再问下一个"；缩进几格，就在第几层。
二、判断链从上往下、命中即停，所以要"先严后松"。
三、条件平等就用 and 并列，别硬叠三层。
你们现在已经能写出"会思考"的程序了——下一单元，我们让它学会"重复地思考"。

你在双岔迷宫学到了什么

  • 嵌套分支——分支里面再写分支；外层的答案决定要不要问内层。
  • 缩进即层级——同缩进的 if / elif / else 是一家人，多缩进一层就是进了里屋。
  • 判断链——if - elif - else 从上往下判断，命中即停，所以要先严后松。
  • 逻辑组合——and 全真才真、or 一真则真、not 取反。
  • 常见判断——奇偶用 % 2，区间可用连写 1 <= n <= 100。
  • 两个变量的用处——左边一只、右边一只，互不覆盖。
