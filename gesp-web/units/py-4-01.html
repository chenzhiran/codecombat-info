1　什么是"嵌套"

What Is Nesting

1.1 什么是"嵌套"

"嵌套"这个词听着吓人，意思其实很朴素：把容器放进容器里。

1.2 一句话理解

打个比方： 嵌套就像大箱子里面装小箱子——要拿到最里面那个东西，得先开大箱子，再开小箱子。
每多套一层，就要多"开"一次：
开 1 次 = 一层；开 2 次 = 两层；a[1][2] 就是"先开第 1 个大箱，再从里面拿第 2 样东西"。
一句话理解： 普通列表的元素是数字或字符串；嵌套列表的元素还是一个列表。
访问的时候，就得一层一层往下写：先取外层，再取内层。

2　列表里放列表

List of Lists

2.1 二维列表怎么读

嵌套列表的创建与访问 Python 
grid = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

print(grid[0])        # 第 0 个元素：整个小列表 [1, 2, 3]
print(grid[0][0])     # 先取第 0 个小列表，再取它的第 0 个 → 1
print(grid[1][2])     # 第 1 个小列表的第 2 个 → 6
print(grid[2][1])     # 第 2 个小列表的第 1 个 → 8

print(len(grid))      # 外层有 3 个元素
print(len(grid[0]))   # 第 0 个小列表里有 3 个元素
OUTPUT　[1, 2, 3]
1
6
8
3
3

2.2 读法口诀

读法口诀： grid[1][2] 从右往左读——"先取第 1 个箱子，再取里面第 2 格"。
就像说"二楼的第三个房间"：先说楼层，再说房间号。

动手改一个元素

修改嵌套列表里的元素 Python 
grid = [[1, 2], [3, 4]]

grid[0][1] = 99       # 把第 0 个小列表的第 1 个改成 99
print(grid)           # [[1, 99], [3, 4]]
OUTPUT　[[1, 99], [3, 4]]

3　列表里放字典

List of Dictionaries

3.1 字典装得下"有名字的东西"

有时候光靠位置不够用。比如描述一个"士兵"，他有名字、有血量、有攻击力—— 用字典装，比用列表清楚得多。

字典：用"键"来取"值" Python 
soldier = {"name": "塔林", "hp": 100, "atk": 25}

print(soldier["name"])    # 塔林
print(soldier["hp"])      # 100

soldier["hp"] = 80        # 直接改
print(soldier)            # {'name': '塔林', 'hp': 80, 'atk': 25}
要点　字典用{}写，键和值用冒号隔开；访问用字典[键]

3.2 列表和字典各管什么

列表 vs 字典： 列表靠"位置"找东西——a[0] 是第 0 个；
字典靠"名字"找东西——d["name"] 是名字对应的值。
位置会变，名字不会变——这就是字典存在的理由。

3.3 列表里放字典

把好几个字典放进一个列表，就成了最常见的一种嵌套结构：

列表里装字典 Python 
team = [
    {"name": "塔林", "hp": 100},
    {"name": "安雅", "hp": 80},
    {"name": "艾达", "hp": 60}
]

print(team[1]["name"])     # 第 1 个字典的 name → 安雅
print(team[2]["hp"])       # 第 2 个字典的 hp → 60

# 遍历：先拿到每个字典，再取字段
for member in team:
    print(member["name"], member["hp"])
OUTPUT　安雅

4　一步步"拆"开数据

Reading Nested Data

4.1 一层一层拆开

面对复杂结构，最稳的办法是别一口气写完，一步一步拆：

先拆成中间变量，更不容易错 Python 
data = [{"id": 1}, {"id": 2}, {"id": 3, "items": ["剑", "盾"]}]

# 一步写完（能懂但容易看错）
print(data[2]["items"][0])

# 拆成两步（更清楚，调试也方便）
node = data[2]
print(node["items"][0])
OUTPUT　剑
剑

4.2 拆数据的建议

实用建议： 考试时看代码，如果一行里有三四个中括号，就在草稿纸上标注每一层取出的是什么。
写代码时，宁可多写一行中间变量，也别硬堆成一行—— 代码是给人看的，顺便给机器跑。

5　遍历嵌套数据

Traversing Nested Data

5.1 嵌套结构要用嵌套循环

嵌套结构要用嵌套循环来遍历——外层管"哪个箱子"，内层管"箱子里的第几格"。

双重循环遍历二维数据 Python 
grid = [[1, 2, 3], [4, 5, 6]]

for i in range(len(grid)):          # 外层：第几个小列表
    for j in range(len(grid[i])):   # 内层：小列表里的第几个
        print(grid[i][j], end=" ")
    print()                         # 一行打完就换行
OUTPUT
1 2 3
4 5 6

5.2 外层管箱子，内层管格子

嵌套遍历的核心： 外层循环走一步，内层循环跑一整轮。
这里外层是 2 次（两个小列表），内层每次都跑 3 次（每个小列表有 3 个元素）， 所以内层的语句一共执行 2 × 3 = 6 次。
遍历"列表装字典" Python 
team = [
    {"name": "塔林", "hp": 100},
    {"name": "安雅", "hp": 80}
]

total = 0
for member in team:               # 直接拿到每个字典
    print(member["name"], member["hp"])
    total = total + member["hp"]  # 顺手累加血量

print("总血量：", total)
OUTPUT　塔林 100
安雅 80
总血量：180

故事：高台的图书室里，贺舒曼被食人魔伏击了。她正忙着救治伤员， 得靠你来指挥队伍。

戈登翻着名册说：把它们当成一组数据，用循环一次指挥一整队。

思路：先用 findByType() 拿到**一个装着所有同类单位的数组**， 再用循环逐个下命令。这正是"复合数据 + 遍历"的典型用法。

重点示例：拿到一组单位，逐个指挥 Python 
# 拿到"所有士兵"这一整个数组
soldiers = hero.findByType("soldier")
archers  = hero.findByType("archer")

# 用循环逐个下命令——数组里有多少个，就指挥多少个
for i in range(len(soldiers)):
    soldier = soldiers[i]
    commandSoldier(soldier, i, len(soldiers))
要点　findByType 返回的是数组；用下标配合 len() 就能遍历
这里其实有三层"复合"： ① soldiers 是一个数组；
② 数组里每个元素是一个单位对象（相当于一个带属性的字典）；
③ 传给 commandSoldier 的坐标又是一个 {"x":..., "y":...} 字典。
看懂这三层，你就掌握了四级最核心的读代码能力。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
嵌套结构的错误，几乎全是"少写了一层括号"。四条，看完你就能少调半天。
1
忘了第二层下标。把 grid[0] 当成一个数字用。
扣哒鸭：grid[0] 拿到的是一整个小列表，比如 [1,2,3]。
要拿里面的数字，还得再写一层：grid[0][0]。
正确理解：外层下标取容器，内层下标取数据
2
字典用位置访问。写成 soldier[0]。
扣哒鸭：字典要用键来取，不是位置：soldier["name"]。
写 soldier[0] 会报 KeyError——字典里根本没有叫 0 的键。
正确写法：d["键名"]
3
遍历嵌套列表时越界。内层写成 range(len(grid))。
扣哒鸭：内层要数的是当前这一行的长度： range(len(grid[i]))。
写成 len(grid) 是外层行数，如果每行元素更少，就会下标越界。
正确写法：for j in range(len(grid[i])):
4
以为 a = b 是复制了一份。改 a 时把 b 也改了。
扣哒鸭：对列表和字典来说，a = b 只是又贴了一张标签， 它们指的是同一个东西。
想真的复制一份，要用 a = b[:]（列表）或 a = b.copy()。 这个坑在四级很常见。
正确做法：要独立副本就用切片或 copy()

改编自 2026 年 9 月 · Python 四级 · 第 3 题单选题
齿轮高台的货架上挂着复合数据：外层是列表，里面既套着字典、又套着列表。
执行下面 Python 代码后，输出的结果是（　　）。
1  original = [{'key': 'value'}, [4, 5, 6]]
2  new = original.copy()
3  new[0]['key'] = 'new_value'
4  new[1].append(7)
5  print(original[0]['key'], original[1][-1])
A.value 6　　B.new_value 7　　C.value 7　　D.new_value 6
查看答案与详解
答案：B。list.copy() 是浅拷贝：它只复制了外层列表，里面套着的字典和列表还是同一份。
所以 new[0]['key'] = 'new_value' 改的是同一个字典，原数据跟着变；new[1].append(7) 同理，原列表也多了个 7，original[1][-1] 就成了 7。
打个比方：浅拷贝就像"复印了文件夹的目录页"——目录页是新的，但里面夹着的文件还是原来那几张，改文件两边都看得见。
想真正独立要用 copy.deepcopy()。

原创练习题编程题
题目要求：已知 team = [{"name": "塔林", "hp": 100}, {"name": "安雅", "hp": 80}, {"name": "艾达", "hp": 60}]， 编程输出：① 每个成员的姓名与血量；② 血量最高者的姓名。
查看参考答案与要点 
team = [
    {"name": "塔林", "hp": 100},
    {"name": "安雅", "hp": 80},
    {"name": "艾达", "hp": 60}
]

# ① 逐个输出
for m in team:
    print(m["name"], m["hp"])

# ② 找血量最高的人
best = team[0]
for m in team:
    if m["hp"] > best["hp"]:
        best = m

print("血量最高：", best["name"])

输出：塔林 100、安雅 80、艾达 60、血量最高：塔林
要点：
① 遍历"列表装字典"时，循环变量 m 拿到的是整个字典，要用键取值；
② 求最值时初值取 team[0]（整个字典），比较时用 m["hp"]；
③ 最后输出的是 best["name"]，而不是整个字典。

Unit Summary
戈登 · 齿轮工程师
三句话，够你用一整章：
一、嵌套就是"容器里装容器"，取数据要一层一层往下写。
二、列表靠位置，字典靠名字——描述一个"东西"时字典更清楚。
三、遍历嵌套用双重循环：外层管箱子，内层管格子。
读代码时如果晕，就在草稿纸上把每一层写出来。

你在传送带枢纽收获了什么

  • 嵌套——把列表、字典放进另一个容器里，形成更复杂的结构。
  • 列表里放列表——[[1,2],[3,4]]；访问用 a[1][0] 这样层层下标。
  • 字典——{"键": 值}，靠名字取值：d["hp"]；改值也是直接赋值。
  • 列表里放字典——描述"一组有字段的对象"最常用的写法。
  • 分步拆解——复杂访问先赋值给中间变量，比堆一行中括号清楚得多。
  • 嵌套遍历——双重循环；内层要用 len(外层[i])，别用 len(外层)。
  • 引用陷阱——a = b 只是贴标签，要真复制用 b[:] 或 b.copy()。
