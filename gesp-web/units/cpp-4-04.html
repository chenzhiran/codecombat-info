1　重复的活儿该怎么办

Why Functions

1.1 没有函数会怎样

要三次给英雄加血，只好抄三遍 C++ 
// 没有函数：同样的代码抄了三遍
cout << "正在治疗..." << endl;
hero.hp += 10;
if (hero.hp > 100) hero.hp = 100;
cout << "治疗完成" << endl;

cout << "正在治疗..." << endl;
hero.hp += 10;
if (hero.hp > 100) hero.hp = 100;
cout << "治疗完成" << endl;

cout << "正在治疗..." << endl;
hero.hp += 10;
if (hero.hp > 100) hero.hp = 100;
cout << "治疗完成" << endl;
三个麻烦　 ① 代码又长又啰嗦；② 改一处要改三处；③ 抄第三遍时手一抖就可能写错
用函数：写一次，用三次 C++ 
void heal() {
    cout << "正在治疗..." << endl;
    hero.hp += 10;
    if (hero.hp > 100) hero.hp = 100;
    cout << "治疗完成" << endl;
}

// 主程序里只要喊三次名字
heal();
heal();
heal();
好处立竿见影　要改治疗量？只改函数里的那一处就行

1.2 函数带来的三个好处

函数带来的三个好处： ① 少写——同样的活儿，写一次，用很多次。
② 好改——要调整逻辑，只改定义的那一处，所有调用处一起生效。
③ 好懂——主程序变成一句句"喊名字"，一眼能看出流程，不用被细节淹没。
这就是"模块化"：把一个复杂的大问题，拆成几个各自独立的小功能。
打个比方： 函数就像车间里一台做好的机器——只要把料从这头送进去，成品就从那头出来。
你不需要每次都重新造一台机器，也不需要知道机器里怎么转的；
想用的时候，喊它的名字、把料给它就行。

2　定义与调用

Defining & Calling

2.1 定义一台机器

函数定义的四个部分 C++ 
int add(int a, int b) {      // ①返回类型 ②函数名 ③参数列表
    int s = a + b;           // ④函数体
    return s;                // 把结果交出去
}

int main() {
    int x = add(3, 5);       // ★ 调用：喊名字 + 传参数
    cout << x << endl;        // 8
    cout << add(10, 20) << endl;  // 30  直接用返回值
    return 0;
}
OUTPUT　8 / 30
四要素　返回类型、函数名、参数列表、（大括号里的）函数体
最容易忘的两件事： ① 函数写完不会自动执行——必须有人调用它。 只定义不调用，函数体里的代码一行都不会跑。
② 大括号后面不要写分号—— int add(int a, int b) { ... }; 多这个分号虽然多数情况下能过， 但在有些编译器上会带来麻烦，养成不写的习惯。
（对比记忆：结构体定义要分号，函数定义不要分号。）

2.2 返回类型与 return

返回类型含义例子
int、double、char 等函数会交回一个该类型的值int add(int a, int b)
bool交回"真 / 假"bool isPrime(int n)
void什么都不交回，只是"干件事"void heal()
return 的两个作用： ① 交回一个值——return s; 把 s 交给调用者。
② 立刻结束函数——return 之后的代码一律不再执行。
而且 return 只能交回一个值—— 想要"带出多个结果"，得靠后面要学的引用参数或指针。

3　参数：给函数带东西进去

Parameters

3.1 形参与实参

上面的 heal() 每次都加 10。如果想加不同的量呢？用参数。

加上参数，机器就灵活了 C++ 
void heal(int amount) {          // amount 是"形参"
    hero.hp += amount;
    if (hero.hp > 100) hero.hp = 100;
}

heal(10);                        // 10 是"实参"
heal(30);                        // 加 30
heal(5);                         // 加 5
区别　 形参——函数定义时写在括号里的"占位符"；
实参——函数调用时真正传进去的值
两个名字要分清： 形参（parameter）——定义时写的，是"接货的筐"，本身没有值。
实参（argument）——调用时给的，是"真正送进去的货"。
程序运行时，实参的值被复制给形参——这就是"值传递"。
所以函数里改形参，外面那个实参不会跟着变（这一点上一单元用指针解决过）。

3.2 多个参数与默认值

参数可以有多个，也可以有默认值 C++ 
// 多个参数：用逗号隔开，每个都要写类型
int maxOf(int a, int b) {
    return a > b ? a : b;
}
cout << maxOf(3, 7) << endl;         // 7

// 默认参数：调用时可以不写
void greet(string name, string hi = "你好") {
    cout << hi << "，" << name << endl;
}
greet("小明");                        // 你好，小明
greet("小红", "早上好");               // 早上好，小红
两个要点　 ① 每个参数都要单独写类型：int a, int b，不能写 int a, b；
② 默认参数必须放在参数列表的最右边
参数个数必须对上。 定义了 int add(int a, int b)，调用时写成 add(3) 编译就过不去——少给了一个参数。
写成 add(3, 5, 7) 也不行——多给了。
只有"有默认值"的参数才可以省略。

4　返回值：把结果带出来

Return Values

4.1 有返回值的函数

很多函数不是"干件事"，而是"算个结果给你"。这时候就要用 return。

返回值可以被"接着用" C++ 
int square(int n) {
    return n * n;
}

// 返回值能直接参与运算
int total = square(3) + square(4);
cout << total << endl;         // 9 + 16 = 25

// 也能作为别的函数的参数
cout << square(square(2)) << endl;   // square(4) = 16

// 也能直接输出
cout << square(5) << endl;     // 25
OUTPUT　25 / 16 / 25
关键　有返回值的函数调用，本身就是一个"值"，可以像变量一样用

4.2 return 与 void

写法含义怎么用
int f() { return 5; }交回一个值int x = f();
void f() { cout << "hi"; }什么都不交回f(); 不能写 int x = f();
return;（在 void 函数里）只是提前结束函数常用于"不满足条件就退出"
必考：return 和 cout 的区别。 cout 是"说给人听"——把内容显示在屏幕上， 程序里拿不到它的结果。
return 是"把东西交给程序"——调用者可以接着用它做运算、比较、传参。
举个例子：
void f() { cout << 5; } —— 屏上显示出 5，但你没法写 f() + 1；
int g() { return 5; } —— g() + 1 就是 6，可以随便参与运算。
一句话：cout 是"喊出来"，return 是"递过去"。

5　函数声明

Declaration

5.1 为什么要先声明

把定义写在后面会怎样？ C++ 
// ✘ 这样写在 C++ 里会报错
int main() {
    cout << add(3, 5);      // 编译器这时还不知道 add 是什么
    return 0;
}

int add(int a, int b) {     // 定义在后面
    return a + b;
}
原因　C++ 是"从上往下读"的——读到调用那一行时， 编译器还没见过 add，不知道它有几个参数、返回什么类型
加上一行声明就好了 C++ 
int add(int a, int b);      // ★ 函数声明（也叫"函数原型"）
                            //    只有分号，没有函数体

int main() {
    cout << add(3, 5) << endl;   // 8
    return 0;
}

int add(int a, int b) {     // 定义写在后面
    return a + b;
}
声明和定义的区别　 声明——"有这么个函数，长这样"，末尾是分号；
定义——"它具体做什么"，末尾是大括号

5.2 声明与定义分离

一句话回答那道判断题： 一个函数必须在调用之前既声明又定义——这句话是错的。
准确的说法是：函数必须在调用之前"被声明"。
而"定义"可以写在后面，甚至可以写在另一个文件里（那是更大的工程才需要的）。
当然，"声明 + 定义"合在一起写（也就是把完整定义放前面）也满足"先声明"， 所以那样写当然也对——但不能说"必须两者都有"。
为什么工程里喜欢"声明放前面、定义放后面"？ 因为这样函数之间可以互相调用，而不用操心谁先谁后。
把所有函数声明集中写在文件开头，就等于给编译器一张"目录"： 之后不管谁调用谁，编译器都已经认识它们了。
这也是大型项目里 .h 头文件存在的原因。

之后你只要喊名字就行了。他说，这就是函数最大的用处：让主程序变得清爽。

思路：把"去某个坐标、把附近的东西捡起来"封进一个函数， 主程序里就只剩下一句句"喊名字"。

把重复动作封成函数 C++ 
#include <iostream>
using namespace std;

// 去 (x, y) 这个位置，并把附近的东西捡起来
void gotoAndGet(int x, int y) {
    hero.moveXY(x, y);

    int item = hero.findNearestItem();
    if (item) {
        hero.moveXY(item.pos.x, item.pos.y);
    }
}

int main() {
    // 主程序只剩下"喊名字"，一目了然
    gotoAndGet(20, 35);
    gotoAndGet(60, 35);
    gotoAndGet(60, 10);
    gotoAndGet(20, 10);

    return 0;
}
对比一下　 如果不用函数，主程序里就要把"移动 + 找东西 + 再移动"抄四遍——
现在只剩四行，一眼就能看出"去了哪四个点"
和本单元的关系： 函数最重要的价值不是"少打字"，而是"让主程序能被人一眼读懂"。
看这一行 gotoAndGet(20, 35);，你立刻知道它在干什么； 而如果换成五行的具体动作，你就得逐行去读。
这就是"模块化"：把细节收进机器里，把意图留在外面。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
函数的错，一半是"忘了调用"，一半是"return 和 cout 分不清"。四条。
1
只写了函数定义，忘了调用。
扣哒鸭：函数定义完只是"把机器造好放在那儿"， 它不会自己启动。
int main() 里必须喊一声它的名字，函数体才会执行。
正确做法：定义完别忘了在需要的地方调用
2
把 cout 当成了返回值。
扣哒鸭：cout 只是把内容显示在屏幕上， 它没有把任何东西交给调用者。
想让调用处拿到值，必须写 return。
分清：要显示用 cout，要交回值用 return
3
有返回值的函数忘了 return。
扣哒鸭：返回类型写的是 int， 函数体里却一个 return 都没有——
调用处会拿到一个"不确定的值"，结果完全不可预测。
更麻烦的是，很多编译器不报错。
检查：返回类型不是 void，就必须有 return
4
在 void 函数里用返回值。
扣哒鸭：void 的意思是"什么都不交回"。
所以要写成 f();，不能写 int x = f();——编译器会直接报错。
另外，参数个数也必须对上，多一个少一个都不行。
记牢：void 函数不能取值；参数个数要匹配

8　题目练习

Practice

前 2 题改编自 C++ 四级真题，其余为原创练习题。

改编自 2026 年 6 月 · C++ 四级 · 判断题 第 2 题判断题
一个函数必须在被调用之前既声明又定义。（　　）
查看答案与详解
答案：错误（×）。C++ 的要求是：函数在调用之前必须"被声明"， 但"定义"可以放在后面。
声明只要一行，末尾是分号：int add(int a, int b);
定义才带函数体，末尾是大括号。
正确写法：把声明放在文件开头，定义放在后面（或者放别的文件里）。
为什么这句话容易被判错？因为很多人习惯"把完整定义写在 main 前面"， 那确实同时满足了声明和定义——但那是"也行"，不是"必须"。 题目里"必须既……又……"这种绝对说法，往往是错的。
对应小节5.1 为什么要先声明。
改编自 2026 年 9 月 · C++ 四级 · 判断题 第 4 题判断题
执行下面程序后，输出为 20。（　　）
void change(int x) { x = 20; }
int main() {
    int x = 10;
    change(x);
    cout << x;
    return 0;
}
查看答案与详解
答案：错误（×）。输出是 10。
原因：C++ 默认的参数传递是"值传递"——调用 change(x) 时， 把外面 x 的值复制一份给了形参。
函数里的 x 是"另一个变量"，改它不影响外面那个。
函数一返回，那个副本就销毁了，外面的 x 从头到尾都是 10。
想让函数真的改到外面的变量，得传指针： void change(int *p) { *p = 20; }， 调用时写 change(&x);。
对应小节3.1 形参与实参。
原创练习题单选题
关于返回值和输出，下面说法正确的是（　　）。
A.函数里只要用了 cout，调用处就能拿到那个值
B.void 类型的函数不能有返回值，调用时也不能把它当成一个值来用
C.一个函数可以有多个 return，每次返回多个值
D.函数里写不写 return 都一样，编译器会自动返回最后一个变量
查看答案与详解
答案：B。void 的含义就是"不交回任何值"， 所以调用它只能写成 f();， 不能写 int x = f();。
A 错：cout 只负责"显示"，不会把值交给调用者。 要交回值必须用 return。
C 错：一个函数里确实可以出现多个 return（在不同分支里）， 但每次执行只会走其中一个，而且一次只能交回一个值。
D 错：返回类型不是 void 时必须有 return， 否则调用处会拿到一个不确定的值。
对应小节4.2 return 与 void。
原创练习题单选题
执行下面的代码，输出是（　　）。
int f(int n) {
    if (n <= 0) return 0;
    return n + f(n - 1);
}
cout << f(3) << endl;
A.3　　B.6　　C.9　　D.死循环
查看答案与详解
答案：B。这个函数"自己调用自己"，把问题一步步缩小：
f(3) = 3 + f(2)
f(2) = 2 + f(1)
f(1) = 1 + f(0)
f(0) = 0　← 这里触发了"出口"，不再往下递归
倒着加回来：0 → 1 → 3 → 6。
关键在这个"出口"：if (n <= 0) return 0;—— 没有它，函数就会无限地自己调自己（D 项）。
顺便注意：函数里出现了两个 return， 但每次执行只会走其中一个——这正好印证了上一题的 C 项。
对应小节4.1 有返回值的函数（这也是下一单元"递推与递归"的起点）。
原创练习题判断题
在 C++ 中，函数定义时参数列表里每个参数都必须单独写明类型， 写成 int add(int a, b) 是不允许的。（　　）
查看答案与详解
答案：正确（√）。函数定义（和声明）的参数列表里， 每个参数都要自己带类型。
正确写法：int add(int a, int b)
错误写法：int add(int a, b) —— 编译器不认识 b 是什么类型，直接报错。
对比一下变量的定义：int a, b; 是合法的， 因为类型只写一次就够。
但函数参数列表里不行——这是这两处语法的一个显著差别，很容易踩。
对应小节3.2 多个参数与默认值。
原创练习题编程题
题目要求：写一个函数 bool isPrime(int n) 判断 n 是否为质数；在 main 里读入一个整数并输出判断结果 （是质数输出 yes，否则输出 no）。
查看参考答案与要点 
#include <iostream>
using namespace std;

bool isPrime(int n) {
    if (n < 2) return false;            // 小于 2 的都不是质数
    for (int i = 2; i * i <= n; i++) {  // 只试到 √n
        if (n % i == 0) return false;   // 找到一个因数，立刻结束
    }
    return true;                        // 全试完都没找到 → 是质数
}

int main() {
    int n;
    cin >> n;
    cout << (isPrime(n) ? "yes" : "no") << endl;
    return 0;
}

输入 17 输出：yes；输入 1 输出：no；输入 25 输出：no
要点：
① 返回类型用 bool，因为答案只有"是 / 不是"两种； 调用处就能直接写 if (isPrime(n))；
② "提前 return"是很好的写法——一旦确定不是质数就直接返回， 不用再白跑后面的循环；
③ 循环条件写 i * i <= n 而不是 i <= n—— 因为大于 √n 的因数一定有个小于 √n 的同伴，试到 √n 就够了；
④ n < 2 的边界必须单独处理—— 0 和 1 都不是质数；
⑤ 主程序里用三目运算符一行搞定输出。

9　本单元小结

Unit Summary
奥卡 · 石臂守卫
四句话记住函数：
一、函数把一段代码打包成"机器"——写一次、用多次、改一处。
二、定义写"返回类型 名字(参数列表) { 函数体 }"；只定义不调用，它不会执行。
三、形参是接货的筐，实参是真正送进去的货；值传递时改形参不影响实参。
四、return 把值交给程序，cout 只是显示给人看——这两者绝不能混。
机器造好了。下一站我们钻进输送管里，看看参数到底是"怎么被送进去"的。

你在模块化车间收获了什么

  • 函数——把一段代码打包成可重复使用的"机器"，写一次、用多次、改一处。
  • 三个好处——少写、好改、让主程序一眼读懂。
  • 定义的四个部分——返回类型、函数名、参数列表、函数体。
  • 不调用不执行——只定义函数，函数体里的代码一行都不会跑。
  • 形参 vs 实参——定义时写的是形参，调用时给的是实参；值传递是复制。
  • 参数规则——每个参数都要单独写类型；个数必须匹配；默认参数放最右边。
  • return 的两个作用——交回一个值；立刻结束函数。
  • return vs cout——return 是"递过去"（程序能接着用），cout 是"喊出来"（只显示）。
  • void——什么都不交回；不能当作值来使用。
  • 函数声明——调用之前只需"声明"，不必"既声明又定义"。
  • 声明与定义的区别——声明的末尾是分号，定义的末尾是大括号。
  • 递归的雏形——函数可以调用自己，但必须有出口。
