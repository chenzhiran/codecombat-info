1　重复的活儿该怎么办

The Problem of Repetition

1.1 没有函数会怎样

先看一段"没有函数"的代码。假设要三次给英雄加血：

复制粘贴三遍 Python 
hero.say("正在治疗……")
hero.health = hero.health + 10
hero.say("治疗完成！")

hero.say("正在治疗……")
hero.health = hero.health + 10
hero.say("治疗完成！")

hero.say("正在治疗……")
hero.health = hero.health + 10
hero.say("治疗完成！")
问题　如果想把"加 10"改成"加 20"，你得改三个地方——漏掉一个就出 bug
封装成函数：只写一遍 Python 
def heal():
    hero.say("正在治疗……")
    hero.health = hero.health + 10
    hero.say("治疗完成！")

heal()      # 调用一次
heal()      # 再调用一次
heal()      # 再来一次
好处　改一处、处处生效；代码也短了一大截

1.2 函数带来的三个好处

打个比方： 函数就像车间里一台做好的机器——只要把料从这头送进去，成品就从那头出来。
你不需要每次都重新造一台机器，也不需要知道机器里怎么转的；
想用的时候，喊它的名字、把料给它就行。
函数带来的三个好处：
① 复用——写一次，用很多次；
② 易改——要改逻辑只需改一个地方；
③ 易读——heal() 比五行代码更能说明"我在干什么"。
这三条，就是"模块化编程"的全部理由。

2　定义与调用

Define & Call

2.1 定义与调用

函数的标准样子 Python 
def 函数名():
    语句1
    语句2
    ...

# 调用
函数名()
三个细节　① def 后面要写冒号　② 函数体必须缩进　③ 调用时要带括号

2.2 最容易忘的两件事

最容易忘的两件事： 冒号和缩进。
少写冒号 → SyntaxError；函数体没缩进 → 它就不属于这个函数了，会立刻执行。

3　参数：给函数带东西进去

Parameters

3.1 参数：把东西带进去

上面的 heal() 每次都加 10。如果想加不同的量呢？用参数。

带参数的函数 Python 
def heal(amount):              # amount 是"形参"，是个占位符
    hero.say("正在治疗……")
    hero.health = hero.health + amount
    hero.say("治疗完成！")

heal(10)                       # 把 10 交给 amount
heal(30)                       # 把 30 交给 amount
heal(5)                        # 把 5 交给 amount
输出　依次执行"加 10、加 30、加 5"的治疗流程

3.2 形参与实参

两个名字要分清： 形参——定义时括号里写的名字（amount），只是占位；
实参——调用时真正传进去的值（10、30），是真实数据。
调用的时候，实参会"对号入座"地交给形参。
多个参数与默认值 Python 
def rect(w, h):                  # 两个参数
    print(w * h)

rect(3, 4)                       # 12

def greet(name, times=1):        # times 有默认值
    for i in range(times):
        print("你好，", name)

greet("安雅")                    # 只传一个，times 用默认值 1
greet("塔林", 3)                 # 两个都传，times 变成 3
要点　有默认值的参数必须写在后面；调用时不传就用默认值

4　返回值：把结果带出来

Return Values

4.1 返回值：把结果带出来

很多函数不是"干件事"，而是"算个结果给你"。这时候就要用 return。

有返回值的函数 Python 
def add(a, b):
    return a + b          # 把结果"交出去"

result = add(3, 5)        # 用变量接住返回值
print(result)             # 8

print(add(10, 20) + 1)    # 返回值可以直接参与运算 → 31
OUTPUT　8
31

4.2 return 和 print 的区别

return 和 print 的区别（必考）： print 是"给人看"——把东西显示在屏幕上；
return 是"给程序用"——把结果交回调用处，可以继续参与运算。
把 print 当成 return 用，是四级最常见的失分点。

故事：高台边缘，一群食人魔正围着诱饵转圈。它们很谨慎—— 只有你受伤了，它们才敢追上来。
所以战术很清楚：先判断"我是不是伤得够重"，再决定跑还是打。
戈登把一张工序卡拍在你手上：这个判断你要用好几次，把它写成函数。

思路：把"该不该跑"这个判断封装成一个函数，

让它返回 True 或 False。主循环里直接调用它，代码立刻清爽。

重点示例：写一个返回判断结果的函数 Python 
def shouldRun():
    if hero.health < hero.maxHealth / 2:
        return True
    else:
        return False

while True:
    if shouldRun():          # 直接当条件用，读起来像一句话
        hero.moveXY(75, 37)
    else:
        enemy = hero.findNearestEnemy()
        if enemy:
            hero.attack(enemy)
要点　返回 True/False 的函数，可以直接放进 if 里当条件
这段代码还可以更简洁： def shouldRun(): return hero.health < hero.maxHealth / 2
因为比较表达式本身就是 True 或 False，不用再写 if-else。
但考试时写清楚一点也没关系——可读性永远不吃亏。

6　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
函数的错最好查——报错信息通常直接告诉你行号。但这四条，报错都不明显。
1
忘了写调用，只写了定义。程序什么都不输出。
扣哒鸭：定义只是"记下来"，不会执行。 你写完了 def greet():，还得在下面写一句 greet()。
这是学生最常犯的第一个函数错误。
正确做法：定义之后必须写调用语句
2
调用时忘了带括号。写 greet 而不是 greet()。
扣哒鸭：写 greet 只是"提到了这个函数"， 不会执行它。要执行必须带括号：greet()。
正确写法：greet()
3
把 print 当成 return。函数里只打印，外面却想用它的结果。
扣哒鸭：print 只把东西显示出来， 函数外面拿不到它。
想拿到结果，必须写 return；否则函数默认返回 None。
正确做法：要传结果用 return，要显示才用 print
4
参数个数对不上。定义了 2 个参数，调用时只给 1 个。
扣哒鸭：会报 TypeError: missing 1 required positional argument。
除非那个参数有默认值，否则一个都不能少。
正确做法：实参个数要和形参一致（有默认值的可以省略）

改编自 2026 年 9 月 · Python 四级 · 第 6 题单选题
关于下面这个函数，说法正确的是（　　）。
1  def process(a: int, b: str = "default") -> str:
2      return b * a
A.调用函数时必须为形参 a 传递一个整数值
B.调用函数时不能省略对形参 b 的传参
C.函数返回值必须是字符串类型
D.参数类型注解在运行时不会强制检查类型
查看答案与详解
答案：D。函数签名里的 a: int、-> str 只是类型注解（提示），给人和工具看的，Python 运行时不会强制检查 ——传个字符串进去也不会报错，只是逻辑上可能出错。
A 错：注解不强制，传别的类型照样能调用；
B 错：b: str = "default" 是带默认值的参数，调用时可以不传，不传就用 "default"；
C 错：-> str 同样只是注解；这里 b * a 恰好返回字符串，但如果传入的 b 是数字，返回的就是数字。
两条要记牢：① 带默认值的参数必须写在后面；
② 类型注解是"君子协定"，不是强制约束。
对应小节3 参数：给函数带东西进去。

原创练习题编程题
题目要求：① 定义一个函数 isEven(n)， 当 n 是偶数时返回 True，否则返回 False；② 用它统计列表 [3, 8, 15, 22, 7] 中有几个偶数并输出。
查看参考答案与要点 
def isEven(n):
    return n % 2 == 0          # 比较表达式本身就是 True 或 False

nums = [3, 8, 15, 22, 7]

count = 0
for x in nums:
    if isEven(x):              # 返回值直接当条件用
        count = count + 1

print(count)                   # 2

输出：2（8 和 22）
要点：
① n % 2 == 0 直接就是布尔值，不用再写 if-else；
② 返回 True/False 的函数可以直接放进 if 条件里，代码更接近自然语言；
③ 判断偶数也可以用位运算 n & 1 == 0。
对应小节3 参数；4 返回值。

8　本单元小结

Unit Summary
戈登 · 齿轮工程师
三句话记住函数：
一、def 定义，函数名加括号才是调用。
二、参数是"带进去的东西"，return 是"带出来的结果"。
三、print 给人看，return 给程序用——千万别混。
学会把重复的活儿封成函数，你的程序就开始"像样"了。

你在模块化车间收获了什么

  • 函数——把一段代码起个名字装起来，用 def 定义、用 名字() 调用。
  • 三个好处——复用、易改、易读。
  • 定义不执行——只有调用语句才会让函数体跑起来。
  • 参数——形参是占位符，实参是真实数据；有默认值的参数写在后面。
  • 返回值——return 把结果交回调用处，可以用变量接住，也可以直接参与运算。
  • 没有 return 就返回 None——这是"print 当 return 用"错误的根源。
  • 模块化——把长程序拆成几个各司其职的函数，主流程一目了然。
