1　为什么要用数组

Why Arrays

1.1 不用数组有多麻烦

要存 5 个矿车的载重，不用数组得这样写 C++ 
// 笨办法：一个变量装一个
int cart0 = 12;
int cart1 = 7;
int cart2 = 25;
int cart3 = 3;
int cart4 = 18;

// 想把它们都翻倍？只能一个个写
cart0 *= 2;
cart1 *= 2;
cart2 *= 2;
cart3 *= 2;
cart4 *= 2;

// 如果有一百节车厢呢？……
问题　cart0 到 cart99 要写一百行；
而且没法用循环——因为循环变量拼不出变量名

换成数组，一切立刻变得清爽：

用数组：一个名字管一整排 C++ 
int cart[5] = {12, 7, 25, 3, 18};    // 一个名字，五个格子

for (int i = 0; i < 5; i++) {
    cart[i] *= 2;                     // 循环一跑，全部翻倍
}
OUTPUT　cart 变成 {24, 14, 50, 6, 36}
关键　循环变量 i 直接当下标用——这是数组最大的价值

1.2 数组是什么

打个比方： 数组就像矿坑里的一列编号矿车——同一个名字（数组名），按顺序排成一串， 每节车厢用编号（下标）来区分。
想找第 3 节车厢？报编号就行；想"每一节都装两倍矿石"？用循环从头走到尾就行。
比"给每节车厢都单独起一个名字"省事太多。
数组的三个特点： ① 同一个名字——所有元素共用一个数组名。
② 用下标区分——第几个元素，用中括号里的数字表示。
③ 长度固定——定义时就要说清有多少个格子，之后不能变。
还有一条很重要的：所有元素的类型必须相同——整型数组里只能放整数。
"长度固定"这一点，和后面要学的容器不一样。 在 C++ 里，int a[10]; 一旦定义，就是板上钉钉的 10 个格子。
想要"能自动变长"的，得用标准库里的 vector（那是更高级的内容）。
三级阶段请记住：数组的长度在定义时就定死了。

2　定义与初始化

Declaring & Initializing

2.1 三种初始化方式

三种写法，各有用处 C++ 
// ① 只定义，不初始化 —— 里面是"垃圾值"，千万别直接用
int a[5];

// ② 全部列出来 —— 最清楚
int b[5] = {12, 7, 25, 3, 18};

// ③ 只写一部分 —— 剩下的自动补 0
int c[5] = {12, 7};         // 结果是 {12, 7, 0, 0, 0}

// ④ 全部补 0 的常用写法
int d[5] = {0};             // 结果是 {0, 0, 0, 0, 0}

// ⑤ 让编译器自己数个数
int e[] = {1, 2, 3, 4};     // 长度自动是 4
重点　{0} 是把所有元素都补成 0 的常用写法；
而 int a[5]; 这样不初始化，里面的值是不确定的
为什么 {0} 能全部补 0？ 因为 C++ 的规矩是：初始化列表里写了几项，就先填几项，剩下的自动补 0。
{0} 只写了第 0 项是 0，后面四项也自动补 0——结果全 0。
注意：int d[5] = {1}; 得到的不是"全是 1"，而是 {1, 0, 0, 0, 0}。

2.2 数组长度怎么求

用 sizeof 算出元素个数 C++ 
int a[] = {12, 7, 25, 3, 18, 9, 40};

int n = sizeof(a) / sizeof(a[0]);
//      ↑整个数组占的字节数   ↑单个元素占的字节数

cout << n << endl;      // 7
原理　整个数组的字节数 ÷ 一个元素的字节数 = 元素个数
sizeof(a) = 7 × 4 = 28 字节；sizeof(a[0]) = 4 字节；28 ÷ 4 = 7
这个写法的好处：不用自己数。 如果以后往数组里加了一个数，这行代码会自动给出新的长度，不用改。
而如果硬写 int n = 7;，加一个数就忘了改，循环就会漏掉最后一个元素。
注意：这个技巧只在"数组定义所在的作用域里"有效—— 一旦把数组传给函数，sizeof 就失效了（那是四级的内容）。

3　下标访问

Indexing

3.1 下标从 0 开始

第一个元素是 a[0]，不是 a[1] C++ 
int a[5] = {12, 7, 25, 3, 18};

cout << a[0] << endl;     // 12   第一个
cout << a[2] << endl;     // 25   第三个
cout << a[4] << endl;     // 18   第五个（最后一个）

a[1] = 100;               // 把第二个元素改成 100
cout << a[1] << endl;     // 100
规律　长度为 n 的数组，合法下标是 0 ~ n−1
最后一个元素是 a[n-1]，写成 a[n] 就越界了
为什么偏偏从 0 开始？ 因为下标表示的是"离数组开头偏移了几个格子"。
第一个元素就在开头，偏移量是 0——所以是 a[0]。
偏移 3 格就是第 4 个元素，也就是 a[3]。
理解成"偏移量"就不容易数错了。

3.2 越界是最危险的错误

数组越界（out of bounds）： 访问了合法范围之外的下标，比如对长度 5 的数组写 a[5] 或 a[−1]。
C++ 不会检查下标是否越界！
这意味着程序可能不报错、继续跑，但它读写的是数组旁边的内存—— 那里可能放着别的变量。
越界的后果：悄无声息地改掉别人的数据 C++ 
int a[3] = {1, 2, 3};
int b = 999;

a[3] = 0;         // ★ 越界！这个位置其实已经不属于 a 了
                  // 它可能正好就是 b 占的那块内存

cout << b << endl; // 可能是 999，也可能莫名其妙变成别的值
警告　这段代码编译不报错、运行也可能不报错——
但结果已经不可靠了。这类错误极难排查。
避免越界的两条铁律： ① 循环条件写 i < n，不要写 i <= n （除非你确实要从 0 走到 n，那数组长度就得是 n+1）。
② 数组定义得"稍微大一点"——比如题目说最多 1000 个数，就写 int a[1005];， 留几个格子的余量最保险。

4　遍历数组

Traversing

4.1 标准遍历写法

"遍历"就是把每个元素都走一遍 C++ 
int a[] = {12, 7, 25, 3, 18};
int n = sizeof(a) / sizeof(a[0]);

// 标准写法：让 i 从 0 走到 n-1
for (int i = 0; i < n; i++) {
    cout << a[i] << " ";
}
cout << endl;                 // 12 7 25 3 18

// 倒着遍历
for (int i = n - 1; i >= 0; i--) {
    cout << a[i] << " ";
}
cout << endl;                 // 18 3 25 7 12
记忆　正着走：i = 0; i < n; i++；倒着走：i = n-1; i >= 0; i--
两个边界一个是 0、一个是 n−1，千万别写错

4.2 范围 for 与它的坑

C++11 的范围 for：更短的写法，但有陷阱 C++ 
int a[5] = {2, -5, 7, 0, -1};

// 写法一：值拷贝 —— 改不动原数组！
for (int num : a) {
    if (num > 0) num = 0;        // ★ 改的只是副本
}
// 数组 a 完全没变，还是 {2, -5, 7, 0, -1}

// 写法二：加 & 变成引用 —— 才能真正改到原数组
for (int &num : a) {
    if (num > 0) num = 0;
}
// 现在 a 变成 {0, -5, 0, 0, -1}
OUTPUT　写法一：数组不变；写法二：正数全被清成 0
关键　不加 & 就是"复制一份给你看"，加 & 才是"把原件交给你"
这是真题挖过的坑： for (int num : a) { if (num > 0) num = 0; } 能够将数组中所有大于 0 的元素赋值为 0。
这句话是错的。因为 num 是每个元素的副本， 改它不会影响原数组。
想改原数组，必须写成 for (int &num : a)。
写法能不能改原数组什么时候用
for (int i = 0; i < n; i++)能需要下标、需要倒序、需要跳跃访问
for (int num : a)不能只是读一遍、打印、求和
for (int &num : a)能要修改每一个元素

5　三个经典小算法

Three Classic Patterns

5.1 求和与求平均

累加器：从 0 开始，一路加过去 C++ 
int a[] = {12, 7, 25, 3, 18};
int n = sizeof(a) / sizeof(a[0]);

int sum = 0;                        // ★ 累加器必须初始化为 0
for (int i = 0; i < n; i++) {
    sum += a[i];
}

cout << sum << endl;                // 65
cout << sum * 1.0 / n << endl;      // 13   ← 乘 1.0 变成小数除法

return 0;
OUTPUT　65 / 13
注意　sum / n 是整数除法；想得到小数要写 sum * 1.0 / n
求平均值的经典坑： 65 / 5 正好整除还好说。可如果是 7 / 2， 整数除法会给你 3，而不是 3.5。
因为它丢掉了小数部分。所以要写 sum * 1.0 / n： 乘上 1.0 之后整个式子变成小数运算，结果才是 3.5。

5.2 找最大值与计数

两个最常用的套路 C++ 
int a[] = {12, 7, 25, 3, 18, 40, 25};
int n = sizeof(a) / sizeof(a[0]);

// 【套路一】找最大值
int mx = a[0];                      // ★ 初值取第一个元素，不是 0
for (int i = 1; i < n; i++) {
    if (a[i] > mx) mx = a[i];
}
cout << mx << endl;                 // 40

// 【套路二】统计个数
int cnt = 0;                        // ★ 计数器初始化为 0
for (int i = 0; i < n; i++) {
    if (a[i] >= 20) cnt++;
}
cout << cnt << endl;                // 3（25、40、25）
OUTPUT　40 / 3
三个初始值要记牢　累加器 = 0、计数器 = 0、最值取 a[0]
任务初始值循环里做什么
求和sum = 0sum += a[i]
计数cnt = 0满足条件就 cnt++
求最大mx = a[0]a[i] > mx 就更新
求最小mn = a[0]a[i] < mn 就更新
求平均sum = 0先求和，最后 sum * 1.0 / n

6　代码实战

Level Practice
关卡

资源谷

进入关卡 →
故事：资源谷里散落着一整片矿石，每一堆的重量都记在旁边的木牌上。
安雅说：这一关有个要求——你只能记住"目前最大的那一堆"在哪儿。
你有点疑惑：为什么不能全都记下来？
因为你记不住。她笑了，但数组能。所以我们先把它们都存进去，再慢慢算。

思路：先把所有数据读进数组，再遍历一遍做统计。 这是数组题的标准两步。

先存进去，再算出来 C++ 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;                    // 一共有几堆

    int a[1005];                  // ★ 开得比题目上限稍大一点
    for (int i = 0; i < n; i++) {
        cin >> a[i];              // 第一遍：全部读进数组
    }

    int mx = a[0];                // 第二遍：遍历求最大值
    int pos = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] > mx) {
            mx = a[i];
            pos = i;
        }
    }

    cout << mx << " " << pos << endl;
    return 0;
}
输入　6　/　12 7 25 3 18 9　　输出　25 2
读法　最大的是 25，它在 a[2]（第三个元素）
和本单元的关系： "先存数组、再遍历"是数组类题目最通用的套路。
因为很多统计要求你回过去看前面的数据——比如"比平均值大的数有几个"， 你就必须先算完平均值，再回头扫一遍。
如果数据读完就丢了，第二步就没法做了。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
数组的错，一半是下标，一半是初始值。四条，条条都考过。
1
循环写成 i <= n，越界了。
扣哒鸭：长度 n 的数组，最后一个下标是 n−1。
i <= n 会让 i 取到 n，那是第 n+1 个格子，不在数组里。
C++ 不检查越界，所以它不会报错，只会悄悄改坏别人的内存。
正确写法：for (int i = 0; i < n; i++)
2
以为 int a[5]; 里的元素默认是 0。
扣哒鸭：不初始化的话，里面是"不确定的值"，不是 0。
直接拿来做加法，答案就是乱七八糟的。
要清零就写 int a[5] = {0};。
正确做法：定义时就初始化，{0} 可全部清零
3
用范围 for 想改数组，结果没改到。
扣哒鸭：for (int num : a) 里的 num 是副本。
你在副本上改来改去，原数组一点都不受影响。
想真改，就得写 for (int &num : a)——那个 & 是关键。
正确写法：要修改元素就加 &
4
求最大值的初值写成了 0。
扣哒鸭：数组里全是负数的时候，mx = 0 会输出 0——
可 0 根本不在数组里。
正确答案是 mx = a[0]：它是真实存在的元素，肯定安全。
记牢：求最大最小，初值取 a[0]

Practice

改编自 2026 年 9 月 · C++ 三级 · 第 14 题单选题
以下数组定义，符合 C++ 语法的是（　　）。
A.int a[] = {1, 2, 3.0};
B.int b['A'];
C.int c[ ];
D.float d[10.0];
查看答案与详解
答案：B。数组长度必须是一个整型常量表达式。
B 项：'A' 是字符常量，它的值是整数 65， 所以这相当于 int b[65];——完全合法（虽然写得不直观）。
A 项：初始化列表里混进了 3.0 这个浮点数。 用花括号初始化 int 数组时发生"窄化转换"，C++11 起会报错。
C 项：int c[ ]; 既没写长度，也没有初始化列表让编译器自己数， 编译器不知道要开多大，报错。
D 项：数组长度不能用 10.0 这样的浮点数，必须是整数。
一句话记牢：数组长度 = 整型常量。
对应小节2.1 三种初始化方式；2.2 数组长度怎么求。
改编自 2026 年 6 月 · C++ 三级 · 判断题 第 6 题判断题
char str[4] = "GESP"; 将在内存空间中给 str 分配 5 个字节。（　　）
查看答案与详解
答案：错误（×）。这句话有两处问题：
① 字符串字面量 "GESP" 末尾还有一个隐含的结束符 '\0'，一共需要 5 个字节 （G、E、S、P、'\0'）。
② 而 str 只声明了 4 个字节—— 装不下，这在 C++ 里是编译错误。
正确写法：char str[5] = "GESP"; 或者干脆省掉长度 char str[] = "GESP";（让编译器自己数）。
要记牢：字符串占的字节数 = 字符个数 + 1（那个结束符 '\0' 也算一个）。
对应小节2.1 三种初始化方式；3.2 越界是最危险的错误。
改编自 2026 年 9 月 · C++ 三级 · 第 5 题编程题
公共二进制位：给定 n 个非负整数， 求有多少个二进制位在所有整数中都是 1。
样例：输入 3 与 7 15 21，输出 2。
查看参考答案与要点 
#include <iostream>
using namespace std;

int a[20010];                   // ★ 数组开得比上限大一点

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    int S = a[0];
    for (int i = 1; i < n; i++) S &= a[i];   // 全部按位与

    int ans = 0;
    while (S > 0) {
        if (S & 1) ans++;       // 数一数 S 里有几个 1
        S >>= 1;
    }
    cout << ans;
    return 0;
}

验算：7 = 00111、15 = 01111、21 = 10101。
00111 & 01111 = 00111，再 & 10101 = 00101—— 里面有 2 个 1，答案 2 ✔
要点：
① "每一位在所有数里都是 1" ⟺ "所有数按位与之后那一位是 1"；
② 这题用数组是因为第一个数要留到最后一起"与"，所以得先存下来 （其实也可以边读边与，但用数组更直观）；
③ 数组上限定成 20010，比题目给的 20000 留了 10 个余量，防止越界；
④ 注意这题用的是全局数组——全局数组默认全是 0，不用担心未初始化的问题。
对应小节4.1 标准遍历写法；5.2 找最大值与计数。

A.5 0 1　　B.6 0 1　　C.6 9 1　　D.程序运行出错
查看答案与详解
答案：B。① 长度：数组定义写的是 a[6]， 虽然只给了 5 个初值，但长度就是 6，所以 sizeof(a)/sizeof(a[0]) = 6。
② a[5]：初始化列表只有 5 项，剩下的自动补 0， 所以 a[5] 是 0。
③ a[2]：从 0 开始数——a[0]=3、 a[1]=8、a[2]=1，所以是 1。
合起来输出 6 0 1。
A 项是把长度误当成初值个数 5；C 项是把下标当成了"第几个"。
对应小节2.1 三种初始化方式；3.1 下标从 0 开始。
原创练习题判断题
在 C++ 中，int a[5]; 这样定义一个局部数组后， 若不赋初值，则数组所有元素的值都是 0。（　　）
查看答案与详解
答案：错误（×）。局部数组不初始化时，元素的值是"不确定的" （常说的"垃圾值"），不是 0。
要清零必须显式写：int a[5] = {0};。
一个例外要记住：全局数组（定义在所有函数外面的）会自动全部初始化为 0。 这也是比赛里很多人喜欢把大数组开在全局的原因之一。
对应小节2.1 三种初始化方式。
原创练习题编程题
题目要求：读入 n 和 n 个整数， 输出它们的总和、平均值（保留两位小数）以及大于平均值的数的个数。
样例：输入 5 与 10 20 30 40 50， 输出 150 30.00 2。
查看参考答案与要点 
#include <iostream>
#include <cstdio>
using namespace std;

int a[1005];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    // 第一遍：求和
    int sum = 0;
    for (int i = 0; i < n; i++) sum += a[i];

    // 第二遍：统计比平均值大的个数
    double avg = sum * 1.0 / n;      // ★ 乘 1.0 变小数除法
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] > avg) cnt++;
    }

    printf("%d %.2f %d\n", sum, avg, cnt);
    return 0;
}

要点：
① 必须扫两遍：第一遍求总和，第二遍才能拿平均值去比较 ——这就是为什么非要用数组（数据得留着）；
② sum * 1.0 / n 是得到小数平均值的写法； 直接写 sum / n 会丢掉小数；
③ 比较时用 a[i] > avg 而不是 >=， 题目说的是"大于"；
④ %.2f 控制保留两位小数；
⑤ 数组开成全局的，自动全 0、还能开得比较大。
对应小节5.1 求和与求平均；5.2 找最大值与计数。

9　本单元小结

Unit Summary
安雅 · 红发队长
四句话记住数组：
一、数组是"同一个名字 + 一个编号"，能一口气管住一整排同类型的数。
二、下标从 0 开始；长度为 n 时合法下标是 0 到 n−1，越界不会报错但会改坏别的数据。
三、int a[5] = {0}; 可以全部清零；不初始化的局部数组里是垃圾值。
四、三个初始值要记牢：求和从 0 起、计数从 0 起、最值取 a[0]。
编队管住了。下一站是石碑上的密语——那里管的不再是数字，而是一长串字符。

你在矿车编队前收获了什么

  • 数组——同一类型、同一名字、用下标区分的一排格子；长度定义时就定死。
  • 定义——int a[10];；长度必须是整型常量。
  • 初始化——int a[5] = {1,2,3}; 剩下自动补 0； {0} 可全部清零；不初始化则值是垃圾。
  • 求长度——sizeof(a) / sizeof(a[0])。
  • 下标——从 0 开始；长度为 n 时合法范围是 0 ~ n−1。
  • 越界——C++ 不检查，可能不报错却改坏了别的变量， 是最危险的错误之一。
  • 遍历——for (int i = 0; i < n; i++)；倒着是 i = n−1; i >= 0; i--。
  • 范围 for——for (int num : a) 拿到的是副本，改不动原数组； 要改必须写 for (int &num : a)。
  • 三个套路——求和／计数初始化为 0；最值初值取 a[0]。
  • 求平均——用 sum * 1.0 / n，否则会丢掉小数。
