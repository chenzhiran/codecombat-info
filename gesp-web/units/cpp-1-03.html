1　算术运算符

Arithmetic Operators

1.1 加、减、乘、除

打个比方： 配方台上有五只瓶子，每只瓶身刻着一个符号，倒进水晶杯就会发生不同的事：
① 加号瓶——把两堆东西合成一堆；
② 减号瓶——从一堆里拿走一些；
③ 乘号瓶——把同一堆东西复制好几份；
④ 除号瓶——把一堆平均分给几个人，只留下"每人分到几份"；
⑤ 百分号瓶——平均分完之后，只留下"还剩下几个"。
五只瓶子里最容易搞错的是后两只——它们是一对兄弟，一个留商、一个留余。
最容易被绊倒的一步：整除 C++ 
cout << 7 / 2 << endl;        // 3     两个整数相除，结果还是整数
cout << 7 % 2 << endl;        // 1     余数

cout << 7 / 2.0 << endl;      // 3.5   有一个是小数，结果就是小数

cout << 8 / 10 << endl;       // 0     ★ 商是 0，不是 0.8
cout << 8 % 10 << endl;       // 8     被除数比除数小，余数就是它自己
OUTPUT　3
1
3.5
0
8
整除与取余，记住这两条：
① 整数 ÷ 整数 = 整数（商取整，小数部分直接丢）：7 / 2 = 3、8 / 10 = 0。
② 取余 % 求的是"还剩多少"：7 % 2 = 1、8 % 10 = 8。
口诀：/ 求商，% 求余；分东西就靠这两个。

1.2 取余 %

取余是 C++ 一级的"明星运算"，很多题目的核心就是它。

表达式结果用途
17 % 5217 个东西分给 5 人，还剩 2 个
n % 20 或 1判断奇偶：0 是偶数，1 是奇数
n % 100~9取出个位数字
n / 10去掉个位去掉最后一位；配合 % 10 可逐位取数
n % 1000~99取出末两位
经典组合：拆出一个整数的各位数字 C++ 
int n = 1234;

int ge   = n % 10;          // 4   个位
int shi  = n / 10 % 10;     // 3   十位
int bai  = n / 100 % 10;    // 2   百位
int qian = n / 1000;        // 1   千位

cout << qian << bai << shi << ge;   // 1234
要点　/ 10 去掉末位，% 10 取出末位，两者配合就能逐位拆数
打个比方： 17 颗糖分给 5 个小朋友，每人先分到 3 颗，最后还剩 2 颗。
那个"每人 3 颗"就是 17 / 5 的结果；
那个"还剩 2 颗"就是 17 % 5 的结果。
所以 / 和 % 是一对好兄弟：一个回答"分到多少"，一个回答"剩下多少"。

1.3 正负号与负数取余

正负号是一元运算符 C++ 
int a = 4 + -2 * 3;      // -2 * 3 先算得 -6，再加 4
cout << a << endl;        // -2

int b = -5;
cout << -b << endl;       // 5     负号可以反转

int c = -7 % 3;          // -1    结果的符号跟着"被除数"走
cout << c;
OUTPUT　-2
5
-1
易错点：那个负号到底跟谁？ 在 4 + -2 * 3 里，-2 是一个整体（负号是一元运算符，优先级很高），
所以先算 -2 × 3 = -6，再算 4 + (-6) = -2。
千万不要把它读成"4 减 2 乘 3"。

2　赋值与自增自减

Assignment & Increment

2.1 赋值与复合赋值

写法等价于含义
a += 3a = a + 3在原有基础上加 3
a -= 3a = a - 3在原有基础上减 3
a *= 3a = a * 3乘 3 倍
a /= 3a = a / 3缩小到三分之一（注意整除）
a %= 3a = a % 3取余后存回去
+= 和 =+ 完全不同！
a += 1 —— 让 a 增加 1（复合赋值）。
a =+ 1 —— 意思是 a = (+1)，把 a 直接变成 1，和原来的值毫无关系！
这一个字母的位置，是真题专门设过的陷阱。

2.2 ++ 与 --

让变量自己加一 / 减一 C++ 
int n = 5;

n++;            // 相当于 n = n + 1，n 变成 6
n--;            // 相当于 n = n - 1，n 变回 5

++n;            // 前置写法，效果一样，n 变成 6
--n;            // n 变回 5

cout << n;      // 5
要点　n++ 与 ++n 单独成句时完全等价，都是"加一"
打个比方： ++ 就像楼梯旁的上升机关——按一下，格子里的数字往上跳一格；
-- 则是下降机关，按一下往下跳一格。
注意：如果一句话里只有 n++; 这一件事，按一下就完了，看不出前置后置的区别。
只有把它塞进更大的句子里（比如 cout << n++;），区别才会露出来。

2.3 前置与后置的区别

当 ++ 出现在表达式里面时，前置和后置就有区别了。

写法先做什么表达式的值例子
++n（前置）先加 1加完之后的值n=5; cout << ++n; 输出 6，n 也是 6
n++（后置）先用原值加之前的值n=5; cout << n++; 输出 5，n 变成 6
真题级的一行：先加，再复合赋值 C++ 
int b = 8;
++b *= 2 + 1;           // ① ++b：b 先变成 9
                        // ② 算出 2 + 1 = 3
                        // ③ b *= 3：b = 9 * 3 = 27

cout << b;              // 27
OUTPUT　27
怎么读这种"叠在一起"的式子？ 把它拆成三步，一步一步来：
① 先把 ++ 处理掉（b 从 8 变成 9）；
② 再算右边的加法（2 + 1 = 3）；
③ 最后做复合赋值（b = 9 × 3 = 27）。
顺序不能反——先自增，再乘。

3　关系运算符

Relational Operators

3.1 六个关系符

3.2 结果是 1 或 0

关系运算的结果不是"真"这个字，而是数字 C++ 
cout << (3 < 5) << endl;      // 1   成立
cout << (3 > 5) << endl;      // 0   不成立
cout << (4 == 4) << endl;     // 1
cout << (4 != 4) << endl;     // 0

int a = (2 < 3) + 1;         // 关系式的结果 1 参与计算
cout << a;                    // 2
OUTPUT　1
0
1
0
2
打个比方： 关系运算像驿站的验货员——他从不回答"对"或"不对"，只举牌：
合格就举 1，不合格就举 0。
既然是数字牌，那它就能被拿来算——所以 (2 < 3) + 1 才能算出 2。 千万别写成 true + 1，那不是 C++ 的写法。
一定要记住： 关系运算的结果是 1（成立） 或 0（不成立）， 不是 true / false 这两个单词。
所以 (2 < 3) + 1 的结果是 2——关系式可以当成 0 或 1 直接参与运算。

4　逻辑运算符

Logical Operators

4.1 与、或、非

运算符读作什么时候为真例子
&&与（并且）两边都成立才为真(3 > 1) && (2 > 1) → 1
||或（或者）只要一边成立就为真(3 > 9) || (2 > 1) → 1
!非（取反）原来是真就变假，原来假就变真!(3 > 1) → 0
真值表（记住 1 和 0 就够了） C++ 
cout << (1 && 1) << endl;    // 1    真且真 = 真
cout << (1 && 0) << endl;    // 0    只要有一个假，与就是假
cout << (1 || 0) << endl;    // 1    有一个真，或就是真
cout << (0 || 0) << endl;    // 0    两个都假，或才假
cout << (!0) << endl;        // 1    非假 = 真
OUTPUT　1
0
1
0
1

4.2 短路求值

有时候右边根本不会被算 C++ 
int a = 0;

// && ：左边已经是假，右边不再计算
if (a != 0 && 10 / a > 1) {
    cout << "不会进这里";
}

// || ：左边已经是真，右边不再计算
if (a == 0 || 10 / a > 1) {
    cout << "会进这里";
}
OUTPUT　会进这里
打个比方： 逻辑与（&&）就像宝箱上挂了两把锁——两把都打开，箱盖才掀得起来；只要一把没开，试都不用试第二把。
逻辑或（||）像走廊上的两扇门——推开任意一扇，就能走过去。
逻辑非（!）是翻牌子——原来写"真"的翻成"假"，写"假"的翻成"真"。
记牢这三句话，逻辑运算的题基本不会错。
短路有什么用？ 上面那段代码里，如果 && 不短路，10 / a 就会执行， 而 a 是 0——除以 0 会出错。
短路让程序"提前判断、不必冒险"，也顺便节省了计算时间。
记忆：&& 遇到假就停，|| 遇到真就停。
再打个比方： 逻辑与是一条吊桥，桥面由两块木板拼成——第一块断了，第二块就不用看了，直接判定"过不去"。
逻辑或是一条分岔路——左边这条通了，就没必要再去走右边那条，直接判定"能过去"。
"看一眼就知道结果、剩下的不再算"，这就叫短路。

5　优先级与结合性

Precedence

5.1 谁先算

三步算出一个表达式的值 C++ 
int a = 2 + 3 * 4;          // 先算 3 * 4 = 12，再加 2 → 14
int b = (2 + 3) * 4;        // 括号先算 → 5 * 4 → 20
int c = 10 - 4 - 3;         // 同级从左往右 → (10-4)-3 → 3
int d = 20 / 2 * 5;         // 同级从左往右 → (20/2)*5 → 50
int e = 2 * -2 % 3;         // 先处理负号 → (2*-2)%3 → -4%3 → -1

cout << a << " " << b << " " << c << " " << d << " " << e;
OUTPUT　14 20 3 50 -1

5.2 拿不准就加括号

打个比方： 优先级就像驿站打饭的排队规矩——
括号里的人排在最前面；其次是一元运算符（!、++、正负号）； 再是乘、除、取余；然后是加、减。
同一队里的人不分先后，谁站在左边谁先办——这就是"同级从左往右"。
拿不准谁先谁后？给对方加一对括号，他就排到最前面去了。
两条保命规则：
① 同级运算从左往右：20 / 2 * 5 是 (20/2)*5 = 50， 不是 20/(2*5) = 2。
② 不确定就加括号：括号不花钱，却能让你和判卷老师都看懂。
考试里遇到长式子，先在心里给每一步标上序号，再一步一步算。

故事：前方一片火海，宝石就散落在火焰之间。 你要一步步走进去，把宝石一颗颗捡起来，再安全退出来。

int step = 2;

hero.moveXY(nextX, hero.pos.y);

int left = 5 % 3;                   // 顺手练一下取余
cout << left << endl;                // 2

hero.moveXY(hero.pos.x + 3, hero.pos.y);
要点　hero.pos.x + step 就是最简单的表达式；% 的结果是余数
和本单元的关联： hero.pos.x + step 里，先算加法，再把结果给 moveXY 用—— 这就是"先算表达式、再使用结果"。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
运算符这一块，真题几乎年年出。四条，每条都值得抄在草稿纸上。
1
把"赋值 = "当成"相等 =="。
扣哒鸭：= 是"把右边放进左边"；== 才是"问它们相不相等"。
判断条件里写成单个等号，是新手最经典的错。
正确写法：判断相等用 ==
2
把 += 写成了 =+。
扣哒鸭：a += 1 是"加 1"；
a =+ 1 是 a = (+1)，会把 a 直接覆盖成 1！
两个符号的顺序换了，含义天差地别。
正确写法：a += 1
3
算 20 / 2 * 5 时先算了乘法。
扣哒鸭：乘和除是同一级，同级运算从左往右。
20 / 2 * 5 = (20/2)*5 = 50，不是 2。
正确做法：同级从左往右；要换顺序就加括号
4
用 % 做小数运算。
扣哒鸭：取余 % 只能用于整数。
2.5 % 2 这种写法编译就通不过。
要处理小数的"余数"，得先想清楚题目到底要什么。
正确认识：% 的操作数必须是整数

8　题目练习

Practice

改编自 2026 年 9 月 · C++ 一级 · 第 3 题单选题
下列 C++ 代码执行的输出是（　　）。
int a = 4 + -2 * 3;
cout << a;
A.-2　　B.6　　C.18　　D.输出错误提示信息
查看答案与详解
答案：A。这里的 -2 是一个整体（负号是一元运算符，优先级高于乘法），
所以先算 -2 × 3 = -6，再算 4 + (-6) = -2。
易错点：读成"4 减 2 再乘 3"会得到 6（B 项），那是把运算顺序搞反了。
对应小节1.3 正负号与负数取余；5.1 谁先算。
改编自 2026 年 9 月 · C++ 一级 · 第 4 题单选题
下列 C++ 表达式与 2 * -2 % 3 的值相同的是（　　）。
A.(2 * -2) % 3
B.2 * (-2 % 3)
C.2 * -(2 % 3)
D.2 % -2 * 3
查看答案与详解
答案：A。* 和 % 同级，从左往右算，
所以原式 = (2 * -2) % 3 = -4 % 3 = -1，与 A 完全一致。
B = 2 × (-2) = -4；C = 2 × (-2) = -4；D = (2 % -2) × 3 = 0 × 3 = 0——都不同。
对应小节5.1 谁先算。
改编自 2026 年 9 月 · C++ 一级 · 第 6 题单选题
下列 C++ 代码执行后的输出是（　　）。
int a = 8;
int b = 10;
cout << (a % b) << " " << (a * 1 / b) << " " << (a * 1.0 / b);
A.8 0.8 0　　B.0 0.8 0　　C.8 0 0.8　　D.0 0 0.8
查看答案与详解
答案：C。一个一个算：
① a % b = 8 % 10 = 8（被除数比除数小，余数就是它自己）；
② a * 1 / b —— 全是整数，从左往右：8 × 1 = 8，8 ÷ 10 = 0（整除）；
③ a * 1.0 / b —— 出现了小数 1.0，整体按小数算：8.0 ÷ 10 = 0.8。
所以是 8 0 0.8。
这道题把"整除"和"浮点运算"放在一起对比，是典型的考法。
对应小节1.1 加、减、乘、除。
改编自 2026 年 9 月 · C++ 一级 · 第 7 题单选题
执行下面代码后，b 的值是（　　）。
int b = 8;
++b *= 2 + 1;
A.18　　B.17　　C.19　　D.27
查看答案与详解
答案：D。分三步看：
① ++b：b 先自增，从 8 变成 9；
② 2 + 1 = 3；
③ b *= 3：b = 9 × 3 = 27。
易错点：A 项 18 = 6 × 3，是把 b 当成了 6；B、C 都是没先做自增。
对应小节2.3 前置与后置的区别。
改编自 2026 年 6 月 · C++ 一级 · 第 8 题单选题
已知整型变量 cnt，下列对 cnt += 1 的改写中， 执行效果不同的是（　　）。
A.cnt = cnt + 1
B.cnt = 1 + cnt
C.cnt =+ 1
D.cnt = + 1 + cnt
查看答案与详解
答案：C。cnt =+ 1 会被理解成 cnt = (+1)， 把 cnt 直接赋成 1，与原来的值无关。
其余三项展开后都是"原值加 1"，效果相同。
这一题专门考 += 与 =+ 的顺序——符号位置不同，含义完全不同。
对应小节2.1 赋值与复合赋值。
原创练习题单选题
下列 C++ 代码执行后，输出的结果是（　　）。
int n = 5;
cout << n++ << " ";
cout << n;
A.5 5　　B.5 6　　C.6 6　　D.6 5
查看答案与详解
答案：B。n++ 是后置：先输出 n 当前的值 5，然后 n 才变成 6。
所以第一个输出 5，第二个输出 6。
对比：如果写的是 ++n，就会输出 6 6。

原创练习题编程题
题目要求：输入一个三位正整数，分别输出它的百位、十位、个位数字 （每个数字单独一行）。例如输入 357，输出 3、5、7。
查看参考答案与要点 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int bai = n / 100;              // 百位：去掉后两位
    int shi = n / 10 % 10;          // 十位：先去掉个位，再取末位
    int ge  = n % 10;               // 个位：直接取末位

    cout << bai << endl;
    cout << shi << endl;
    cout << ge  << endl;

    return 0;
}

输入 357 时输出：3、5、7
要点：
① / 10 去掉末位，% 10 取出末位——这两个动作是拆数的万能钥匙；
② 百位用 n / 100 一步到位（因为只有三位）；
③ 十位要"先去后取"：n / 10 得 35，再 % 10 得 5；
④ 全是整数运算，结果自然是整数，不会出现小数。

四句话记住运算符：
一、/ 求商、% 求余；整数除整数，结果还是整数。
二、++ 是加一；前置先加再用，后置先用再加。
三、关系运算的结果是 1 或 0，可以当数字参与计算。
四、括号 > 一元 > 乘除余 > 加减；同级从左往右。
配方台已经熟了。下一单元，我们让程序开口"说话"、也让它听得懂"输入"。

你在炼金台前学到了什么

  • 五个算术运算符——+ - * / %；除号右边不能是 0。
  • 整除——整数 ÷ 整数 = 整数；7 / 2 = 3、8 / 10 = 0。
  • 取余——17 % 5 = 2；n % 2 判奇偶，n % 10 取个位。
  • 拆数套路——/ 10 去末位，% 10 取末位。
  • 复合赋值——+= -= *= /= %=；注意别写成 =+。
  • 自增自减——++ 加一、-- 减一；前置与后置在表达式中不同。
  • 关系运算符——< > <= >= == !=；结果是 1 或 0。
  • 逻辑运算符——&& 两边都真、|| 一真即真、! 取反；有短路效果。
  • 优先级——括号 → 一元 → 乘除余 → 加减 → 关系 → 逻辑 → 赋值；同级从左往右。
