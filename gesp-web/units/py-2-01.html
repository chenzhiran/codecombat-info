1　计算机怎么记住东西

How Computers Remember

1.1 存储器是什么

一级里我们说过：计算机有五大部件——输入设备、运算器、控制器、存储器、输出设备。 今天我们要把存储器单独拎出来，好好看一看。

为什么？因为存储器是电脑的仓库。你写的代码、画的图、拍的照片、听的歌， 只要没被存进仓库，一关机就全没了。

一句话记住： 存储器 = 计算机用来"记住"数据和程序的地方。 它有两个关键指标：能装多少（容量）和读写多快（速度）。
欧卡 · 撼地者
我背东西特别快，但我记性差——扛过去一趟，转头就忘了。
内存就是我这号人：又快又忘事。
硬盘嘛，像我们村的老账房，翻本子慢吞吞的，可十年前借的半袋米他都记着。

1.2 三种存储器

名称全称 / 中文特点断电后会怎样
Cache高速缓冲存储器最快、最小、最贵内容消失
RAM随机存储器（内存）快、中等容量，程序运行时用它内容全部丢失
ROM只读存储器只能读、不能随便改，出厂就写好内容保留
硬盘 / U 盘外存储器慢、容量大、可以长期保存内容保留
最容易错的一题： 内存（RAM）里的东西，一断电就没了！
所以写作业、写代码，一定要按 Ctrl + S 存到硬盘上。 不保存就关机——你辛辛苦苦写的代码，会像没写过一样。
扣哒鸭 · 调试官
每年都有人把"内存"和"硬盘"搞反。我给你个最简单的办法——
想想你的手机："8G + 256G"里的 8G 是内存，"明明没存几张照片却提示空间不足"的那个 256G 是存储（硬盘）。
手机关机再开机，照片还在吧？说明它存在硬盘上。

1.3 位、字节与容量单位

计算机里最小的单位叫 位（bit），它就是一个小小的开关， 只表示两种状态：0 或 1（想象一盏灯，要么灭要么亮）。

但一个开关能表达的信息太少了，所以人们把 8 个位捆成一组， 叫做一个 字节（Byte，读作"拜特"）。

必须记住： 1 Byte（字节）= 8 bit（位）
字母的 B 大写是字节，小写 b 是位——1 B = 8 b。
单位英文约等于生活里像什么
B 字节Byte8 个二进制位一个英文字母
KB 千字节Kilobyte1024 B一小段文字
MB 兆字节Megabyte1024 KB一首歌
GB 吉字节Gigabyte1024 MB一部电影
TB 太字节Terabyte1024 GB一块大硬盘
PB 拍字节Petabyte1024 TB一整个数据中心

1.4 容量换算练习

换算是二级最爱考的小题，其实只要抓住一句话：大单位换小单位，乘以 1024。

用 Python 做换算（顺便复习一级的运算符） Python 
# 1 KB 有多少字节？
print(1 * 1024)

# 2 MB 有多少 KB？
print(2 * 1024)

# 1 GB 有多少 MB？
print(1 * 1024)

# 3 GB 有多少 MB？
print(3 * 1024)
OUTPUT　1024
2048
1024
3072
两步换算怎么算？比如"2 GB 等于多少 MB，又等于多少 KB"—— 一步一级往下乘：2 GB = 2 × 1024 = 2048 MB；2048 MB = 2048 × 1024 = 2097152 KB。
记住这个顺序：GB → MB → KB → B，每次乘 1024。

2　网络是什么

What Is a Network

2.1 从喊话到网络

还记得你刚进溪谷时喊的那一嗓子吗？声音从你嘴里出来，撞上岩壁，弹回来—— 信息从一端传到了另一端。

网络干的就是同一件事：把一台计算机里的信息，送到另一台计算机里。 只不过它不靠嗓门，靠的是电缆、光缆和无线电。

网络的定义： 把两台或更多计算机连接起来，让它们能够互相传递信息，这就是网络。
小到教室里两台电脑连一根网线，大到覆盖全球的互联网，本质都是这件事。

2.2 协议：大家约好的规矩

假设你在溪谷东岸，对面是西岸。你喊"喂"，人家回"喂"——这叫打招呼。 可如果你想告诉对方"帮我带三袋米"，就得说清楚：先说数量还是先说货物？用哪种方言？

两边必须先约好一套规矩，话才说得通。计算机之间也一样，这套规矩就叫 协议（Protocol）。

欧曼 · 传奇巫师
我在牢里关了太多年，早忘了外面的话怎么说。
有一次我对着守卫喊了一串古咒语，他愣是三秒没反应——因为我说的话，不在他的"协议"里。
后来我改说"放我出去"，他立刻听懂了。你看，规矩对上了，话才传得过去。

2.3 互联网与 IP 地址

把全世界无数个网络再连起来，就成了互联网（Internet）。 它像一个巨大的邮局系统：你寄出的每一封信，都要写上收件地址。

计算机在网络上的"门牌号"叫 IP 地址。它长这样：

IP 地址长什么样 
192.168.1.1
10.0.0.25
114.114.114.114
要点　四段数字，用小数点隔开，每一段都在 0~255 之间
名词是什么打个比方
网络把多台计算机连起来，互相传信息村里互相喊话的邻居
协议通信时双方共同遵守的规矩大家约好都说普通话
IP 地址每台设备在网络上的唯一编号每户人家的门牌号
互联网把全世界的网络连成一张大网全国的邮局系统
小知识：你在浏览器里输入的网址（比如 codecombat.cn）， 会被"域名解析"翻译成 IP 地址，电脑才知道该去哪儿找。 就像你先说"找安雅队长"，再查到她住在岗哨三号房。

关卡

平原森林保卫战

进入关卡 →
故事：溪谷外是一片开阔的平原，木农民们在这儿种地、养牛，日子过得挺安稳—— 直到食人魔开始从两侧的山口摸进来。
村长把一张地图塞给你，上面用 X 标出了两个最要紧的位置。 你得在这两处各立一道围栏，把路堵死。

思路：看上面的关卡实况——两处山口各有一个 X 标记。 这一关你第一次用到"坐标"——地图上的每个点都有唯一的 x 和 y。
这跟存储器的"地址"是一个道理：想存取东西，先得知道它在哪儿。

重点示例：在指定坐标建造 Python 
hero.buildXY("fence", 40, 53)    # 在 (40, 53) 这个点造一道围栏
就这一条　把括号里的坐标换成另一处 X 标记的 (40, 21)，再写一遍就完工了
看懂这个方法名： build 是"建造"，XY 表示"用坐标指定位置"—— 合起来就是"在指定坐标建造"。
后面的两个数字就是坐标：40, 53 是一处山口，40, 21 是另一处。
和存储接上了：计算机里每个字节也都有一个"坐标"（我们叫地址）。 CPU 想读一个数据，得先说出它的地址。
你在关卡里做的，和 CPU 做的事，其实是同一件：按地址找位置。

4　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
这一单元的"陷阱"不在代码里，全在概念上。四条，条条都是送分题变成送命题的地方。
1
以为内存就是硬盘。把"内存 8G"当成"能存 8G 文件"。
扣哒鸭：内存是工作台，硬盘是仓库。 工作台再大，也没法把家具收进去；仓库再大，工作台上也放不下太多东西。 内存管"正在运行的程序"，硬盘管"长期保存的文件"。
正确理解：内存（RAM）断电即忘，硬盘断电还在
2
把单位换算写成 ×1000。1 GB = 1000 MB。
扣哒鸭：是 1024，不是 1000！ 因为计算机只会数 0 和 1，1024 = 2 的 10 次方，这才是它"顺手"的数。 你按 1000 算，考试就按 0 分算。
正确写法：1 GB = 1024 MB
3
分不清 B 和 b。把 100 Mbps 当成 100 MB/s。
扣哒鸭：大 B 是字节，小 b 是位，1 B = 8 b。 所以 100 Mbps 的宽带，实际下载速度大约只有 12.5 MB/s—— 这就是为什么"百兆宽带"下东西没那么快。
正确换算：100 Mbps ÷ 8 ≈ 12.5 MB/s
4
以为没有协议也能通信。觉得"只要连上线就能传数据"。
扣哒鸭：连上线只是"路通了"，能不能听懂还得看协议。 就像两个不同国家的人打电话——线路没毛病，可谁也不知道对方在说什么。
正确理解：协议 = 双方共同遵守的通信规矩

5　题目练习

Practice

第 1 题改编自 2026 年 9 月 · Python 二级 第 2 题，其余为原创练习题。

改编自 2026 年 9 月 · Python 二级 · 第 2 题单选题
回声溪谷的观测塔里装着一台"溪谷计算中枢"，工程师在 CPU 与主存之间加了一级高速缓冲存储器（Cache），用来加快水情数据的处理。
下列关于 Cache 的说法中正确的是（　　）。
A.Cache 的容量比主存大，速度比主存快
B.Cache 通常用于暂存 CPU 频繁访问的数据
C.Cache 中的数据断电后不会丢失，属于非易失性存储器
D.Cache 的访问速度比 CPU 寄存器还要快
查看答案与详解
答案：B。Cache（高速缓存）的作用是把 CPU 近期频繁访问的数据暂存起来，减少 CPU 直接访问主存的次数，从而提升速度。
A 错：Cache 的容量最小（通常只有几 MB），但速度最快；
C 错：Cache 属于易失性存储器，断电后数据全部丢失；
D 错：速度由快到慢是 寄存器 → Cache → 主存 → 硬盘。
对应小节1.2 三种存储器。
原创练习题单选题

A.内存（RAM）里的数据断电后仍然保留
B.硬盘的读写速度比内存快
C.ROM 是只读存储器，其中的内容一般不能随意修改
D.Cache 的容量比硬盘大
查看答案与详解
答案：C。
A 错：内存断电后数据全部丢失；
B 错：速度从快到慢是 Cache → 内存 → 硬盘；
C 对：ROM 是只读存储器，出厂写入，一般不能改；
D 错：Cache 容量最小，只有几 MB。

6　本单元小结

Unit Summary
贺舒曼 · 镜中先知
存储与网络，是二级门口的第一道常识题。我给你们收成三句话：
一、存储器分三级：Cache 最快最小，内存断电竞失，硬盘最慢但能长期保存。
二、容量单位每一级都是 1024 进一，别写成 1000。
三、网络是"把机器连起来"，协议是"约好怎么说"，IP 地址是"门牌号"。
记住这三条，这一单元的题你就能全拿下。

你在回声溪谷收获了什么

  • 存储器——计算机里负责"记住"数据的部件，分内存与外存两大类。
  • 三档记忆——Cache（最快最小）→ RAM 内存（断电丢失）→ 硬盘（慢但长久）。
  • ROM——只读存储器，出厂写入，一般不能修改。
  • 位与字节——bit 是最小单位，1 Byte = 8 bit。
  • 容量单位——B → KB → MB → GB → TB → PB，每级 ×1024。
  • 网络——把多台计算机连起来互相传递信息。
  • 协议——通信双方共同遵守的规则；IP 地址是设备在网络上的唯一编号。
