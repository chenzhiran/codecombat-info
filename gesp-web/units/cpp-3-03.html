1　位运算是什么

What Are Bitwise Ops

1.1 普通运算 vs 位运算

平时我们算 3 + 5，是把它当成一个完整的数字来算的；
而位运算是把它拆成一位一位，每一位单独算，算完再拼回去。

一对比就明白了 TEXT 
加法（会进位）        位运算（绝不进位）

  0011   3            0011   3
+ 0101   5          | 0101   5     ← 按位或
───────             ───────
  1000   8            0111   7
  ↑ 进了一位          ↑ 每一位各算各的
关键区别　普通运算会进位；位运算每一位独立计算，绝不进位

1.2 六个位运算符

运算符名称规则（每一位）例子
&按位与两个都是 1 才得 16 & 3 = 2
|按位或有一个是 1 就得 16 | 3 = 7
^按位异或两个不同才得 16 ^ 3 = 5
~按位取反0 变 1、1 变 0~6 = −7
<<左移整体左挪若干位，右边补 03 << 2 = 12
>>右移整体右挪若干位，左边补符号位12 >> 2 = 3
打个比方： 普通的加减乘除，是把整个数当成一个整体来算的；
而位运算是把数拆成一位一位，每一位单独算，算完再拼回去。
就像一排八盏灯：普通运算看的是"整排灯总共有多少瓦"， 位运算看的是"第几盏灯是亮着的"。
所以位运算最关键的一点是：不做进位。
六个运算符（C++ 写法）： &　|　^　 ~　<<　>>
注意别混淆：&& 是逻辑与、|| 是逻辑或， 它们的结果只有 0 和 1；而 &、| 是按位算的，结果可以是别的数。

2　与、或、异或

AND, OR, XOR

2.1 三种逐位运算的法则

拿 6 和 3 一起算一遍 TEXT 
6 = 0110
3 = 0011

6 & 3 = 0010 = 2      逐列都取"与"
6 | 3 = 0111 = 7      逐列都取"或"
6 ^ 3 = 0101 = 5      逐列都取"异或"
验算　6 & 3：第 2 位（值 4）两数都是 1 → 保留； 第 0 位（值 1）只有 3 是 1 → 与掉。所以得 2

2.2 异或的妙用

异或有个很妙的性质： 自己异或自己等于 0　a ^ a = 0
异或 0 等于自己　　a ^ 0 = a
异或满足交换律　　a ^ b = b ^ a
连续异或两次会"还原"　(a ^ b) ^ b = a
两个经典用法，都用异或"还原"的性质 C++ 
// 用法一：不借第三个变量，交换两个数
int a = 5, b = 9;
a = a ^ b;      // a 变成了 5^9
b = a ^ b;      // (5^9)^9 = 5   → b 拿到原来的 a
a = a ^ b;      // (5^9)^5 = 9   → a 拿到原来的 b
cout << a << " " << b;      // 9 5

// 用法二：找出唯一出现一次的数
// 其他数都出现两次，把它们全部异或起来，成对的会互相抵消
int arr[] = {5, 7, 9, 7, 5};
int r = 0;
for (int x : arr) r ^= x;
cout << r;                  // 9
OUTPUT　9 5　/　9
为什么"成对的会互相抵消"？ 因为异或满足交换律和结合律，我们可以把式子重新排一排：
5 ^ 7 ^ 9 ^ 7 ^ 5 ＝ (5 ^ 5) ^ (7 ^ 7) ^ 9 ＝ 0 ^ 0 ^ 9 ＝ 9。
这就是"找唯一数"这类题的通用解法——不需要排序，不需要额外空间，一遍扫完。

3　取反 ~

Bitwise NOT

3.1 取反的规则

取反最简单：把每一位都反过来——0 变 1，1 变 0。

但这里有个坑：在 C++ 里，~n 的结果是负数。比如 ~6 不是 9，而是 −7。

记住这个公式就够了： ~n == −(n + 1)
~6 = −7；~0 = −1；~(−1) = 0；~100 = −101
反过来也一样：~(−7) = 6。这个公式两个方向都成立。
为什么 ~6 是 −7？拿 8 位算一遍 TEXT 
6 的八位补码：   0000 0110
按位取反：       1111 1001     ← 这就是 ~6

1111 1001 是多少？
  最高位是 1 → 负数
  按位权求和：128+64+32+16+8+1 = 249
  249 − 256 = −7

所以 ~6 = −7     ✔ 和公式 −(6+1) 一致
要点　取反会把符号位也翻过来，所以结果一定是"另一个符号"的数

3.2 为什么结果是 −(n+1)

打个比方： 取反就像照镜子——把每一位都翻成反面。
但镜子里的世界和现实是"对不上"的，因为 C++ 里的负数用的是补码表示：
一个数取反之后，正好等于"它的相反数再减 1"，也就是 −(n+1)。
别去死记，只要记住"取反 ≠ 取相反数"就不会错。
为什么是 −(n+1) 而不是 −n？ 因为"取反"只翻了面，没有加那关键的 1。
求相反数要做的是"取反再加 1"：−n == ~n + 1。
两边移项就得到 ~n == −n − 1 == −(n + 1)。
所以 ~ 和 − 之间差的就是那个 1——这也是补码定义里"反码再加 1"的来源。

4　左移与右移

Shift

4.1 左移就是乘 2

移位更好理解：把整串二进制位整体挪动若干格，空出来的位置补上。

左移：整体往左挪，右边补 0 TEXT 
3 的八位：  0000 0011
3 << 1：    0000 0110  = 6          相当于 × 2
3 << 2：    0000 1100  = 12         相当于 × 4
3 << 3：    0001 1000  = 24         相当于 × 8

规律：a << k  就相当于 a × 2 的 k 次方（只要不溢出）
记忆　左移 k 位 = 乘 2k；1 << 10 就是 1024，比写 1024 更能说明"这是 2 的幂"

4.2 右移与整数除法

右移：整体往右挪，左边补符号位 TEXT 
12 的八位： 0000 1100
12 >> 1：   0000 0110  = 6          相当于 ÷ 2 取整
12 >> 2：   0000 0011  = 3          相当于 ÷ 4 取整
12 >> 3：   0000 0001  = 1          相当于 ÷ 8 取整

移出去的低位直接丢掉 → 所以结果天然"向下取整"

对正整数：a >> k  就相当于 a ÷ 2 的 k 次方，结果向下取整
OUTPUT　12 >> 2 = 3（12 ÷ 4 = 3）
注意　如果换成正整数 7：7 >> 1 = 3，而 7 / 2 在整数除法里也是 3 ✔
两条关于"溢出"的重要规定： ① 有符号整数左移溢出时，结果是不确定的。
C++ 标准里这是未定义行为（undefined behavior）——不同编译器、不同机器可能给不同答案。
② 无符号整数的移位是"规定好的"。
溢出时它会自动丢弃高位，低位补 0，结果完全确定。
所以考试里问"有符号整数左移溢出时结果是否确定"，答案是"不确定"。
小技巧：用移位代替乘除 2 的幂 n * 8 可以写成 n << 3；n / 4 可以写成 n >> 2。
早期计算机上移位比乘除快得多，所以老代码里到处都是这种写法。
但要注意：>> 对负数不一定等于除法—— 比如 −7 / 2 在 C++ 里是 −3（向零取整），而 −7 >> 1 是 −4（向下取整）。

5　优先级与实战用法

Precedence & Usage

5.1 运算符优先级

位运算常常和别的运算混在一起出现，算错顺序就全错了。记住下面这张顺序表：

优先级运算符说明
1（最高）( )括号
2!　~　−（负号）一元运算符
3*　/　%乘除余
4+　−加减
5<<　>>移位
6<　<=　>　>=关系
7==　!=相等 / 不等
8&按位与
9^按位异或
10|按位或
11&&　||逻辑与 / 逻辑或
12（最低）=　+= 等赋值
考试时只记三条经验就够用： ① 一元运算符（~、!、负号）最高，先算它们。
② 移位比 & 高，& 比 ^ 高，^ 比 | 高——顺序是 & → ^ → |，别记反了。
③ 拿不准就加括号。括号永远最高，而且加了括号代码更好读，不丢分。
按优先级一步步拆开算 TEXT 
算 3 & 7 | 15 ^ ~11

第 1 步  ~ 最高优先：~11 = −12
         式子变成 3 & 7 | 15 ^ (−12)

第 2 步  只剩 > ^ > |，先算 &：3 & 7 = 3
         式子变成 3 | 15 ^ (−12)

第 3 步  再算 ^：15 ^ (−12)
         15      = 0000 1111
         −12     = 1111 0100
         异或    = 1111 1011 = −5

第 4 步  最后算 |：3 | (−5)
         0000 0011 | 1111 1011 = 1111 1011 = −5

结果：−5
答案　−5　　—— 按"~ → & → ^ → |"的顺序，一步步来就不容易错

5.2 四个常见用途

用途写法说明
判断奇偶n & 1结果是 1 就是奇数；比 n % 2 更快
取出第 k 位(n >> k) & 1右移 k 位让第 k 位到最低位，再与 1
把第 k 位置 1n | (1 << k)用"或"把那一格强行点亮
把第 k 位清 0n & ~(1 << k)用"与"一个"除了第 k 位全是 1"的数
把第 k 位翻面n ^ (1 << k)用"异或"翻转单一位
判断 2 的幂n > 0 && (n & (n−1)) == 02 的幂只有一位是 1，减 1 后就会变成全 0
重点掌握"位掩码"（bit mask）的思路： 用一个整数的每一位表示一种"有 / 没有"。
比如权限管理：1 << 0 表示读、1 << 1 表示写、 1 << 2 表示修改、1 << 3 表示删除。
添加权限用 |，清除权限用 & ~，检查权限用 &。
一个整数就能装下四种权限，比用四个 bool 变量省事得多。
位掩码：一个整数管四种权限 C++ 
#include <iostream>
using namespace std;

int main() {
    const int READ   = 1 << 0;      // 0001
    const int WRITE  = 1 << 1;      // 0010
    const int MODIFY = 1 << 2;      // 0100
    const int DELETE_ = 1 << 3;     // 1000

    int mask = 0;                   // 什么权限都没有

    mask = mask | READ;             // 添加读
    mask = mask | WRITE;            // 添加写
    cout << mask << endl;           // 3   → 0011

    mask = mask & (~READ);          // 清除读，其他位不变
    cout << mask << endl;           // 2   → 0010

    mask = mask | DELETE_;          // 添加删除
    cout << mask << endl;           // 10  → 1010

    return 0;
}
OUTPUT　3 / 2 / 10
读懂关键　mask & (~READ) 里的 ~READ 是"除了第 0 位，其余全是 1"， 与上去正好把第 0 位清掉、别位不动

你蹲下看第一块：6 & 3。 ……0110 和 0011，逐列取与，是 0010，等于 2。
石板亮了。他点头：记住你不是在算数，你是在一根一根地拨灯。

思路：把每一个表达式按运算符优先级拆成几步，每一步都换算成二进制看。

把六个位运算符一次跑完 C++ 
#include <iostream>
using namespace std;

int main() {
    int a = 6, b = 3;

    cout << (a & b) << " ";      // 2   按位与
    cout << (a | b) << " ";      // 7   按位或
    cout << (a ^ b) << " ";      // 5   按位异或
    cout << (~a)    << " ";      // -7  按位取反
    cout << (a << 2) << " ";     // 24  左移 2 位 = ×4
    cout << (a >> 1) << endl;    // 3   右移 1 位 = ÷2 取整

    return 0;
}
OUTPUT　2 7 5 -7 24 3
验证　~6 = −(6+1) = −7 ✔　6 << 2 = 6×4 = 24 ✔　6 >> 1 = 3 ✔
和本单元的关系： 这六行就是本单元的全部内容。
建议你在本地把 a、b 换成别的数（负数也试试）， 观察每个运算符的结果怎么变——尤其是 ~ 和负数右移， 自己动手跑一遍，比背十条规则都管用。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
位运算的错，一半是"把 & 和 && 搞混"，一半是"优先级想当然"。
1
把按位与 & 当成了逻辑与 &&。
扣哒鸭：6 & 3 是 2，而 6 && 3 是 1（非零即真）。
两个字符之差，结果是"按位算"还是"当真假算"的天壤之别。
正确认识：&/| 按位算；&&/|| 按真假算
2
以为 ~n 就是"取相反数"。
扣哒鸭：~6 不是 −6，是 −7。
取反只是翻面，没有加 1。
想取相反数，得写 −n 或者 ~n + 1。
记公式：~n == −(n+1)，−n == ~n + 1
3
以为"有符号整数左移溢出后结果还是确定的"。
扣哒鸭：规则说得很清楚：有符号整数左移导致溢出时，结果是未定义行为（UB），不确定。
只有无符号整数的移位才是"规定好"的——高位丢掉、低位补 0。
正确认识：有符号左移溢出 → 结果不确定；无符号 → 确定（丢弃高位）
4
忘记 &、^、| 之间的优先级，从左往右瞎算。
扣哒鸭：顺序是 & → ^ → |，不是从左往右。
1 | 2 & 3 先算 2 & 3 = 2，再 1 | 2 = 3；
要是从左往右算就变成 (1|2) & 3 = 3 & 3 = 3——这次碰巧一样，换个数字就差远了。
稳妥做法：拿不准就加括号，既不会错，也更好读

8　题目练习

Practice

前 4 题改编自 C++ 三级真题，其余为原创练习题。

改编自 2026 年 9 月 · C++ 三级 · 第 6 题单选题
关于位运算，下列说法错误的是（　　）。
A.找唯一数：数组中唯一出现一次的数、其余都出现两次，全部异或的结果即为该数
B.若左移导致高位溢出（如超过整型范围），结果不再符合乘法规律
C.有符号整数左移溢出时，结果确定
D.一个二进制数的最后两位是 00，它一定是 4 的倍数
查看答案与详解
答案：C。C++ 标准规定：有符号整数左移如果导致溢出，属于未定义行为（UB），结果是不确定的， 不同编译器可能给出不同答案。
能确定的是无符号整数——它溢出时会丢弃高位、低位补 0。
A 项是异或的经典应用，正确：成对的数异或后抵消为 0，只剩唯一那个数。
B 项正确：一旦溢出，a << k 就不再等于 a × 2k 了。
D 项正确：最后两位权重是 2 和 1，都为 0 说明这个数一定是 4 的倍数。
对应小节4.2 右移与整数除法；2.2 异或的妙用。
改编自 2026 年 9 月 · C++ 三级 · 第 7 题单选题
表达式 3 & 7 | 15 ^ ~11 的结果是（　　）。
A.−9　　B.−1　　C.−7　　D.−5
查看答案与详解
答案：D。按优先级 ~ → & → ^ → | 逐步算：
① ~11 = −(11+1) = −12　（一元运算符最高）
② 3 & 7：0011 & 0111 = 0011 = 3
③ 15 ^ (−12)：0000 1111 ^ 1111 0100 = 1111 1011 = −5
④ 3 | (−5)：0000 0011 | 1111 1011 = 1111 1011 = −5
所以结果是 −5。
易错点：如果从左往右瞎算，或者把 & 和 | 的优先级记反，就会选到别的项。
对应小节5.1 运算符优先级。
改编自 2026 年 9 月 · C++ 三级 · 第 5 题单选题
下面程序的输出是（　　）。
int x = 2026;
int count = 0;
while (x > 0) {
    count++;
    x = x & (x - 1);
}
cout << count << endl;
A.2026　　B.8　　C.16　　D.32
查看答案与详解
答案：B。x & (x − 1) 这个写法的效果是 把 x 的二进制里最右边的那个 1 变成 0。
所以这个循环执行的次数，正好等于 x 的二进制里 1 的个数。
把 2026 拆成 2 的幂之和：1024 + 512 + 256 + 128 + 64 + 32 + 8 + 2， 一共 8 项，也就是二进制里有 8 个 1，所以输出 8。
验算：2026 = 11111101010₂，数一数确实是 8 个 1 ✔
记住这个技巧：x & (x−1) 是"消掉最低位的 1"， 用来统计 1 的个数（也叫 popcount）或判断是不是 2 的幂都很方便。
对应小节5.2 四个常见用途。
改编自 2026 年 9 月 · C++ 三级 · 第 11 题单选题
下面选项中提到的变量都是正整数，关于位运算，说法错误的是（　　）。
A.num >> 1，对于正整数，等价于对 num 做整数除以 2 并向下取整
B.num | 0x0F，可以把 num 的低 4 位全部置为 1，高位保持不变
C.num ^ num 的结果一定等于 0
D.若 num 右移时低位被移出丢弃，结果一定符合除法数学规律
查看答案与详解
答案：D。A、B、C 三项都正确：
A：正整数右移 1 位，移出的低位直接丢弃，等价于除以 2 向下取整。
B：0x0F 就是 0000 1111， 与任何数"或"之后，低 4 位必然全为 1，而高 4 位原样保留
（因为"或 0"不改变原值）。
C：相同的两个数异或，每一位都是"相同"，结果必然全 0。
D 项错在"一定"两个字：这只对正整数成立。
对负数就不成立——C++ 的 / 是向零取整， 而右移是向下取整。比如 −7 / 2 = −3，但 −7 >> 1 = −4。

原创练习题单选题
表达式 ~5 + 1 的值是（　　）。
A.−6　　B.−5　　C.5　　D.6
查看答案与详解
答案：B。~5 = −(5+1) = −6，再加 1 得 −5。
换个角度看更清楚：前面讲过 −n == ~n + 1， 所以 ~5 + 1 正好就是 −5。
这道题的本质："取反再加 1"就是求相反数——这正是补码的定义。
对应小节3.2 为什么结果是 −(n+1)。
原创练习题判断题
表达式 1 | 2 & 3 的结果是 3。（　　）
查看答案与详解
答案：正确（√）。按优先级，& 比 | 高， 所以先算 2 & 3：
0010 & 0011 = 0010 = 2；
再算 1 | 2：0001 | 0010 = 0011 = 3。
结果是 3。
有意思的是：如果误按"从左往右"算，会得到 (1|2) & 3 = 3 & 3 = 3， 答案碰巧一样——所以这题不算陷阱，但换个数字就不一样了。
结论：别靠运气，老老实实按优先级（或加括号）。

原创练习题编程题
题目要求：读入一个非负整数 n，输出它的二进制表示中 1 的个数， 以及最高位 1 在第几位（最低位记为第 0 位）。
查看参考答案与要点 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int cnt = 0;        // 1 的个数
    int high = -1;      // 最高位 1 的位置
    int pos = 0;
    int t = n;

    while (t > 0) {
        if (t & 1) {    // 看最低位是不是 1
            cnt++;
            high = pos; // 每次更新，循环结束时留在最高位
        }
        t >>= 1;        // 整体右移一位
        pos++;
    }

    cout << cnt << " " << high << endl;
    return 0;
}

输入 2026 输出：8 10　（2026 的二进制是 11111101010， 共 8 个 1，最高位在第 10 位）
要点：
① t & 1 取出最低位、t >>= 1 右移一位， "看一位、挪一位"是位运算题的标准循环结构；
② 因为是从低位往高位扫，每次满足条件就更新 high，最后留下的自然就是最高位；
③ 用 t 做副本，不破坏原来的 n；
④ 别忘了 n = 0 的情况——此时 cnt = 0、high = −1， 循环一次都不进，结果也是对的。

哈利 · 铁匠
四句话记住位运算：
一、位运算是"一位一位地算"，绝不进位。
二、与（都亮才亮）、或（有一盏就亮）、异或（不一样才亮）。
三、~n = −(n+1)；左移 k 位乘 2 的 k 次方，右移 k 位除 2 的 k 次方取整。
四、优先级：~ → 移位 → & → ^ → |，拿不准就加括号。
闸门会拨了。下一站我们去矿道图纸那儿——那里讲的是怎么把一件事"说清楚"再动手。

你在光栅闸门前收获了什么

  • 位运算的本质——逐位独立计算，不进位。
  • 按位与 &——都为 1 才得 1；常用来"取某几位"或"清某几位"。
  • 按位或 |——有一个 1 就得 1；常用来"置位"。
  • 按位异或 ^——不同才得 1；a ^ a = 0，可用来找唯一数、交换两数。
  • 按位取反 ~——~n == −(n+1)；~n + 1 == −n。
  • 左移 <<——a << k 相当于 a × 2k；右边补 0。
  • 右移 >>——正整数时相当于 a ÷ 2k 向下取整；对负数不一定等于除法。
  • 溢出——有符号左移溢出是未定义行为（不确定）；无符号会丢弃高位。
  • 优先级——~ > 移位 > & > ^ > |。
  • 常用套路——n & 1 判奇偶、(n >> k) & 1 取第 k 位、 n | (1 << k) 置位、n & ~(1 << k) 清零、 x & (x−1) 消掉最低位的 1。
  • 位掩码——用一个整数的每一位表示一种状态，添加用 |、清除用 & ~、检查用 &。
