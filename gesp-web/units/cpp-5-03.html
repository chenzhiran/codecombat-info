1　大数为什么装不下

Integer Overflow

1.1 每种类型都有上限

类型占用大致范围有多少位十进制
int4 字节−2.1 × 10⁹ ~ 2.1 × 10⁹约 9 ~ 10 位
unsigned int4 字节0 ~ 4.2 × 10⁹约 9 ~ 10 位
long long8 字节−9.2 × 10¹⁸ ~ 9.2 × 10¹⁸约 18 ~ 19 位
装不下会怎样 C++ 
int a = 2000000000;
a = a * 2;                 // 本来该是 40 亿
cout << a << endl;          // -294967296   ← 变成负数了

// 这叫"溢出"（overflow）
// 加过头会"绕回去"，而且 C++ 不会给你任何提示
最危险的地方　 溢出不会报错、不会警告，程序照跑——只是结果是错的
怎么判断"会不会溢出"？ 拿到题目先看数据范围，再算一下答案最大可能是多少位。
答案超过 18 位 → long long 也装不下 → 必须用高精度。
顺便记住两个常用的安全写法： a * b 容易溢出时，可以先转 long long 或改用除法做判断（比如判质数时写 i <= n / i）。
而如果位数真的超出类型上限，那就只有一条路：高精度。

1.2 大数从哪儿来

几种常见的"大数来源" TEXT 
① 大数的阶乘
     30! = 265252859812191058636308480000000     ← 33 位

② 大数的幂
     2^200 = 1606938044258990275541962092341162602522202993782792835301376   ← 61 位

③ 斐波那契数列的后面几项
     F(100) 就已经有 21 位了

④ 加法、递推结果不断累加
     1000 个十位数相加，结果可能有一两千位

这几种题一旦出现，就必须上高精度。
识别信号　 题目里出现"阶乘"、"次方"、"递推很多项"、"输入是几十位的整数"——基本就是高精度题
打个比方： 变量的容量就像一个固定大小的水桶——水满了再往里倒，就会溢出来。
int 是个小桶，long long 是个大桶，但都有底。
而高精度就是"不用桶"，改用一长排小格子，一位数字占一格—— 想装多少位都行，只看你开了多长的数组。

2　用数组存一个大数

Storing with an Array

2.1 每一位住一格

把 12345 存进一个数组 TEXT 
数字：      1  2  3  4  5
位数：      万 千 百 十 个

【方案一】高位在前（和读法一致）
   下标：  0   1   2   3   4
   内容：  1   2   3   4   5

【方案二】低位在前（高精度里用这个）
   下标：  0   1   2   3   4
   内容：  5   4   3   2   1
           ↑
           a[0] 存个位
高精度里统一用"低位在前"　 也就是 a[0] 存个位、a[1] 存十位、a[2] 存百位……

2.2 低位在前还是高位在前

为什么高精度要用"低位在前"？ 因为进位是"从右往左"传的。
竖式加法里，我们总是先算个位、再算十位、再算百位—— 个位算出的进位要交给十位。
用"低位在前"存，个位就是 a[0]， 十位是 a[1]——进位天然就是"往后一位"， 下标一路递增，写起来顺得很。
而多出来的那一位进位，直接放到数组末尾（下标更大处）就行。
三段式：输入 → 计算 → 输出 C++ 
// ① 把读进来的字符串转成"低位在前"的数组
string s;  cin >> s;
int a[1005], len = s.size();
for (int i = 0; i < len; i++) {
    a[i] = s[len - 1 - i] - '0';    // ★ 从字符串末尾往前取
}
// "12345" → a[0]=5, a[1]=4, a[2]=3, a[3]=2, a[4]=1

// ② 各种运算都在这上面做……

// ③ 输出时要倒着打印（从最高位开始）
for (int i = len - 1; i >= 0; i--) {
    cout << a[i];
}
三个关键点　 ① 输入用 string 读（因为位数太多，整数类型装不下）；
② 存的时候倒着存（s[len-1-i]）；
③ 输出时再倒回来（从 len-1 打到 0）
最容易错的一步：- '0' 别忘了。 读进来的是字符，不是数字。
s[0] 是字符 '1'，它的值是 49，不是 1。
必须减掉 '0'（也就是减 48）才能得到真正的数字 1。
忘了这一步，算出来会是一堆乱七八糟的大数——而且不会报错。

3　高精度加法

Big Integer Addition

3.1 竖式的三步

小学竖式：一位一位加，满了就进位 TEXT 
算 999 + 7：

      9 9 9
    +     7
    ─────────
    1 0 0 6

过程（从个位开始）：
  个位：9 + 7 = 16 → 写 6，进位 1
  十位：9 + 0 + 1(进位) = 10 → 写 0，进位 1
  百位：9 + 0 + 1(进位) = 10 → 写 0，进位 1
  千位：没有数了，但还有进位 1 → 补上 1

结论：每一位算的是"两个数字之和 + 上一位的进位"，
      写下来的那一位是"和取个位"，新的进位是"和除以 10"。
两个公式　 写进结果的那一位 = sum % 10；
新的进位 = sum / 10

3.2 完整代码

高精度加法 C++ 
// a、b 都是"低位在前"的大数数组，len 是较长者的位数
vector<int> add(const vector<int> &a, const vector<int> &b) {
    vector<int> c;
    int carry = 0;                          // ★ 进位，从 0 开始
    int n = max(a.size(), b.size());

    for (int i = 0; i < n; i++) {
        int sum = carry;                    // ① 先把进位算进来
        if (i < (int)a.size()) sum += a[i];  // ② 加上这一位
        if (i < (int)b.size()) sum += b[i];

        c.push_back(sum % 10);              // ③ 写下这一位
        carry = sum / 10;                   // ★ 算出新的进位
    }

    if (carry) c.push_back(carry);          // ★ 最后还有进位就补一位
    return c;
}
三个关键动作　 ① sum 先加上 carry；
② 写下 sum % 10；
③ carry = sum / 10，且循环结束后若 carry 不为 0 要再补一位
真题就考这一句：carry = sum / 10; 很多同学会顺手写 carry = sum % 10;—— 那就错了：% 得到的是"写下来的那一位"， / 得到的才是"要交给下一位的进位"。
记法："写的用取余，进位的用整除。"
再强调一遍：循环结束后的 if (carry) 不能省。 比如 999 + 7，它最后会多出一位千位的 1—— 少了这一句，答案就变成 006 了。

4　高精度减法

Big Integer Subtraction

4.1 借位怎么处理

小学竖式：不够减就向前借 1 TEXT 
算 1000 - 7：

     1 0 0 0
   -       7
   ───────────
       9 9 3

过程（从个位开始）：
  个位：0 - 7 = -7，不够！→ 向前借 1 → 10 - 7 = 3，借位标记 = 1
  十位：0 - 0 - 1(借位) = -1，不够！→ 借 1 → 10 - 1 = 9，借位标记 = 1
  百位：0 - 0 - 1 = -1，不够！→ 借 1 → 10 - 1 = 9，借位标记 = 1
  千位：1 - 0 - 1 = 0

结论：每一位算的是"a 的这一位 − b 的这一位 − 上一位的借位"。
      如果结果 < 0，就加 10、并标记"向再前一位借了 1"。
三种情况　 ① 结果 ≥ 0 → 直接写下来，borrow = 0；
② 结果 < 0 → 加 10 再写下来，borrow = 1

4.2 完整代码

高精度减法（保证 a ≥ b） C++ 
// 保证 a >= b，结果非负
vector<int> sub(const vector<int> &a, const vector<int> &b) {
    vector<int> c;
    int borrow = 0;                     // ★ 借位标记，0 表示没借

    for (int i = 0; i < (int)a.size(); i++) {
        int t = a[i] - borrow;          // 先减掉上一次的借位
        if (i < (int)b.size()) t -= b[i];   // 再减 b 的这一位

        if (t < 0) {                    // ★ 不够减 → 向前借
            t += 10;
            borrow = 1;
        } else {
            borrow = 0;
        }
        c.push_back(t);
    }

    // 去掉高位多余的 0（但要至少保留一位）
    while (c.size() > 1 && c.back() == 0) c.pop_back();
    return c;
}
三个要点　 ① 先减 borrow，再减 b[i]；
② t < 0 时 t += 10 并置 borrow = 1；
③ 结束后去掉高位的 0（1000 - 1000 的结果不该是 0000）
高精度减法必须先保证 a ≥ b。 上面这段代码只会算出正确答案的绝对值。
如果被减数比减数小，你得先自己"掉个个儿"，算完之后再补一个负号。
判断大小的办法：先比位数（位数多的更大）， 位数相同时从高位往低位逐位比。
考试里如果题目保证了"被减数不小于减数"（真题里就常这么写），那就不用管这一步。
加法和减法的结构，其实长得一模一样。 都是：从低位到高位循环 → 算这一位 → 处理"向上一位的传递" → 记下结果。
加法传递的是进位，减法传递的是借位。
看懂了其中一个，另一个也就懂了。

5　高精度乘单精度数

Multiply by a Small Number

5.1 一位一位地乘

大数 × 一个普通整数 C++ 
// 把大数 a 乘以普通整数 k（k 在 int 范围内）
vector<int> mulSmall(const vector<int> &a, int k) {
    vector<int> c;
    long long carry = 0;                    // ★ 进位可能很大，用 long long

    for (int i = 0; i < (int)a.size(); i++) {
        long long cur = (long long)a[i] * k + carry;
        c.push_back(cur % 10);              // 写下这一位
        carry = cur / 10;                   // 新的进位
    }

    while (carry > 0) {                     // ★ 进位可能还剩好几位
        c.push_back(carry % 10);
        carry /= 10;
    }
    return c;
}
和加法几乎一样　 只是把 a[i] + b[i] 换成了 a[i] * k
注意两点　 ① 进位必须用 long long（9 × 99 + 进位 可能超过 int）；
② 循环结束后进位可能不止一位，要用 while 一位位地补完

5.2 阶乘就是典型例子

求 n! 的精确值 C++ 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> a;
    a.push_back(1);                    // 从 1 开始

    for (int i = 2; i <= n; i++) {
        long long carry = 0;
        for (int j = 0; j < (int)a.size(); j++) {
            long long cur = (long long)a[j] * i + carry;
            a[j] = cur % 10;
            carry = cur / 10;
        }
        while (carry > 0) {
            a.push_back(carry % 10);
            carry /= 10;
        }
    }

    for (int i = (int)a.size() - 1; i >= 0; i--) cout << a[i];
    cout << endl;
    return 0;
}
n = 30 时 OUTPUT　265252859812191058636308480000000（33 位）
n = 100 时会输出 158 位——这已经远远超出 long long 的能力了
阶乘为什么必须用高精度？ 因为阶乘长得极快。 20! 大约 2.4 × 10¹⁸，刚好卡在 long long 上限附近；
到了 21! 就已经超过 long long 了。
所以只要 n 超过 20，就必须上高精度。
顺便记一下本题的写法：a 数组是从低位到高位存的， 所以最后要倒着打印。

6　代码实战

Level Practice
关卡

奥林匹克比赛

进入关卡 →
故事：巨钟上刻着比赛的计分，分数高得吓人——一长串数字。
塞尼克把记录板递给你：钟身只能写下位数有限的数字， 可比赛的总分远远超过它。
你看了看那串数字：那就一位一位地记在石格子里，算完再拼起来。
对了。他点点头，变量装不下的时候，就换一整个数组来装。

思路：把两个大数读成字符串，倒着存进数组， 像竖式一样一位一位相加，最后倒着输出。

读入 → 相加 → 输出，一条龙 C++ 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s1, s2;
    cin >> s1 >> s2;

    int a[1005] = {0}, b[1005] = {0}, c[1005] = {0};
    int la = s1.size(), lb = s2.size();

    // ① 倒着存进数组（低位在前）
    for (int i = 0; i < la; i++) a[i] = s1[la - 1 - i] - '0';
    for (int i = 0; i < lb; i++) b[i] = s2[lb - 1 - i] - '0';

    // ② 一位一位相加
    int len = max(la, lb);
    for (int i = 0; i < len; i++) {
        c[i] += a[i] + b[i];       // 加上这一位
        c[i + 1] += c[i] / 10;     // ★ 进位交给下一位
        c[i] %= 10;                // ★ 自己只留个位
    }
    if (c[len]) len++;             // 最高位还有进位

    // ③ 倒着输出
    for (int i = len - 1; i >= 0; i--) cout << c[i];
    cout << endl;
    return 0;
}
输入　999 7　　输出　1006
输入　123456789123456789 987654321987654321　　输出　1111111111111111110
和本单元的关系： 这段代码把"存"和"算"分开写，比前面那版更好懂。
进位处理用了一个小技巧：不是先算 sum 再拆，而是
c[i] += a[i] + b[i];　→　c[i+1] += c[i] / 10;　→　c[i] %= 10;
先把这一位的和攒着，把进位往高位丢，最后再把自己"削"成一位数字。 结果完全一样，但写起来更短。
两种写法都值得掌握——考试里可能考其中任意一种。

7　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
高精度的坑特别集中——全是"边界"。四条。
1
把进位写成了 sum % 10。
扣哒鸭：sum % 10 是写进结果的那一位， sum / 10 才是要交给下一位的进位——这两句千万别调包。
写反了程序不报错，但结果全错。
记牢：写的用 %，进位的用 /
2
忘了处理最后剩下的进位。
扣哒鸭：999 + 7 最高位会多出一位。 循环走完之后，carry 如果还是 1，必须再往结果里补一位。
少了这一步，答案就少了一位——1006 会变成 006。
正确做法：if (carry) c.push_back(carry);
3
忘记减 '0'，或者输出时忘了倒序。
扣哒鸭：s[i] 是字符，值在 48~57 之间， 不减 '0' 存进去的就是字符编码。
另外，既然存的时候倒着存了，输出时就必须从最高位往低处打—— 忘了倒序，12345 会打印成 54321。
正确做法：输入时 - '0'；输出时 for (i = len-1; i >= 0; i--)
4
减法结果是 0，却输出了一串 0。
扣哒鸭：高精度减法算完之后，高位上可能留下一串没用的 0。
比如 1000 - 1000，数组里是 0 0 0 0， 直接倒着输出就是 0000，而不是 0。
要写一句去掉高位 0 的循环——但要保证至少留一位。
正确做法：while (c.size() > 1 && c.back() == 0) c.pop_back();

改编自 2026 年 9 月 · C++ 五级 · 第 15 题单选题
数组 a 和 b 按低位在前的顺序 保存两个非负大整数。下面代码实现高精度加法，横线处应填写（　　）。
vector<int> add(const vector<int> &a, const vector<int> &b) {
    vector<int> c;
    int carry = 0;
    int n = max(a.size(), b.size());
    for (int i = 0; i < n; i++) {
        int sum = carry;
        if (i < a.size()) sum += a[i];
        if (i < b.size()) sum += b[i];
        c.push_back(sum % 10);
        ____________________
    }
    if (carry) c.push_back(carry);
    return c;
}
A.carry = sum % 10;　　B.carry = sum;
C.carry = sum / 10;　　D.carry = c[i] / 10;
查看答案与详解
答案：C。前面那句 c.push_back(sum % 10); 已经把"这一位要写下的数字"交出去了——接下来要算的，是"要带给下一位的进位"。
进位怎么算？把这一位的总和除以 10，取整数部分。
举例：个位相加得 16 →
sum % 10 = 6 → 写下 6；
sum / 10 = 1 → 进位是 1，交给十位。
A 项把两句写反了：carry 和写下的数字变成同一个值， 等于进位丢了。
B 项把整个 sum 当进位， 进位就爆炸了（比如 16 全进上去）。
D 项用的是 c[i]，那是刚才写下的个位数字， 和进位毫无关系。
一句话记牢：% 管"写"，/ 管"进"。

假设两个非负高精度整数分别存储在数组 a 和 b 中， 且已保证被减数不小于减数。数组采用低位在前的方式存储 （即 a[0] 表示个位）。下面代码中的 c 可以正确保存 a − b 的各位数字。（　　）
int borrow = 0;
for (int i = 0; i < len; ++i) {
    int t = a[i] - b[i] + borrow;
    if (t < 0) { t += 10; borrow = 1; }
    else       { borrow = 0; }
    c[i] = t;
}
查看答案与详解
答案：正确（√）。这段代码正确地实现了"逐位相减 + 借位"的逻辑。
三个动作都对：
① int t = a[i] - b[i] + borrow; —— 把上一位的借位也扣掉（借位是"减去 1"，所以是加在减数一边）；
② if (t < 0) { t += 10; borrow = 1; } —— 不够减就借一个 10 过来，并标记"欠了 1"；
③ else { borrow = 0; } —— 够减就把借位清零（这一步最容易被忘掉， 忘了的话借位会一直往下传）。
验证一下 1000 − 7：
个位：0 − 7 + 0 = −7 → 借 → 3，borrow = 1；
十位：0 − 0 + 1 = −1 → 借 → 9，borrow = 1；
百位：0 − 0 + 1 = −1 → 借 → 9，borrow = 1；
千位：1 − 0 + 1 = 0，borrow = 0。
结果各位是 3、9、9、0 —— 倒过来读就是 0993， 去掉高位的 0 就是 993 ✔

原创练习题判断题
在高精度运算中，通常把大数的最低位（个位）存放在数组下标 0 的位置。（　　）
查看答案与详解
答案：正确（√）。这就是所谓的"低位在前"存储。
为什么要这样存？因为竖式计算是从个位开始的—— 先算个位、再算十位、再算百位。
把个位放在 a[0] 之后：
进位/借位的方向（从低位到高位）正好和"下标递增"的方向一致； 而新产生的高位（比如最高位的溢出进位）直接 push_back 到数组末尾就行。
如果反过来用"高位在前"存：个位就在数组最末尾， 那么进位要往"下标减小的方向"传， 还可能出现"最高位溢出却无处可放"的麻烦——代码会难写很多。
代价只有一个：输入和输出时都要手动倒一次顺序 （读字符串时从末尾往前取，输出时从 len−1 往 0 打）。
对应小节2.2 低位在前还是高位在前。
原创练习题编程题
题目要求：读入一个正整数 n（1 ≤ n ≤ 100）， 输出 n! 的精确值（不能有误差）。
样例：输入 10，输出 3628800。
查看参考答案与要点 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> a;
    a.push_back(1);                     // 从 1 开始

    for (int i = 2; i <= n; i++) {      // 依次乘 2、3、…、n
        long long carry = 0;            // ★ 进位用 long long
        for (int j = 0; j < (int)a.size(); j++) {
            long long cur = (long long)a[j] * i + carry;
            a[j] = cur % 10;            // 写下这一位
            carry = cur / 10;           // 算出新的进位
        }
        while (carry > 0) {             // ★ 进位可能还剩好几位
            a.push_back(carry % 10);
            carry /= 10;
        }
    }

    for (int i = (int)a.size() - 1; i >= 0; i--) cout << a[i];
    cout << endl;
    return 0;
}

输入 10 输出：3628800；输入 30 输出：265252859812191058636308480000000
要点：
① 21! 就已经超过 long long 了， 所以从 21 开始必须用高精度——本题 n 能到 100，非高精度不可；
② 乘法的进位必须用 long long： a[j] 最大是 9、i 最大是 100、进位也可能不小， 三者相加用 int 有溢出风险；
③ 每一轮的 carry 都要重新清零（写在内层循环外面、外层循环里面）；
④ 内层循环结束后进位可能还剩好几位， 必须用 while 一位一位补完，不能只补一位；
⑤ 数组是"低位在前"存的，输出时要倒着打。
对应小节5.2 阶乘就是典型例子。

四句话记住高精度：
一、int 约 10 位、long long 约 18 位；答案超过就只能上高精度。
二、用数组存：a[0] 存个位（低位在前），输入输出都要倒一次。
三、每位算"和 + 进位"，写下的用 %10、交给下一位的用 /10。
四、减法记住借位要清零；乘法进位用 long long，且循环后可能剩多位。
钟报数了。下一站是商队铁链——那里没有一排格子，每一节只认下一节在哪。

你在巨钟下收获了什么

  • 类型上限——int 约 ±2.1 × 10⁹（9~10 位）， long long 约 ±9.2 × 10¹⁸（18~19 位）。
  • 溢出不报错——加过头会"绕回去"，程序照跑，只是结果是错的。
  • 什么时候用高精度——看数据范围，答案超过 18~19 位就必须用。
  • 常见的大数来源——阶乘、大数的幂、斐波那契、不断累加。
  • 存储方式——用数组，一位数字占一格； a[0] 存个位（低位在前）。
  • 为什么低位在前——进位/借位是"从低位往高位"传的， 这样下标递增的方向正好一致。
  • 输入输出——用 string 读大数； a[i] = s[len−1−i] − '0'；输出时倒着打。
  • 别忘了 − '0'——字符 '1' 的值是 49，不是 1。
  • 高精度加法——sum 先加进位， 写下 sum % 10，进位 = sum / 10。
  • 最后的进位要补——if (carry) c.push_back(carry);。
  • 高精度减法——先减 borrow 再减 b[i]； t < 0 时 t += 10、borrow = 1， 够减时 borrow = 0。
  • 减法要先保证 a ≥ b，否则结果只是绝对值；结束后要去掉高位的 0。
  • 高精度乘单精度——结构和加法一样， 进位用 long long，循环后可能剩好几位进位。
