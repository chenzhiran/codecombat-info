1　顺序结构：一步接一步

Sequential Flow

1.1 什么是一句话

打个比方： 顺序结构就像排队打饭——前面的同学没打完，后面的同学绝不能插上去。
计算机也是一位"特别守规矩的排队者"：它永远从第一行开始，一行一行往下走，绝不跳行、绝不回头。
所以你不能"先使用、后计算"——顺序错了，结果就错了。

1.2 C++ 程序的完整骨架

背下这个骨架，所有一级题目都能往里填 C++ 
#include <iostream>          // ① 引入输入输出功能
using namespace std;         // ② 使用标准命名空间

int main() {                 // ③ 主函数，程序从这里开始
    int a, b;                // ④ 声明变量
    cin >> a >> b;            // ⑤ 输入
    cout << a + b;            // ⑥ 计算并输出
    return 0;                // ⑦ 正常结束
}
输入　3 5　　输出　8
打个比方： 写一个完整的 C++ 程序，就像写一封信，必须有三段：
① 抬头——#include <iostream> 和 using namespace std;， 告诉驿站"我要用哪些工具"；
② 正文——int main() { … } 里写的那些语句，才是你真正要说的话；
③ 落款——return 0;，表示"我说完了"。
考试让"补全代码"时，先检查这三段缺了哪一段，通常一眼就能看出来。
骨架分三段：
头部——#include 与 using namespace std;（照抄，别改）；
主体——int main() { } 里写你的语句；
收尾——return 0;（表示程序正常结束）。
考试让"补全代码"时，先看这三段缺哪一段。

2　输出：让程序开口

Output

2.1 cout 与 <<

cout：把东西"送出去" C++ 
int a = 3, b = 4;

cout << a;                  // 输出 3
cout << a << " " << b;     // 输出 3 4（中间夹一个空格）
cout << a << "#" << b;     // 输出 3#4（中间夹一个井号）

cout << "答案是：" << a + b;   // 字符串和表达式可以连在一起
要点　<< 可以连续写；每一段输出的内容，都要单独用一个 << 接上去
箭头方向别写反： cout << a; —— 意思是"把 a 送进 cout"。
箭头指向 cout，就是"流出"；箭头指向变量，就是"流入"（cin 用）。

2.2 printf 与格式符

printf 是 C 语言传下来的输出函数，一级真题里出现得非常多。

格式符用来输出例子结果
%d整数（int）printf("%d", 42)42
%lld长整数（long long）printf("%lld", x)按原样输出
%c单个字符printf("%c", 'A')A
%f小数（float / double）printf("%f", 3.5)3.500000
%.2f小数，保留两位printf("%.2f", 3.5)3.50
%nd整数，占 n 个字符宽printf("%3d", 7)  7（右对齐补空格）
格式符里可以夹别的字符 C++ 
int a = 3, b = 4;
printf("%d#%d\n", a, b);        // 3#4     两个数字中间夹一个 #
printf("和是:%d\n", a + b);      // 和是:7

float x = 2.0;
printf("%.2f", x);              // 2.00
关键　"%d#%d\n" 里的 # 是原样输出的普通字符， 只有 %d 才会被后面的变量替换掉
打个比方： printf 的格式串就像一张填空题的答题卡。
答题卡上写着 "%d#%d\n"——凡是 % 开头的地方都是"空"，等着后面的变量来填；其他字（比如那个 #）都是印好的固定内容，照原样印出来。
填错了空（格式符和变量类型对不上），印出来的就是乱码。

2.3 换行：\n 与 endl

写法用在哪儿说明
cout << endl;cout换行，并立刻把内容送出去
cout << "\n";cout换行，效率略高
printf("\n");printf换行
printf("%c", '\n');printf效果与上一行完全相同
两种换行写法可以互相替代： printf("\n") 与 printf("%c", '\n') 输出效果一模一样。
因为 \n 本质上就是一个字符——换行符。
口诀：\n 是反斜杠加小写 n，别写成 /n，也别写成大写的 \N。

2.4 输出小数与保留位数

两种保留小数的方式 C++ 
double x = 3.14159;

// 方式一：printf，用 %.2f
printf("%.2f\n", x);        // 3.14

// 方式二：cout 配 fixed 和 setprecision
cout << fixed << setprecision(2) << x;   // 3.14
要点　小数默认输出 6 位，想控制位数就得显式指定

3　输入：让程序听见

Input

3.1 cin 与 >>

打个比方： cin 就是驿站的收货口。你把它打开，外面的人往里递什么，它就收什么。
但它有个怪脾气：你让它收整数，它就只收"能当整数看的字"，一见到减号、字母这类字，它立刻关门，剩下的留给下一次。
这就是为什么输入 2026-6-27 时，cin >> N 只能拿到 2026。
cin：把东西"收进来" C++ 
int a;
double b;
char c;

cin >> a;          // 等待用户输入一个整数
cin >> b;          // 再输入一个小数
cin >> c;          // 再输入一个字符
要点　>> 的方向与 << 相反；输入时按住回车，程序才会继续往下走

3.2 连续输入与顺序

一行里读多个数 C++ 
int a, b;
cin >> a >> b;             // 用空格、Tab 或回车隔开都行

cout << a << " " << b;
输入　3 5　　输出　3 5
输入　3（回车）5（回车）　输出　3 5　—— 换行也算分隔符
cin 读数的"规矩"： ① 自动跳过前面的空格和换行；
② 一遇到"不属于这个类型"的字符就停下来，剩下的留给下一次读。
这条规矩解释了一个常考题：如果输入 2026-6-27， 而程序是 cin >> N;（N 是 int）， 那么它只能读到 2026——读到减号就停了。

3.3 scanf 与 & 符号

scanf：printf 的"输入版" C++ 
int a;
double x;

scanf("%d", &a);          // 注意：变量前面要加 &
scanf("%lf", &x);         // double 用 %lf，不是 %f

printf("%d %.2f", a, x);
最容易忘的一点　用 scanf 时，变量名前必须加 &
打个比方： scanf 是让驿站"去外面收东西"。收货总得有个放东西的地方——
scanf("%d", &a); 里那个 &，说的就是"把收到的东西放到 a 这个箱子里"。
而 printf 是"把箱子里的东西拿出来给人看"，只需要说拿什么，不用说放哪儿，所以不加 &。
记法：收东西要地址（加 &），给人看不用（不加 &）。
记住这个配对： 输入用 scanf，变量前加 &；输出用 printf，变量前不加。
scanf("%d", &a); ✔　　printf("%d", a); ✔
写反了要么报错，要么输出一堆乱七八糟的地址数字。

4　输入输出配合的完整程序

A Complete Program
例题：读两个数，输出它们的和、差、积 C++ 
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    int sum  = a + b;
    int diff = a - b;
    int prod = a * b;

    printf("%d %d %d\n", sum, diff, prod);

    return 0;
}
输入　7 3　　输出　10 4 21
写这类题的检查清单：
① 变量声明了吗？int a, b;
② 输入的顺序对得上吗？cin >> a >> b; 先读 a 再读 b。
③ 格式符和变量类型对得上吗？整数用 %d，小数用 %f / %lf。
④ 输出的顺序和题目要求一致吗？差一个空格、少一个换行都可能不得分。

6　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
输入输出是"细节题"——错一个符号，答案就全变了。四条，条条都是丢分点。
1
scanf 忘了加 &。
扣哒鸭：“写 scanf("%d", a); 是错的， 必须写 scanf("%d", &a);。
记法：scanf 要告诉程序"东西放到哪里"，所以要写上地址 &。”
正确写法：scanf("%d", &a);
2
格式符与变量类型不匹配。
扣哒鸭：“%d 配整数，%c 配字符，%f / %lf 配小数。
把小数用 %d 输出，会得到一串莫名其妙的数字。 另外输入 double 要用 %lf，不是 %f。”
配对表：int→%d　char→%c　double→%lf（输入）/%f（输出）
3
把 \n 写成了 /n。
扣哒鸭：“换行符是反斜杠 \ 加小写 n， 不是斜杠 /。
写成 printf("/n")，屏幕上会真的输出 /n 两个字。”
正确写法：printf("\n");
4
以为 cin >> N; 能一次读进整串字符。
扣哒鸭：“如果 N 是 int，输入 2026-6-27 时， 它只会读到 2026——因为遇到减号就停了。
读什么类型，就按那个类型的规则去读，这是 cin 的铁律。”
正确认识：cin 按类型读，遇到不合法字符就停

7　题目练习

Practice

前 4 题改编自 C++ 一级真题，其余为原创练习题。

改编自 2026 年 9 月 · C++ 一级 · 第 5 题单选题
如下 C++ 代码执行后，其输出是（　　）。
int a = 3;
int b = 4;
printf("%d#%d\n", a, b);
A.3 4　　B.3#4　　C.3 # 4　　D.3#4 换行后再输出一个空行
查看答案与详解
答案：B。格式串 "%d#%d\n" 的读法是：
第一个 %d 用 a 替换 → 3；
中间的 # 是普通字符，原样输出；
第二个 %d 用 b 替换 → 4；
\n 换行。
所以输出 3#4，然后换行。
关键：格式串里只有 % 开头的才是"占位符"，其余字符一律照原样打印。
对应小节2.2 printf 与格式符。
改编自 2026 年 6 月 · C++ 一级 · 第 6 题单选题
如下 C++ 代码执行时输入 2026-6-27，下列说法正确的是（　　）。
int N;
cin >> N;
cout << N;
A.输入失败，不允许输入减号，没有输出
B.允许输入，输出 1993
C.允许输入并原样输出 2026-6-27
D.允许输入并输出 2026
查看答案与详解
答案：D。N 是 int 类型，cin >> N 会按整数规则读：
从开头读到 2026，一遇到减号 -（不属于整数的一部分），立刻停止读取。
所以 N 的值是 2026，输出也就是 2026，剩下的 -6-27 留在输入缓冲区里没被处理。
B 项是把减号当成了减法去算——cin 不做运算，它只是"照着类型取字"。
对应小节3.2 连续输入与顺序。

C++ 程序执行 cin 或 scanf 语句时， 通常是通过键盘这类输入设备来为变量提供值。（　　）
查看答案与详解
答案：正确（√）。cin 和 scanf 都是从标准输入读数据， 默认就是键盘。
顺带记一下：cout 与 printf 输出到标准输出，默认是屏幕。

把 C++ 代码中的 printf("\n") 换成 printf("%c", '\n')，输出效果相同。（　　）
查看答案与详解
答案：正确（√）。\n 本身就是一个字符（换行符），
用 %c 输出一个字符，和直接写 "\n" 的效果完全一样—— 都是"换到下一行"。

原创练习题单选题
下列 C++ 代码执行后，输出的结果是（　　）。
int a = 7;
int b = 2;
cout << a << "+" << b << "=" << a + b;
A.7+2=9　　B.7 + 2 = 9　　C.72=9　　D.9
查看答案与详解
答案：A。这段代码依次输出：a（7）、"+"（加号）、 b（2）、"="（等号）、a + b（9）。
连起来就是 7+2=9，中间没有任何多余空格。
易错点：B 项多加了空格——想要空格必须自己写成 " + "。
对应小节2.1 cout 与 <<。

使用 scanf 读入一个整数时，变量名前必须加 &。（　　）
查看答案与详解
答案：正确（√）。scanf 需要知道"把读到的值放到哪里"， 所以要写成 scanf("%d", &a);。
对比记忆：输出用的 printf 不加 &。

原创练习题单选题
下列 C++ 代码执行后，输出的结果是（　　）。
double x = 2.5;
printf("%.1f", x);
A.2.5　　B.2.50　　C.2.500000　　D.3
查看答案与详解
答案：A。%.1f 表示"按小数输出，保留 1 位"，
所以 2.5 原样输出为 2.5。
对比：如果写 %f（不指定位数），默认输出 6 位小数，得到 2.500000（C 项）。

原创练习题编程题
题目要求：读入两个整数，按下面格式输出三行—— 第一行是它们的和，第二行是它们的差（第一个减第二个），第三行是它们的积。
查看参考答案与要点 
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;                  // 一次读两个整数

    cout << a + b << endl;          // 第一行：和
    cout << a - b << endl;          // 第二行：差
    cout << a * b << endl;          // 第三行：积

    return 0;
}

输入 8 3 时输出：11、5、24
要点：
① cin >> a >> b; 一行读两个数，用空格隔开即可；
② 每个结果后面用 endl 换行，保证三行各占一行；
③ 表达式可以直接写在 cout 里，不必先存进变量；
④ 输出格式要严格遵守题目要求——多一个空格、少一次换行都可能判错。

8　本单元小结

Unit Summary
安雅 · 红发队长
三句话记住这一单元：
一、顺序结构——从上往下，一句接一句，每条语句以分号结尾。
二、输出用 cout << 或 printf，输入用 cin >> 或 scanf（记得加 &）。
三、格式符要配对：%d 配整数、%c 配字符、%f / %lf 配小数。
吊篮已经升到顶了。下一单元，我们第一次让程序"做选择"。

你在升降梯上学到了什么

  • 顺序结构——程序从上往下逐句执行；每条语句以分号结尾。
  • 程序骨架——#include → using namespace std; → int main() { } → return 0;。
  • 四步套路——声明 → 输入 → 计算 → 输出。
  • 输出——cout << a << " " << b;，各段用 << 连接。
  • printf 格式符——%d 整数、%c 字符、%f 小数、%.2f 保留两位、%3d 占三格。
  • 格式串里的普通字符原样输出——如 "%d#%d" 会输出一个 #。
  • 换行——endl、"\n"、printf("\n") 三者等价；\n 是反斜杠加 n。
  • 输入——cin >> a >> b;；空格与回车都算分隔符。
  • scanf——变量前必须加 &；double 输入用 %lf。
  • cin 的规矩——按类型读，遇到不属于该类型的字符就停下。
