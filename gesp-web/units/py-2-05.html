1　循环里的循环

Loops Inside Loops

先看一个你非常熟悉的例子：课表。

学校每周上 5 天课，每天上 4 节。你想说"每一节课都要点名"，怎么写？

  • 外层循环：遍历 5 天（周一、周二……）
  • 内层循环：每一天里遍历 4 节课（第 1 节、第 2 节……）

于是"点名"这件事总共会发生 5 × 4 = 20 次。 这就是循环嵌套：外面转一圈，里面转满好几圈。

课表点名 Python 
for day in range(5):          # 外层：5 天
    print("第", day + 1, "天")
    for lesson in range(4):   # 内层：每天 4 节课
        print("  第", lesson + 1, "节课：点名")
OUTPUT（节选）
第 1 天
  第 1 节课：点名
  第 2 节课：点名
  第 3 节课：点名
  第 4 节课：点名
第 2 天
  第 1 节课：点名
……
一句话理解： 嵌套循环就是"重复的事情里，还包含着另一件要重复的事情"。
比如：每周（外层）都要上 5 天课，每天（内层）都要上 4 节课。
星璃 · 女武神
我练兵的时候有两重口令：第一重喊"整队"，第二重喊"报数"。
整队一次，全队就要报数一整轮；整队第二次，又报一整轮。
你看，外层动一次，内层就得跑满一遍。这就是嵌套循环的节奏。

2　执行顺序与次数

Execution Order & Count

2.1 内层跑完，外层才走一步

这是嵌套循环最核心的一条规律，务必背下来：

铁律： 外层循环每执行一次，内层循环就要完整地执行一遍。
——内层不跑完，外层绝不动。

2.2 总共跑几次？

考试最爱出的题型之一：给一段嵌套循环，问最里面的语句执行了多少次。

计算公式： 总次数 = 外层次数 × 内层次数（有三层就再乘第三层）
循环体写在外层里、内层外的语句，只执行 外层次数 次——这是最容易算错的地方。
数一数各执行几次 Python 
count_a = 0
count_b = 0

for i in range(3):
    count_a += 1              # 在外层里、内层外
    for j in range(4):
        count_b += 1          # 在最里面

print(count_a)
print(count_b)
OUTPUT　3
12
怎么数最稳妥？ 看缩进！
缩进 4 格的语句 → 属于外层，执行 外层次数 次；
缩进 8 格的语句 → 属于内层，执行 外层次数 × 内层次数 次。
缩进是嵌套循环的"楼层卡"，数楼层比数次数可靠得多。

3　用嵌套循环画图

Drawing with Nested Loops

嵌套循环最直观的用途就是打印图形——因为"长方形的图案"本来就是"几行 × 每行几个"。

打印一个 3 行 5 列的星号方阵 Python 
for i in range(3):            # 3 行
    for j in range(5):        # 每行 5 个
        print("*", end="")    # end="" 表示不换行
    print()                   # 一行结束后换行
OUTPUT
*****
*****
*****

注意那个 print()——它缩进 4 格，属于外层循环。 它的作用是"每画完一行就换行"。如果把它也缩进到内层，星号就会一个一行。

打印直角三角形（第几行就几个星） Python 
for i in range(1, 5):         # i = 1,2,3,4
    for j in range(i):        # 第 i 行画 i 个星
        print("*", end="")
    print()
OUTPUT
*
**
***
****
看第 2 行：for j in range(i)—— 内层的循环次数由外层变量 i 决定。
这就是嵌套循环最漂亮的地方：外层管"第几行"，内层管"这一行画几个"。

4　break 与 continue 的管辖范围

Scope of break & continue

这是二级考试里的"高级陷阱"。先记住一句话：

铁律： break 和 continue 只管它所在的那一层循环。
在双层循环里，break 只跳出最内层，外层照样继续转。
break 到底跳出了谁 Python 
for i in range(3):
    for j in range(3):
        if j == 1:
            break          # 只跳出内层
        print(i, j)

print("结束")
OUTPUT　0 0
1 0
2 0
结束

看输出：外层 i 从 0 走到 2，每轮都只打印了一个 0 就跳出来了。 说明 break 每次只终结了内层那一轮，外层毫发无伤。

想跳出两层怎么办？ 一级学的 break 只管一层。真要"一次跳两层"， 可以用一个标记变量配合判断，或者把代码写成一个函数再用 return—— 后者是三级以后的内容。二级只要记住"break 只管一层"就够了。

5　代码实战

Level Practice
关卡

食人魔营地

进入关卡 →
故事：你摸到了食人魔营地的边缘。营地中央堆着一只巨大的宝箱—— 里面装着被抢走的所有宝物。
可麻烦在于：食人魔会一波一波地冲过来。你要一边打退它们，一边抽空砸宝箱。 什么时候打人、什么时候砸箱子？全看眼前有没有敌人。

思路：看上面的关卡实况——宝物就堆在营地中央，可食人魔会一波一波地冲过来。 外层用一个永不停止的循环盯着营地，里面用 if-else 做一次判断： 有敌人就打敌人，没敌人就砸箱子。
这是"循环 + 分支"最经典的组合，也是二级考试里最爱考的结构。

重点示例：每轮先看一眼，再决定做什么 Python 
while True:
    enemy = hero.findNearestEnemy()   # 看一眼
    if enemy:
        hero.attack(enemy)            # 有人，打人
    else:
        hero.attack("Chest")          # 没人，砸箱
要点　一秒都没浪费：有人打人，没人砸箱
这段代码妙在哪？ 如果写成顺序结构（先打三下敌人，再砸一下箱子）， 那就一定会浪费动作——没有敌人的时候你在对着空气挥剑。
而"每轮先看一眼再决定"，是效率最高的写法。
和嵌套的关系：这里的 if-else 整个嵌在 while 里，每转一圈就判断一次。
嵌套不只是"循环套循环"，"循环套分支"也是嵌套——而后者在实战关卡里出现得更频繁。

6　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
嵌套循环的错误，最典型的就是"数错次数"和"缩错楼层"。 下面四条你要是全躲过，这章就没问题了。
1
把次数算成"相加"。以为外 3 次、内 4 次，总共 7 次。
扣哒鸭：是相乘！3 × 4 = 12 次。
因为外层每动一次，内层就要跑满一整轮——一整轮懂吗，不是一次。
正确算法：总次数 = 外层次数 × 内层次数
2
把换行的 print() 缩进到内层。结果星号变成一列，一行一个。
扣哒鸭：换行是"这一行画完了"的意思，所以它属于外层。 缩进到内层，等于每画一个星就换一次行——那还叫什么"一行"？
正确写法：换行的 print() 与外层的 for 对齐
3
以为 break 能一次跳出两层。
扣哒鸭：break 只管它自己那一层。 你在内层写 break，外层该转还转——这叫"各扫门前雪"。
正确理解：break / continue 只作用于它所在的那一层循环
4
内外层用了同一个变量名。比如内外都写 for i in range(...)。
扣哒鸭：内层的 i 会把外层的 i 覆盖掉， 外层那个圈就找不着北了。
习惯写法：外层用 i，内层用 j，第三层用 k——老规矩，别乱。
正确写法：for i in ...: 里用 for j in ...:

下列 Python 代码执行后，其输出是（　　）。
1  cnt = 0
2  for i in range(10):
3      cnt += 1
4  print(i, cnt)
A.10 10　　B.9 9　　C.10 9　　D.9 10
查看答案与详解
答案：D。range(10) 产生 0~9 共 10 个数， 循环结束时 i 停在最后一个值 9， 而 cnt 累加了 10 次，是 10。

原创练习题单选题
下列 Python 代码中，print("*") 一共会执行多少次？（　　）
1  for i in range(4):
2      for j in range(5):
3          print("*")
A.9　　B.20　　C.4　　D.5
查看答案与详解
答案：B。外层 4 次，内层每次 5 次， 总共 4 × 5 = 20 次。
易错点：不要把它们相加（那是 9）——外层每转一圈，内层都要跑满一整轮。

原创练习题单选题
下列 Python 代码执行后，输出的结果是（　　）。
1  for i in range(3):
2      for j in range(3):
3          if j == 2:
4              break
5          print(i, j)
A.输出 9 行　　B.输出 6 行　　C.输出 3 行　　D.什么都不输出
查看答案与详解
答案：B。外层 3 次；每一轮内层 j 依次取 0、1、2—— j=0 和 j=1 各打印一次，j=2 时遇到 break 跳出内层。
所以每轮输出 2 行，3 轮共 6 行：0 0、0 1、1 0、 1 1、2 0、2 1。
关键：break 只跳出内层，外层照样跑满 3 轮。

for i in range(5):

题目要求：用嵌套循环打印一个"倒三角形"——第一行 5 个星号， 第二行 4 个，第三行 3 个，第四行 2 个，第五行 1 个。

8　本单元小结

Unit Summary
贺舒曼 · 镜中先知
三层意思，说完就散课：
一、外层跑一次，内层跑满一整轮——所以次数是相乘，不是相加。
二、缩进就是楼层：缩进 4 格属于外层，缩进 8 格属于内层。
三、break 只管一层，别指望它一次跳两层。
你们现在已经会用"循环套分支"写出真正干活的程序了。下一单元，我们换个轻松的话题——让数字听话。

你在漩涡阶梯学到了什么

  • 循环嵌套——重复的事情里还包含着另一件要重复的事情。
  • 执行顺序——外层每转一圈，内层必须跑满一整轮。
  • 次数计算——总次数 = 外层次数 × 内层次数（不是相加）。
  • 缩进即楼层——缩进 4 格属于外层，8 格属于内层。
  • 打印图形——外层管"第几行"，内层管"这一行几个"，换行的 print() 属于外层。
  • break 的范围——只跳出它所在的那一层；内外层变量名要用 i / j / k 区分。
  • 循环 + 分支——"每轮先看一眼再决定"，这是实战关卡里最常见的写法。
