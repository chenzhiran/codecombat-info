1　为什么需要数学库

Why a Math Library

1.1 内置运算符不够用

自己写 vs 用现成的 Python 
# 想开平方，自己写很麻烦
# 用 math 模块，一行搞定

import math

print(math.sqrt(16))    # 4.0
print(math.sqrt(2))     # 1.4142135623730951
要点　import math 之后，用 math.函数名() 调用

1.2 导入 math 的两种写法

导入的两种写法：
写法一（推荐）：import math，用时写 math.sqrt(9)——一看就知道来自哪个库；
写法二：from math import sqrt，可直接写 sqrt(9)——短，但不易看出出处。
考试里两种都可能出现，都要认得。

2.2 两个容易踩的坑

两个容易踩的坑：
① math.pow 返回的是小数！ 要整数结果请用 ** 或 pow(a, b)。
② sqrt 的结果一定是小数， 即使 sqrt(16) 也返回 4.0 而不是 4。
要整数时记得用 int() 转换，或改用 math.isqrt()。

2.3 三角函数：参数是"弧度"，不是"度"

七级考纲把数学库分成了三小类：三角、对数、指数。
它们和二级学过的 sqrt / fabs 一样，都是现成的函数——难点不在"会不会写"，而在"参数是什么意思、返回什么类型"。真题里最爱考的就是这两点。

弧度 vs 度，一句话记牢：
数学库里的三角函数只认弧度。想用"度"，先乘 π 再除以 180（Python 写 math.radians(30)）。
三角、对数、指数的基本用法 Python 
import math

# ① 三角函数：参数是"弧度"，不是"度"
print(math.sin(math.pi / 2))            # 1.0    π/2 弧度 = 90 度
print(math.cos(0))                      # 1.0
print(math.sin(math.radians(30)))       # 0.4999...  ≈ 0.5

# ② 对数函数：三种底各有一个
print(math.log(math.e))                 # 1.0    以 e 为底（自然对数）
print(math.log10(1000))                 # 3.0    以 10 为底
print(math.log2(8))                     # 3.0    以 2 为底

# ③ 指数函数：e 的 x 次方
print(math.exp(0))                      # 1.0
print(math.exp(1))                      # 2.718281828459045
结论 三角的参数是弧度；log / log10 / log2 分别以 e / 10 / 2 为底；三个函数的返回值都是 float

2.4 它们在实际题目里怎么用

对数用来估"要试几次" Python 
import math

# 对数常用来"估数量级"：100 万个数，二分几次能查完？
n = 1000000
print(math.ceil(math.log2(n)))      # 20   只要 20 次

# 反过来，"每轮翻一倍"能用指数表示
days = 10
print(2 ** days)                    # 1024  与 math.exp 的差别见下面的提示
要点 log2 就是"翻倍几次"的逆运算；指数函数 exp 与 ** 的区别只有底不同

2.5 三个函数一起考的点

考场三步：
① 看参数单位——三角函数的参数是弧度；
② 看底数——log 是 e、log10 是 10、log2 是 2；
③ 看返回类型——三个函数都返回小数（Python 里是 float）。

3　两点之间的距离

Distance Between Two Points

3.1 距离公式怎么来的

这是七级最常考的计算之一：给出两个坐标，求它们之间的直线距离。

距离计算的标准写法 Python 
import math

def dist(x1, y1, x2, y2):
    dx = x2 - x1
    dy = y2 - y1
    return math.sqrt(dx * dx + dy * dy)

print(dist(0, 0, 3, 4))      # 5.0
print(dist(1, 1, 4, 5))      # 5.0
要点　先算两个方向的差，平方相加，最后开方

3.2 只比远近时不用开方

只比较远近时，可以不开方！ 因为平方运算是单调的——距离越远，平方和一定越大。
所以"谁离我最近"这类问题，直接比 dx*dx + dy*dy 就行， 既省一次开方，也避免小数误差。
这是个很实用的优化，考试里也常考。

4　取整与取余的配合

Rounding & Modulo

4.1 四种"取整"方式

四种"取整"方式，结果完全不同 Python 
import math

x = 7.6
print(math.floor(x))     # 7     向下取整
print(math.ceil(x))      # 8     向上取整
print(int(x))            # 7     截断

y = -7.6
print(math.floor(y))     # -8    注意负数！
print(int(y))            # -7    截断（向 0 靠）
重点　对负数，int() 是向 0 截断，floor() 是向下
经典应用题：能装几箱、需要几辆车 Python 
import math

items = 47          # 一共 47 件货
perBox = 10         # 每箱装 10 件

full = items // perBox             # 能装满几箱 → 4
need = math.ceil(items / perBox)   # 至少需要几个箱子 → 5

print(full, need)   # 4 5
区别　"能装满几个"用 //；"至少需要几个"用 ceil

4.2 取整与取余一起吃

什么时候用哪个：
"最多能装满几个" → //（向下取整）
"至少需要几个" → math.ceil()（向上取整）
"四舍五入保留小数" → round(x, n)
读题时先分清问的是"装得下"还是"够不够用"。

6　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
数学库的坑，一半是"整数还是小数"，一半是"负数取整"。四条，条条都考。
1
忘了 import math。
扣哒鸭：会报 NameError: name 'math' is not defined。
用之前一定要在文件开头写 import math。
正确写法：文件开头写 import math
2
以为 math.sqrt(16) 返回整数 4。
扣哒鸭：它返回的是 4.0（浮点数）。
题目要整数输出时，记得 int(math.sqrt(16))， 或者直接用 math.isqrt(16)。
正确做法：需要整数就 int() 转换
3
负数取整想当然。以为 int(-7.6) 和 math.floor(-7.6) 一样。
扣哒鸭：int(-7.6) 是 -7（向 0 截断）； math.floor(-7.6) 是 -8（向更小的方向）。
对正数两者相同，对负数就差了 1。
正确认识：int() 向 0；floor() 向下；ceil() 向上
4
用了 math.pow 却期望整数结果。
扣哒鸭：math.pow(2, 10) 得到 1024.0， 位数一大还会丢精度。
算整数幂请用 2 ** 10 或 pow(2, 10)（不带 math）。
正确写法：整数幂用 **

改编自 2026 年 6 月 · Python 七级 · 第 2 题单选题
雷塔的观星台上已经 import math。下列关于数学库函数的说法，正确的是（　　）。
A.math.log2(32) 的返回值类型为 int
B.math.pow(2, 5) 的返回值类型一定为 int
C.math.sqrt(49) 的返回值可以参与浮点运算
D.math.sin(90) 的参数 90 表示 90 度
查看答案与详解
答案：C。数学库里的这三个函数返回的都是浮点数：math.sqrt(49) 得到 7.0、math.log2(32) 得到 5.0、math.pow(2, 5) 得到 32.0。
所以 sqrt 的返回值当然可以参与浮点运算 —— C 正确。
A、B 错：返回值都是 float，不是 int；
D 错：三角函数的参数是弧度，math.sin(90) 里的 90 是 90 弧度（≈5157 度），想算 90 度要写 math.sin(math.radians(90))。
一句话记：数学库的"开方、对数、幂"三兄弟，返回的全是小数。
对应小节2.5 三个函数一起考的点。

使用 cmath（或 math）中的三角函数时，角度参数默认采用弧度制。（　　）
（　　）
查看答案与详解
答案：正确（√）。三角函数的自变量默认就是弧度，这是国际通用的数学约定，不是 Python 特有的。
换算关系：180 度 = π 弧度；想把度化成弧度，就乘 π 再除以 180（Python 里可以直接用 math.radians(度)）。

原创练习题单选题
已知两点 (1, 2) 与 (4, 6)，它们之间的距离是（　　）。
A.5　　B.7　　C.25　　D.3
查看答案与详解
答案：A。横向差 = 4-1 = 3，纵向差 = 6-2 = 4，
距离 = sqrt(3² + 4²) = sqrt(9 + 16) = sqrt(25) = 5。
这是最经典的 3-4-5 直角三角形。

A.7　　B.8　　C.6　　D.9

原创练习题编程题
题目要求：输入圆的半径 r，输出圆周长、圆面积（都保留 2 位小数），以及面积除以周长的值。
查看参考答案与要点 
import math

r = float(input("请输入半径："))

c = 2 * math.pi * r              # 圆周长
s = math.pi * r * r              # 圆面积

print("周长：", round(c, 2))
print("面积：", round(s, 2))
print("面积/周长：", round(s / c, 2))

运行示例：输入 5 → 周长 31.42，面积 78.54，比值 2.5
要点：
① math.pi 直接用，不用自己写 3.14（更精确）；
② 半径可能是小数，所以用 float() 转换输入；
③ 保留两位小数用 round(x, 2)；
④ 面积 ÷ 周长 = (πr²) ÷ (2πr) = r/2，可用来自我验证。

8　本单元小结

Unit Summary
塞尼克 · 沙海向导
三句话记住数学库：
一、先 import math，再用 math.函数名()。
二、sqrt 和 math.pow 返回的都是小数——要整数记得转换。
三、距离用勾股定理：sqrt(dx² + dy²)。
再送你一句："至少需要几个"用 ceil，"最多装几个"用 //。

你在塔顶星图上收获了什么

  • 导入模块——import math；调用写 math.函数名()。
  • 开方——math.sqrt(x) 返回浮点数；整数用 int() 或 isqrt()。
  • 取整——ceil 向上、floor 向下、int() 向 0 截断。
  • 常量——math.pi 直接用，精度比自己写的 3.14 高。
  • 距离公式——math.sqrt(dx*dx + dy*dy)，本质是勾股定理。
  • 实用优化——只比远近时，比较距离平方即可，不用开方。
  • 取整选择——"能装满几个"用 //；"至少需要几个"用 ceil。
