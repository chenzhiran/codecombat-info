1　标识符与关键字

Identifiers & Keywords

1.1 名字要合法

标识符（Identifier）就是你给程序里的东西起的名字，比如变量名、函数名。 给箱子刻名字总得守规矩——岗哨的规矩是这四条：

规则说明合法例子非法例子
① 只能用字母、数字、下划线不能有空格、减号、标点score、my_scoremy score、my-score
② 不能以数字开头数字可以在中间和末尾score1、lvl2_hp1score、2hp
③ 不能是关键字关键字被 Python 自己占用了total、countif、for、class
④ 区分大小写Score 与 score 是两个不同的名字score 与 Score 可共存—
口诀：字母下划线打头，数字不能走前头；空格标点都不许，关键字儿要绕开。

良好的命名习惯（不强制，但强烈建议）

  • 见名知意：用 hp 表示血量，别用 a、x、aaa。
  • 多个单词用下划线连：max_hp、player_score。
  • 变量名用小写：Python 社区的惯例是小写加下划线。

1.2 关键字不能占用

2　变量

Variables

2.1 会记事的木箱

程序运行的时候，需要不停地记住各种数字和文字：英雄的血量、捡到的金币数、对手的名字…… 这些"要记住的东西"就存在变量（Variable）里。

我们来看一个最小的例子：

变量初体验 Python 
hp = 100          # 把 100 放进名字叫 hp 的箱子里
print(hp)         # 打开箱子看看
OUTPUT　100

这一行 hp = 100 读作"把 100 赋值给 hp"。它做了两件事：

  1. 在内存里申请一小块空间；
  2. 给它贴上名字 hp，并把 100 放进去。

2.2 赋值：一个等号的秘密

这是零基础最容易搞错的地方： 在 Python 里，一个等号 = 不是"等于"，而是"把右边的值装进左边的变量"。 数学里的"等于"在程序里要写成两个等号 ==。
写法名字含义举例
=赋值运算符把右边的值放进左边的变量hp = 100　→ hp 里面装的是 100
==相等比较判断两边是否相等，结果是 True 或 Falsehp == 100　→ 结果是 True
扣哒鸭 · 调试官
一个等号是"装进去"，两个等号才是"一样吗"。这条记不住， 你后面写判断语句时会一错到底。我现在就说了，省得你到时候哭着回来找我。

再看两个赋值：

赋值的方向 Python 
name = "安雅"      # 字符串要加引号
level = 3
print(name, level)

3 = level          # 这样写是错的！左边必须是变量名
OUTPUT　安雅 3　（最后一行为语法错误）
方向感：赋值语句永远是从右往左。 hp = 100 是"把 100 装进 hp"； 写成 100 = hp 就像说"把箱子装进数字里"，Python 会直接报错。

2.3 变量的重新赋值

变量最大的好处是可以反复换内容，而且可以拿自己算自己：

血量被打了 Python 
hp = 100
print("初始血量：", hp)

hp = hp - 30        # 取出现有的 hp，减掉 30，再放回去
print("挨了一下：", hp)

hp = 60             # 也可以直接换成另一个值
print("回血后：", hp)
OUTPUT　初始血量： 100
挨了一下： 70
回血后： 60

请重点体会 hp = hp - 30 这一行。虽然两边都有 hp，但它不是等式，而是三步操作：

  1. 先取出右边 hp 现在的值（100）；
  2. 计算 100 - 30，得到 70；
  3. 把 70 放回左边那个叫 hp 的箱子。
一句话记忆：赋值是"装"，不是"等"； a = a + 1 的意思是"把 a 现在的值加 1 之后再装回去"。
娜莉亚 · 翠羽射手
我的箭袋里永远有箭。可射出去一支，就少一支——
arrows = arrows - 1，你看，这就是变量在"变"。
哪天箭袋空了，我就得回家补货。变量的值会变，所以你得时时盯着它。

3　常量

Constants

常量（Constant）是程序运行过程中不会改变的值。 比如岗哨灯的"最大亮度"、圆周长公式里的圆周率，它们在整段程序里始终是一个数。

变量常量
值会变吗会，随时可以重新赋值不会，一旦定下就不再改动
例子血量、分数、金币数圆周率、最大等级、一天的小时数
命名习惯小写加下划线：max_hp全大写加下划线：MAX_LEVEL
常量的写法 Python 
PI = 3.14159          # 圆周率，以后都不改
MAX_HP = 999          # 血量上限

hp = 100              # 这个是变量，会变
hp = hp + 50
print(PI, MAX_HP, hp)
OUTPUT　3.14159 999 150
重要区别：Python 并没有一条语法强制常量真的不能改—— 你写 PI = 3 它也不会报错。 常量是一种"约定"：用全大写名字提醒自己和大家，这个值不要动。 而考试里问"常量和变量的区别"，标准答案就是：变量的值可以改变，常量的值不能改变。

4　四种基本数据类型

Basic Data Types

箱子可以装不同的东西：装粮的是粮箱、装箭的是箭箱。程序里的"箱子"也一样， 放进不同类型的数据，就成了不同的数据类型（Data Type）。 一级阶段你只需要掌握四种：

类型中文名Python 中的名字例子要点
整数整型int100　-7　0不带小数点的数
浮点数实型 / 小数float3.14　0.5　-2.0带小数点的数
字符串文本str"安雅"　"100"用引号括起来的一串字符
布尔值真/假boolTrue　False只有两个值，注意首字母大写

4.1 整数与浮点数

整数与浮点数 Python 
gold = 120            # 整数
price = 9.5           # 浮点数
print(gold)
print(price)
print(gold + price)   # 整数和浮点数一起算，结果变成浮点数
OUTPUT　120
9.5
129.5
注意：2.0 虽然数学上等于 2，但在 Python 里它是浮点数，不是整数。 只看有没有小数点，不看值的大小。

4.2 字符串

字符串就是用一对引号括起来的一串字符。单引号、双引号都可以，但要成对：

字符串的写法 Python 
name = "安雅"
job  = '守夜人'
print(name)
print(job)
print("你好，" + name)     # 字符串可以用 + 拼起来
OUTPUT　安雅
守夜人
你好，安雅
最容易混的一点：100 是整数，"100" 是字符串。 加了引号就不再是数字，而是一段文字。 这两个看起来一样，但类型完全不同，也不能直接相加： 100 + 1 得 101，而 "100" + 1 会直接报错。

4.3 布尔值

布尔值（bool）只有两个值：True（真）和 False（假）。 它们专门用来表示"条件成立不成立"，是第 5 单元判断语句的基础。

布尔值 Python 
is_night = True
is_full  = False
print(is_night, is_full)
print(10 > 9)          # 比较的结果也是布尔值
OUTPUT　True False
True
大小写警告：必须是 True / False—— 首字母大写，其余小写。 写成 true、TRUE、FALSE 都会报错。 这是真题考过的一个点，务必记牢。

4.4 类型查看 type()

不确定一个值是哪种类型？用 type() 查一下就知道：

查类型 Python 
print(type(100))
print(type(3.14))
print(type("100"))
print(type(True))
OUTPUT　<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>

5　类型转换

Type Conversion

有时候你得把箱子里的东西换个形式装——比如把"100"这块写着字的木牌，变成真正的数字 100。 Python 给了三个转换函数：

函数作用例子结果
int()转成整数int("100")　int(3.9)100　3（直接截断，不四舍五入）
float()转成浮点数float("3.5")　float(7)3.5　7.0
str()转成字符串str(100)　str(3.5)"100"　"3.5"
类型转换实战 Python 
a = int("100")        # 字符串 → 整数
b = float("3.5")      # 字符串 → 浮点数
c = str(100)          # 整数 → 字符串

print(a + 1)          # 现在是数字了，可以算
print(c + "分")       # 现在是字符串了，可以拼
print(type(a), type(c))
OUTPUT　101
100分
<class 'int'> <class 'str'>
两个坑：
① int(3.9) 的结果是 3，不是 4。 它切掉小数部分，不做四舍五入（要四舍五入得用 round()）；
② 不是所有字符串都能转数字：int("abc") 会报错。 只有内容全是数字的字符串才转得动。
扣哒鸭 · 调试官
int(3.9) 是 3 不是 4，别拿数学课的习惯套程序。 类型转换是"换一种装法"，不是"按数学规则算个近似值"。 想四舍五入？那是 round() 的活儿，别让 int() 背锅。

6　变量的自增自减

Increment & Decrement

"让变量自己加 1"是程序里出现得最频繁的操作之一。前面我们写成 hp = hp + 30， Python 还给了一种更简短的写法：

简写等价于含义
a += 1a = a + 1自己加 1
a -= 1a = a - 1自己减 1
a *= 2a = a * 2自己乘 2
a //= 2a = a // 2自己整除 2
a %= 3a = a % 3自己取余
计数器 Python 
count = 0
count += 1
count += 1
count += 1
print(count)          # 数到 3

hp = 100
hp -= 25              # 挨了 25 点伤害
print(hp)
OUTPUT　3
75
注意：Python 没有 a++ 这种写法（那是 C / C++ / Java 的语法）。 在 Python 里一律写成 a += 1。这是一个很容易被带偏的地方。

7　代码实战

Level Practice
关卡

名称大师

进入关卡 →
故事：你在装备间里翻出一副鹰眼眼镜。戴上它，你能一眼看见离自己最近的食人魔—— 麻烦来了：你根本不知道它叫什么名字。
以前打怪靠喊名字（hero.attack("Brak")），可现在名字是未知的， 喊不出来就打不着。怎么办？
先给它起个名字，记在木箱里——这就是"名称大师"要教你的本事。

思路：看上面的关卡实况——三只食人魔就站在那里，可你叫不出它们的名字， 喊不出名字就打不着。那就换一招：用眼镜找到最近的敌人，把结果存进一个变量， 之后喊变量名就行，完全不需要知道它的真名。

重点示例：一组"找 + 打" Python 
# 把 hero.findNearestEnemy() 的结果装进变量 enemy1
enemy1 = hero.findNearestEnemy()

# enemy1 现在指向最近的敌人，用变量去攻击！
hero.attack(enemy1)
hero.attack(enemy1)
就这三行　找一次、打两下。换一只木箱（enemy2、enemy3）再重复两遍，三只食人魔就都倒下了
为什么不能只用一个变量？ 如果你一直用 enemy1，那"第一只敌人被打败后"，木箱里装的还是那只已经倒下的敌人。 变量会记住上一次放进去的东西，所以每换一个目标，就要重新装一次。
小技巧：整段代码里 hero.attack(enemy1) 出现了两次—— 因为小食人魔要挨两下。数一数你写了几组"找 + 打两下"，就知道自己打了几个敌人。

8　常见陷阱

Common Pitfalls & Debugging
扣哒鸭 · 调试官
变量这章的错误特别统一——不是名字起错，就是把"装"当成了"等"。 我把最常见的五个摆出来，你挨个避过去就行。
1
用关键字当变量名。写 if = 3 或 for = 5。
扣哒鸭：if、for、class 这些词是 Python 自己的，你借不走。 想表达同样的意思，加个后缀：if_flag、for_count。
正确写法：换个名字，例如 flag = 3
2
变量名以数字开头。写 1hp = 100。
扣哒鸭：数字只能出现在名字的中间或末尾，不能打头。 hp1、lvl2_hp 都行，1hp 不行。
正确写法：hp1 = 100　或　hero_hp = 100
3
把赋值当成数学等式。以为 a = a + 1 是不成立的。
扣哒鸭：这不是数学题，这是操作步骤：先算右边，再装进左边。 a = a + 1 的意思就是"把 a 加一之后再放回去"，完全合法，而且是程序里最常见的写法。
正确理解：赋值方向永远从右往左
4
数字和字符串相加。写 "100" + 1，程序报错。
扣哒鸭："100" 是文字，不是数字。 文字只能和文字拼，数字只能和数字算。 想把文字当数字用，先 int("100") 转一下。
正确写法：int("100") + 1　→　101
5
变量还没赋值就使用。直接写 print(score)，但前面从没写过 score = ...。
扣哒鸭：报错信息是 NameError: name 'score' is not defined。 箱子还没造出来，你就想打开看。先赋值，再使用——顺序不能反。
正确写法：先 score = 0，再使用 score

查看答案与详解
答案：C。100 是整数（int），3.14 是浮点数（float）， True 是布尔值（bool）。只有被引号括起来的才是字符串—— 所以 "3.14" 虽然看着像小数，它其实是一段文字。

下列代码执行后，输出的结果是（　　）。

2  b = int(a)
3  print(b + 5)
A.55　　B.10　　C."55"　　D.程序报错

答案：B。a 里装的是字符串 "5"， 经 int(a) 转换后变成真正的数字 5，5 + 5 = 10。
易错点：如果不转换，直接 a + 5 会报错（文字不能和数字相加）， 而 "5" + "5" 得到的是字符串 "55"——两个等号之差，天壤之别。

原创练习题判断题
在 Python 中，int(3.9) 的结果是 4。（　　）
查看答案与详解
答案：错误（×）。int() 转换浮点数时是直接切掉小数部分， 不做四舍五入，所以 int(3.9) 的结果是 3。 要四舍五入得用 round(3.9)。

Unit Summary

你在这只木箱里收获了什么

  • 标识符规则——字母或下划线开头，只能含字母、数字、下划线，不能用关键字，区分大小写。
  • 变量——贴了名字、内容可以改的箱子；赋值是"把右边装进左边"。
  • 常量——值不会改变，习惯用全大写命名提醒自己和别人。
  • 四种类型——int 整数、float 浮点数、str 字符串、bool 布尔值（True / False，注意大写）。
  • 类型转换——int() 截断、float() 转小数、str() 转文字；type() 用来查类型。
  • 自增自减——+=、-=、*=；Python 没有 a++。
