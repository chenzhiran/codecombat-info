1　每个变量都有地址

Addresses

1.1 变量住在内存的哪一格

内存就像一栋巨大的楼，里面是一间挨着一间的格子房， 每个房间都有一个编号——这个编号就是地址（address）。

一个变量 = 一间房 + 里面的东西 TEXT 
int a = 10;

内存里大概是这样：

  房间号（地址）      房间里装的东西
  ─────────────      ──────────────
  0x7ffd2a40    →        10

"a" 这个名字，是给程序员看的；
机器只认那个房间号。
要点　变量名 = 房间的"外号"；地址 = 房间的"正式编号"
打个比方： 你家住在"幸福路 12 号"。
"幸福路 12 号"是地址，"你"是住在里面的人。
别人要找你，可以直接报地址；也可以拿着写有地址的纸条去找——那张纸条就是指针。

1.2 用 & 取出地址

& 读作"取地址" C++ 
#include <iostream>
using namespace std;

int main() {
    int a = 10;

    cout << a << endl;        // 10        ← 房间里装的东西
    cout << &a << endl;       // 0x...     ← 房间的地址

    return 0;
}
读法　&a 读作 "a 的地址"
注意　地址每次运行可能都不一样——那是系统临时分配的，别去记具体数值

2　指针是什么

Pointers

2.1 定义指针变量

指针（pointer）就是一个专门用来存"地址"的变量。

定义指针要写"指向的类型 + *" C++ 
int a = 10;
int *p = &a;         // ★ p 是一个"指向 int 的指针"

// 拆开读：
//   int     → 它指向的东西是 int 类型
//   *       → 它是个指针
//   p       → 变量名
//   = &a    → 让它指向 a

cout << a << endl;    // 10        a 的值
cout << p << endl;    // 0x...     p 的值（就是 a 的地址）
cout << *p << endl;   // 10        p 指向的那个东西的值
三行输出　10 / 一串地址 / 10
关键区别　p 是"地址"，*p 是"那个地址里装的东西"

2.2 * 与 & 两个符号

符号名字作用例子
&取地址符问"这个变量住在哪儿"&a → a 的地址
*解引用符（取值符）问"这个地址里装着什么"*p → p 指向的值
最容易混淆的一点：* 有两种含义。 在定义的时候：int *p; —— 这个 * 表示 "p 是个指针"，是类型的一部分。
在使用的时候：*p —— 这个 * 表示 "把 p 指向的那个东西取出来"，是一个运算。
同一个符号，一个是"说明身份"，一个是"动手取货"——看它出现在哪儿。
一句话记忆： & 是"问地址"，* 是"按地址取货"。
它们俩正好是一对反操作：*&a 就等于 a。
取地址再解引用，就回到原点了。

3　指针能干什么

Using Pointers

3.1 通过指针改变量

改 *p 就等于改 a C++ 
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int *p = &a;

    *p += 5;                 // ★ 通过指针改 a

    cout << a << endl;        // 15
    cout << *p << endl;       // 15
    return 0;
}
OUTPUT　15 / 15
看明白了吗　*p += 5 改的是 p 指向的那个变量， 所以 a 也变成 15 了——因为 p 指的就是 a
这就是指针最核心的能力： "隔着一段距离"去操作另一个变量。
直接写 a = 15 当然也行，那为什么要绕这一圈？
因为很多时候你拿不到 a 本身——只能拿到它的地址。 比如函数传参、动态数组、链表，都离不开指针。

3.2 指针与数组

数组名本身就是"第一个元素的地址" C++ 
int a[4] = {10, 20, 30, 40};
int *p = a;              // ★ 数组名可以直接赋给指针

cout << *p << endl;       // 10    第一个元素
cout << *(p + 1) << endl; // 20    往后挪一格
cout << *(p + 2) << endl; // 30
cout << p[1] << endl;     // 20    ★ p[1] 和 *(p+1) 是一回事

// 换个角度看：a[i] 其实就是 *(a + i)
cout << a[1] << endl;      // 20
cout << *(a + 1) << endl;  // 20    完全等价
两条重要等价关系　a[i] ≡ *(a + i)； &a[0] ≡ a
为什么数组和指针这么"亲"？ 因为数组里的元素是一个挨一个连续摆放的。
只要知道第一个元素的地址，加上偏移量就能找到任何一个。
所以 a + 1 不是"数值加 1"，而是 "往后挪一个元素的位置"—— 如果 a 是 int 数组，a + 1 实际跳过的字节数是 4（一个 int 的大小）。
记住这三条就够了： ① 数组名就相当于"第一个元素的地址"，可以直接赋给同类型的指针。
② a[i] 和 *(a + i) 完全等价， 这也是为什么下标从 0 开始——因为 a[0] 就是 *(a + 0)， 偏移量是 0。
③ a + 1 是"挪一个元素"，不是"挪一个字节"。

4　复合数据类型

Composite Types

4.1 简单类型与复合类型

类别包含什么特点
基本类型int、long long、double、char、bool单一的、不可再分的最小单位
复合类型数组、指针、结构体、引用、string由别的类型"组装"而成
判断"是不是复合类型"的方法： 问一句——"能不能把它的定义拆成'某种类型 + 修饰'？"
int *p：是"指向 int 的指针" → 复合。
int a[10]：是"10 个 int 排成的数组" → 复合。
string s：是"一串 char" → 复合。
double d：就是"一个双精度小数"，没别的了 → 基本类型。

4.2 指针本身也是一种类型

指针的类型由"它指向什么"决定 C++ 
int    *p1;      // 指向 int 的指针
double *p2;      // 指向 double 的指针
char   *p3;      // 指向 char 的指针

// ★ 不同类型之间不能随便互相赋值
int a = 10;
double *q = &a;   // 编译错误！类型不匹配

// 数组：几个 int 排在一起
int arr[5];      // 它是一种"数组类型"
double brr[5];   // 这是另一种"数组类型"
关键　指针必须"门当户对"——int* 只能指 int， double* 只能指 double
为什么指针要区分类型？ 因为"挪一格"要挪多少字节，取决于它指向什么类型：
int* 加 1 → 往后挪 4 字节；double* 加 1 → 往后挪 8 字节。
如果不管类型，编译器就不知道"加 1"该跳多远，整个下标寻址就乱套了。

图书馆谋士

进入关卡 →
故事：高台顶层是一间巨大的图书馆，书架一眼望不到头。
安雅递给你一张纸条：这不是书名，是书的位置——第几排、第几格。
你拿着纸条走过去，准确抽出了那本书。
看到了吗？她说，你手上那张纸条，就是指针。

思路：把"书的编号"存成数组， 用指针在书架之间移动，按位置取书。

用指针遍历一整排书架 C++ 
#include <iostream>
using namespace std;

int main() {
    int shelf[5] = {12, 7, 25, 3, 18};

    int *p = shelf;              // 指向第一格

    for (int i = 0; i < 5; i++) {
        cout << *p << " ";       // 取出当前格里的书号
        p++;                     // ★ 指针往后挪一格
    }
    cout << endl;

    // 指针挪过头了？用减法拉回来
    p = shelf;                   // 重新指回开头
    cout << *(p + 3) << endl;     // 3   直接跳着取

    return 0;
}
OUTPUT　12 7 25 3 18 / 3
三种写法都能取到同一格　*(p + i)、p[i]、shelf[i]
和本单元的关系： p++ 让指针往后挪一格，这是"用指针访问数组"的标准动作。
挪的"一格"到底是几字节？取决于类型—— int* 挪 4 字节、double* 挪 8 字节。
这正是"指针必须区分类型"的原因。

6　常见陷阱

Common Pitfalls
扣哒鸭 · 调试官
指针这块，考的都是"你有没有分清 p 和 *p"。四条，前两条几乎必考。
1
分不清 p 和 *p。
扣哒鸭：p 是地址，*p 是那个地址里的值。
int a = 10; int *p = &a; 之后——
输出 p 得到一串地址，输出 *p 得到 10。
记牢：p 是门牌号，*p 是房子里的东西
2
指针没初始化就直接用。
扣哒鸭：int *p; 之后，p 里存的是一个随机地址。
直接写 *p = 5; 就等于往一个不知道是谁的房间里塞东西——程序很可能当场崩溃。
定义指针时就要让它有明确的指向：int *p = &a;。
正确做法：定义指针时立刻初始化
3
以为 *p += 5 只改了指针。
扣哒鸭：改的是p 指向的那个变量！
int a = 10; int *p = &a; *p += 5; 之后， a 变成 15，*p 也是 15——它们本来就是同一个东西。
理解：改 *p 就是改 a 本人
4
以为 p++ 就是"地址加 1"。
扣哒鸭：p++ 是"往后挪一个元素"，不是挪一个字节。
int* 挪 4 字节、double* 挪 8 字节——
具体挪多少，看它指向什么类型。
记牢：p + n 是"往后 n 个元素"，等价于 &p[n]

7　题目练习

Practice

前 3 题改编自 C++ 四级真题，其余为原创练习题。

改编自 2026 年 9 月 · C++ 四级 · 判断题 第 1 题判断题
执行下面程序后，变量 a 的值为 15。（　　）
int a = 10;
int *p = &a;
*p += 5;
查看答案与详解
答案：正确（√）。逐句分析：
① int a = 10; —— a 里装 10。
② int *p = &a; —— p 指向 a， 此后 *p 和 a 说的就是同一个东西。
③ *p += 5; —— 等价于 *p = *p + 5， 也就是 a = a + 5，结果是 15。
本题最容易错的地方：以为 *p += 5 是在"移动指针"。 其实改的是指针指向的那个变量的值。
对应小节3.1 通过指针改变量。
改编自 2026 年 6 月 · C++ 四级 · 判断题 第 4 题判断题
执行下面程序后，输出为 20。（　　）
void change(int x) { x = 20; }
int main() {
    int x = 10;
    change(x);
    cout << x;
    return 0;
}
查看答案与详解
答案：错误（×）。输出是 10，不是 20。
为什么？因为 C++ 默认的参数传递是值传递（pass by value）——
change(x) 时，函数内部的 x 是 外面那个 x 的"副本"，是另一个变量。
函数里改的只是副本，函数一返回副本就销毁了，外面的 x 从头到尾没动过，还是 10。
想让函数真的改到外面的变量怎么办？传指针： void change(int *p) { *p = 20; }，调用时写 change(&x);。
对应小节3.1 通过指针改变量（这也是指针最实用的用途之一）。
改编自 2026 年 9 月 · C++ 四级 · 判断题 第 3 题判断题
下面的二维数组在内存中按行优先连续存储， 因此 *(*(a + 1) + 0) 的值为 5。（　　）
int a[2][4] = {{1, 2, 3, 4}, {5, 6, 7, 8}};
查看答案与详解
答案：正确（√）。分两层拆开看：
① a + 1 —— 指向第 1 行（下标从 0 开始，所以是第二行）。 a[i] 本身就是"第 i 行的首地址"。
② *(a + 1) —— 取出第 1 行，它退化为指向该行第一个元素的指针； 等价于 a[1]。
③ *(a + 1) + 0 —— 在第 1 行里偏移 0 格，指向 a[1][0]。
④ *(*(a + 1) + 0) —— 解引用，取出 a[1][0] 的值， 也就是 5 ✔
一句话：*(*(a + i) + j) 完全等价于 a[i][j]。
对应小节3.2 指针与数组。
原创练习题单选题
执行下面的代码，输出是（　　）。
int a[4] = {10, 20, 30, 40};
int *p = a;
cout << *p << " " << *(p + 2) << " " << p[3] << endl;
A.10 20 30　　B.10 30 40　　C.10 12 13　　D.0 2 3
查看答案与详解
答案：B。三部分分别看：
① *p：p 指向数组开头，解引用就是第一个元素 10。
② *(p + 2)：往后挪 2 个元素（不是 2 字节！）， 指向 a[2]，取值 30。
③ p[3]：p[i] 等价于 *(p + i)， 所以是 a[3]，值 40。
C 项是把指针偏移当成了字节偏移（10 + 2 = 12）——这是最典型的错法。
对应小节3.2 指针与数组。
原创练习题单选题
下面关于指针的说法，正确的是（　　）。
A.int *p; 定义之后 p 自动指向 0 号地址
B.指针变量里存的是另一个变量的地址
C.任意两个不同类型的指针之间可以随意赋值
D.*p 表示 p 的地址
查看答案与详解
答案：B。指针的本质就是"存地址的变量"。
A 错：int *p; 之后 p 里是不确定的值（野指针）， 不是自动指向 0 号地址。定义指针时必须初始化。
C 错：指针类型必须匹配。int* 不能直接赋给 double*， 编译器会报错——因为不同类型"挪一格"的距离不同。
D 错：p 才是地址，*p 是 "顺着地址把里面的东西取出来"。
对应小节2.1 定义指针变量；4.2 指针本身也是一种类型。
原创练习题判断题
*&a 的结果与 a 相同。（　　）
查看答案与详解
答案：正确（√）。& 和 * 是一对互逆的运算：
&a 是"取 a 的地址"， *&a 是"顺着这个地址把东西取出来"——正好绕回原点，得到 a 本身。
同理，&*p 就等于 p。
生活化的理解："你家的地址"是 &a； "照着地址找到你家、把住在里面的人请出来"是 *&a—— 请出来的当然还是你本人。
对应小节2.2 * 与 & 两个符号。
原创练习题编程题
题目要求：写一个函数 void swap2(int *a, int *b)， 用它交换两个变量的值。在 main 里读入两个整数， 调用该函数后输出交换的结果。
样例：输入 3 8，输出 8 3。
查看参考答案与要点 
#include <iostream>
using namespace std;

void swap2(int *a, int *b) {
    int t = *a;      // 保存 a 指向的值
    *a = *b;         // 把 b 指向的值写到 a 指向的地方
    *b = t;          // 把原来保存的值写到 b 指向的地方
}

int main() {
    int x, y;
    cin >> x >> y;

    swap2(&x, &y);     // ★ 传的是地址，不是值

    cout << x << " " << y << endl;
    return 0;
}

要点：
① 为什么不用指针就不行？因为值传递只传副本， 函数里换得再热闹，外面的 x、y 也纹丝不动；
② 传指针就是传地址——函数里通过 *a 就能"隔空"改到外部的变量；
③ 调用时要写 &x、&y， 因为形参要的是地址；
④ 交换必须借一个临时变量 t， 否则第一步就会把原值覆盖掉；
⑤ 这是指针最经典、最实用的用途，四级考试里几乎必考。
对应小节3.1 通过指针改变量。

8　本单元小结

Unit Summary
安雅 · 红发队长
四句话记住指针：
一、每个变量都有地址；& 用来取地址，* 用来按地址取值。
二、指针就是"存地址的变量"；p 是地址，*p 是那个地址里的东西。
三、改 *p 就是改它指向的变量；这一点让指针能干成"隔着函数改外面变量"这种事。
四、数组名相当于首元素地址，a[i] 与 *(a + i) 完全等价。
枢纽看明白了。下一站是立体货架——那里有整整一面墙的格子，等着我们用行和列去编号。

你在传送带枢纽收获了什么

  • 地址——变量在内存里的"房间号"；变量名只是外号。
  • & 取地址符——&a 得到 a 的地址。
  • 指针——专门存地址的变量；int *p = &a;。
  • * 的两种身份——定义时表示"这是指针"，使用时表示"解引用取值"。
  • 核心区别——p 是地址，*p 是那个地址里的值。
  • 互逆运算——*&a 就是 a；&*p 就是 p。
  • 改指针指向的内容——*p += 5 会让原变量一起变。
  • 值传递的局限——函数默认只拿到副本，想改外部变量就得传指针。
  • 指针与数组——数组名相当于首元素地址；a[i] ≡ *(a + i)。
  • 指针算术——p + n 是"往后 n 个元素"，挪多少字节取决于类型。
  • 复合数据类型——数组、指针、结构体、引用、string 都属于复合类型。
  • 野指针——定义指针时一定要初始化，否则指向的地址是随机的。
