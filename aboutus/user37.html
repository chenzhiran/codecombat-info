现在少儿编程考级也太多了。电子学会、GESP，还有各种没听过的认证，每家都说自己权威。

我不是不愿意让孩子考证，我是怕辛辛苦苦准备大半年，最后拿了张谁也不认的证书。

前阵子咨询一家编程机构，老师上来就给我介绍考级规划，一级、二级、三级，安排得明明白白。

我问：“那这些证书到底有什么用？”

对方说了一堆，我听完还是没搞明白。

更离谱的是，孩子现在连 Python 循环都没学扎实，人家已经开始给我规划后面的竞赛了。

我想让孩子学点真本事，不是想给他集邮。

后来我学着自己做判断

我专门研究了一下，发现少儿编程考级还真不能光听机构推荐。

主办方是谁？考什么内容？孩子目前的水平适不适合？这些才是该先弄清楚的。

我现在比较关注的是 CCF 推出的 GESP 编程能力等级认证。它有明确的等级划分和考试大纲，支持 Python、C++ 等语言，至少能让我知道不同阶段需要掌握哪些知识。

但我也清楚，考过 GESP 不等于信奥获奖，更不代表升学有保障。

所以比起花钱买一套所谓的“冲证套餐”，我更想先让孩子把基础学明白。

意外发现

后来了解到 CodeCombat扣哒世界，发现它除了平时能通过游戏闯关学真实代码，还有免费的考级学习内容。

137 个 GESP 学习单元免费开放，覆盖 Python、C++ 一至八级，还有图形化一至四级。每个阶段有学习目标、知识点和考纲对照，再也不用我自己到处拼凑资料。

另外还有 CSP-J、CSP-S 相关的信息学竞赛学习内容，孩子以后真有兴趣往算法、竞赛方向发展，也能先了解需要学什么。

平时在游戏里敲 Python 代码控制英雄闯关，卡住了扣哒鸭会提醒，点“问问AI”还能要到思路。

我们现在的节奏

先让孩子真正学会编程，再根据掌握情况决定要不要考、考哪一级。

而不是证书还没拿到，先把钱交了一大堆。

我把这个想法跟那位机构老师说了，对方沉默了两秒，说“您这个思路比较务实”。我心里想，这不就是因为你们不务实吗。

说到底，证书是学习成果的一种证明，不应该成为孩子学编程的唯一目的。考证最怕的不是没考过，而是忙活半天考试，孩子还是不会自己写代码。

证书可以是里程碑，
但不能是终点线。
