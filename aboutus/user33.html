我发现少儿编程有个挺尴尬的现象：孩子学了好几年，家长却说不清他到底学到了哪一步。

我家孩子就是这样。从最开始的图形化，到后面接触 Python，前前后后折腾了快三年。

每次问他最近学了什么，回答永远是：“循环、判断、变量……”

听着好像都会，但真让他自己写个小程序，又不知道从哪儿下手。

我自己就是程序员，太清楚这种感觉了

学过知识点，不等于真正具备编程能力。

尤其是很多入门课程，今天教个循环，明天做个小游戏，单节课看着挺丰富。但学完之后呢？下一步学算法？做项目？还是准备考级？孩子不知道，我也不知道，一头雾水。

我不想让儿子学编程变成一种“每周上课打卡”，学了三年，最后只剩一堆结课证书。

所以这次我最看重的不是热闹

重新选平台时，我最看重的反而不是课程有多热闹，而是有没有一条能持续往下走的学习路线。

对比了一圈，最后选了 CodeCombat扣哒世界。

它让我比较满意的，是把编程知识放进了一整套循序渐进的闯关体系里：从最开始用 Python 指令控制英雄移动，到后面学变量、循环、条件判断、函数，再逐渐接触更复杂的算法和编程任务。

不是学完一个知识点就扔，而是在后面的关卡里还得反复用到。

这一点很关键。我上班写代码也是这个道理，一个 API 你用过三次，才算是真的会了。

2300 多道关卡意味着什么

平台有 2300 多道关卡，不是十几节体验课上完就没东西学了。

孩子想通关，就得自己写代码、运行、调试。哪里没理解，下一关很可能就会暴露出来。

遇到实在解决不了的问题，关卡里的“问问AI”会先给个思路，不用我下班以后继续当家教。

除了基础闯关，平台还有游戏开发、网页开发等方向，后续也能根据他的兴趣和能力考虑项目实践。

如果想准备 GESP 考级，也可以结合平台上免费的考级单元继续专项练习。

我现在的判断标准变了

现在我反而不太关心儿子今天又学了几个新知识点。

我更想知道，他能不能把以前学过的东西用起来，能不能独立解决一个比上周更复杂的问题。

上个月他做了一个小东西，能让英雄按顺序走一圈、捡完所有宝石、再回到起点。他自己挺得意的，我看了一下，逻辑是对的，就是写得啰嗦。

我没改他的代码，只说了一句：如果宝石有二十颗，你还这么写吗？他想了一会儿，说那得用循环。

编程不是学会几个语法就毕业了，而是从会写几行代码，到真正能用代码做点事情。

启蒙只是第一步。
真正重要的是，走完第一步之后，
还有没有清晰的第二步、第三步。
