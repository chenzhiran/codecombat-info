让儿子在 Python 和 C++ 之间选，他说“你选吧”

我一开始想让他学 C++。理由很充分：语法严格、能看见指针、以后打信奥也方便。

我给他讲了一堆，他听完说：“都行，你选吧。”

那一刻我知道，我说的那些他一个字都没听懂，他只是不想让我失望。

我换了顺序

我改成先让他用 Python 上手。理由不是“简单”，是反馈快：一行代码就能让英雄动，不用先写头文件、再写 main。

前三周他每天玩二十分钟，没有一次是因为我催。

第七周他开始自己拆任务。有一关要收集三组宝石再打 Boss，他先在纸上画了路线，再一格一格写。

先自己试了两晚，才敢给他用

我干这行十六年，见过太多“演示很漂亮、实际没内容”的产品。所以我自己开了个号，从第一关打了两晚，只看三件事。

一是真代码。每一关都得自己敲，写对才过，没有“看完视频点下一步”这条路。这一点我特别在意，因为孩子最容易糊弄的就是这个环节。

二是报错有没有人管。写错了，扣哒鸭会指出是哪一行、哪种错；实在想不通，点“问问AI”，AI 助教给思路不给答案，代码还得他自己改。

三是路径是不是完整。关卡地图 11 张，从图形化到 Python、C++，再到网页开发和 AI 编程，加起来 2300 多关，一次全开，不用一关一关买。

同一个关卡，换种语言写一遍

这是我最想说的一个设计：Python 和 C++ 在同一个关卡体系里是两条平行的写法。任务目标一模一样，只是语言不同，界面里直接给“换 C++ 试试”的入口。

对家长来说，这意味着不用换教材、不用重新适应一个界面，点一下就行。对孩子来说，他第一次知道：同一件事可以用不同的话说，但结果必须一样。

我的计划是，等他能自己拆分任务了，再换 C++。那时候他会先撞上“为什么这里必须写分号”“为什么数组下标从零开始”，这些问题他自己问出来，比我提前讲一百遍有用。

C++ 也不是白等

我查过考级这条路：GESP 三级往上要用 C++，CodeCombat扣哒世界里有 137 个免费的 GESP 学习单元，按级别排好，题也是按考点排的。

所以我不着急。他先用 Python 把思路练顺，需要换语言的时候资源就在那儿，不用再去外面报一个“考级冲刺班”。

一个反例

我同事的孩子，五年级直接上 C++，第一周就被编译错误劝退了，现在一提编程就烦。

不是 C++ 难，是顺序错了：先有“我能让它动”的信心，再谈“为什么它不让我动”。

账我也算过

我请过一对一老师，一小时六百。一年按四十周算，两万四，还没算接送的时间。

CodeCombat扣哒世界国内一年 999，一天两块七。我一开始也不信这个价，试完那两晚才觉得：钱花在内容上，比花在“有人盯着”上更值。

我也不是替它说好话。如果孩子需要人推着走、家里又没人能陪，线下的钱不算白花。

为什么我敢推荐给同事

我是做技术的，习惯先看底子：2013 年在美国硅谷成立，做了十三年；全球 190 多个国家在用，2000 万学习者，7.5 万所合作学校、32 万名教师。

课程体系通过了美国大学理事会 AP CSP 的官方认证，也是 Code.org 的官方合作伙伴。这几条我能自己去核，不用听销售转述。

他现在的状态

每天二十分钟，自己在日历上打卡，我不催。周末他会挑一关“看起来难”的，卡住了先看报错，再点问问AI，最后才来找我。

前几天他问我：为什么 Python 不用写类型？我说因为它在运行时自己判断。他想了想，说那是不是快不了。

这个问题我答了十分钟。他听懂了一半，但我很高兴，这是他第一次从“怎么写”问到“为什么这样设计”。

语言不是门槛，
顺序才是。
